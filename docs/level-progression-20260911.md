# 지역·장비 레벨과 착용 요구조건

현재 개발본의 실제 게임에 적용. 수치의 단일 설정은 `data/level-progression.js`, 변환·보상 규칙은
`js/level-progression.js`가 소유한다. UI는 계산 결과를 표시한다.

## 레벨의 역할

| 구분 | 기준과 용도 |
| --- | --- |
| 지역 레벨 | 기존 콘텐츠 티어 1/7/20/60 → Lv.1/25/77/137 사이 선형 변환. 이후도 마지막 기울기로 증가 |
| 몬스터 레벨 | 일반 = 지역, 정예 +1, 보스 +2. 생성 시 기록하여 이동 후 정산에서도 보존 |
| 아이템 레벨 | 드랍한 몬스터 레벨. 신규 드랍의 베이스/옵션 상한을 기존 콘텐츠 상한과 함께 제한 |
| 착용 요구 레벨 | 베이스의 요구 티어를 레벨로 변환한 뒤 8 감소, 최소 Lv.1 |
| 착용 요구 능력치 | 베이스 T1~2 없음, T3에서 6, 이후 티어당 2.8 증가(정수 반올림), T20까지 |

무기는 검·도끼 계열 힘, 활·발사기 계열 민첩, 주문·소환 무기 계열 지능, 창 계열 힘/민첩이다.
37개 무기 베이스의 `requirementWeights`에 능력치를 명시한다. 표시 이름으로 추측하지 않는다.
노바 로드·잿불 완드는 지능, 바늘 리커브·추적 레일건은 민첩, 회오리 글레이브는 힘/민첩을 요구한다.
방어구는 기본 방어도/회피/보호막의 종류로 능력치를 결정한다. 혼합 방어구는 각 요구량을 낮춘다.
장신구에는 능력치 요구가 없다. 고유 옵션 자체의 수치를 아이템 레벨로 다시 배율 조정하지 않는다.

기존 전투 티어와 보스·특수 콘텐츠 배율을 유지한다. 지역 데이터에 `areaLevel`을 명시하는 경우만
그 레벨을 기존 전투 곡선의 티어로 환산한다. 레벨과 티어 배율을 중복 곱하지 않는다.

## 착용·유지·저장

- 새로 착용: 해당 슬롯의 기존 장비를 제외한 영구 능력치로 판정한다. 후보 장비 자체의 능력치는 미포함.
- 착용 유지: 이미 입은 장비 자체의 능력치를 포함한다. 일시적 성소/조건/정예 버프는 제외한다.
  재관측/루프 전까지 지속되는 별자리 선택은 일반 빌드 효과로 포함한다.
- 조건 미달: 장비는 슬롯에 남지만 옵션·장착 주얼·복제·젬 보너스의 공급원에서 제외된다.
  부족한 장비를 순차 제외해 연쇄 조건 미달을 판정하며, 능력치 회복 시 다시 활성화된다.
- 프리셋: 기존 장비 유지와 새 장비의 실제 착용 가능한 순서를 함께 확인한다. 순환 의존으로
  능력치를 만들어내는 신규 세팅은 거부하고, 실패하면 장비와 인벤토리를 바꾸지 않는다.
- 루프 계승 장비: `inheritedLevelExempt`로 요구 레벨만 면제한다. 능력치는 계속 필요하다.
  루프 직후 요구 능력치가 부족해 비활성화되는 것은 의도한 정책이며 이번 리뷰에서도 유지했다.
- 이전 저장의 착용 장비: `requirementsVersion`이 없는 착용 장비만 `legacyRequirementGrace`를
  부여한다. 벗거나 교체하면 유예 종료. 신규 조건 미달 장비를 저장/로드해도 유예를 받을 수 없다.
- 아이템 레벨 누락은 기존 hidden/item tier에서 복원한다. 기존 옵션을 강제로 다시 굴리지 않는다.

`combatEquipmentStats`가 기존 계산기의 영구 능력치 단계와 최종 계산을 조립한다. 별도의 속성
공식을 복제하지 않는다. 임시 계산은 분리한 상태를 사용하며 `game`과 `window.game` 모두 복원한다.
동일 빌드는 서명으로 재사용하고, 동일한 값의 다른 장비 객체로 바뀐 경우도 참조를 갱신한다.
상태에 비활성 플래그를 저장하지 않으므로 저장된 잘못된 판정을 이어받지 않는다.

## 경험치·드랍

플레이어가 몬스터보다 높을 때만 적용하며 최고 도달 지역·루프 번호로 페널티를 정하지 않는다.

- 경험치: 5레벨 차이까지 100%, 이후 `exp(-(레벨 차이 - 5) × 0.10)`.
- 일반 드랍: 10레벨 차이까지 100%, 이후 `exp(-(레벨 차이 - 10) × 0.085)`.
- 장비·생장 드랍 확률과 장비 가뭄 보장 누적에 적용. 일반 재화는 보상 묶음의 채택 확률에 적용해
  소량 드랍이 정수 반올림으로 항상 사라지는 현상을 피한다.
- 코어 키·우버 보스/시련 등 입장권과 별도 완료 보상은 제외한다. 첫 액트 보스 진행 보장도 유지한다.
- 드랍 가능한 콘텐츠의 해금 검사는 계속 적용한다. 높은 적을 잡는다고 별도의 레벨 차이 배율을 더 주지 않는다.
- 일반 몬스터 경험치는 해당 레벨 필요 경험치의 6%(최소 24)를 출발점으로 하며 기존 루프·지역·장비
  보너스를 적용한다. 정예 1.8배, 보스 6배. 플레이어 필요 경험치의 10/20레벨 경계 하락도 제거했다.
- 루프 경험치 배율: 첫 루프 1배, 이후 루프당 0.05배씩 증가한다. 루프 10은 1.45배,
  루프 41부터 최대 3배다. 플레이어가 적보다 5레벨 높아진 이후 추가분만 선형 감소하며,
  10레벨 차이에는 추가분이 0이 된다. 이후에도 기본 1배와 기존 경험치 페널티는 적용한다.
  장비 경험치 보너스·지역 레벨·전투 난이도·아이템 레벨·일반 드랍 페널티 곡선은 변경하지 않는다.
- 온라인·방치 정산 모두 같은 몬스터 경험치/드랍 함수를 사용한다.

예: 40레벨 낮은 적의 일반 드랍 배율은 약 7.81%. 동일 기본 보상에서 열 배 빨리 잡아도 약 78.1%다.
이는 모든 빌드의 파밍 효율을 보장하는 수치가 아니라 초기 밸런스 기준이다.

## 표시와 확인

장비 툴팁에 아이템 레벨·옵션 상한·요구 레벨/능력치·비활성 사유를 표시한다. 장착 슬롯에 조건 부족
표시를 붙인다. 새 장비는 후보 슬롯 모두 검사하고, 일부 슬롯에만 착용 가능하면 그 슬롯 이름을
표시한다. 모든 후보가 실패할 때만 요구조건 부족 경고를 표시한다. 장착 중인 장비의 유지 판정은
해당 장착 슬롯을 기준으로 한다. 지역 이름 옆의 레벨·상시 보상 비율은 숨긴다. 지도에서 보상이 줄어드는 지역에만
`보상 감소`를 표시하고, 화력/생존력 안내에 호버·포커스·터치하면 지역 레벨과 일반 몬스터 기준
경험치/드랍 비율을 확인할 수 있다. 대상 몬스터 레벨 표시는 유지한다.

- `node scripts/smoke-level-progression.js`: 최초 착용/자체 유지/비활성/재활성/임시 버프/계승/기존 저장/
  재로드/프리셋 원자성/전역 참조 복원/드랍 및 경험치 경계를 확인한다.
- `node scripts/audit-level-progression.js`: 난수를 고정한 실제 지역 몬스터 배치의 1회 처치 계산.
  최신 루프 배율의 측정은 `docs/skill-assets-v338/review.md`에 기록한다.
  장비 경험치 보너스 0 기준이며 이동·처치 시간·사망은 포함하지 않는 합성 계산이다.
  경험치 장비를 사용하거나 같은 지역에 머무르면 레벨 차이가 벌어지고 드랍 감소가 적용될 수 있다.
- 같은 후반 세팅/최종 계산기로 요구조건 검사만 제외한 비교군과 측정:
  스탯 1회 중앙값 1.73 → 2.00ms, p95 2.63 → 3.00ms(200회). 환경별 차이가 있으며 모바일 실기 측정은 아님.
- `npx playwright test --config artifacts/level-progression/playwright.config.cjs`: 실제 게임을 저장과
  분리해 PC/모바일에서 장비 상태·계승·지역 레벨을 조작 검증. 예시 페이지는 배포 대상이 아니다.
- 후반 8소환수 세팅의 정밀 전투 재생 180초: 약 5.66초, 36킬/0사망, 원본 상태 불변 검사 통과.
  이는 간소화된 24시간 정산 시간 측정과 구분한다.

첫 적용 수치는 실사용 플레이 세이브와 장시간 플레이테스트로 추가 조정해야 한다. 자동 검사는
계산 일관성과 회귀를 확인하며, 난이도·재미가 확정됐다는 근거로 사용하지 않는다.

후속 리뷰 검증은 `scripts/smoke-level-progression.js`에 무기별 요구 능력치, 슬롯별 안내/장착,
루프 가속 경계와 온라인/방치 일치, 첫 루프 및 후반 루프 진행 회귀를 추가했다.
`tests/browser/level-requirements.spec.js`는 실제 게임 `/`의 장비창에서 PC/모바일의
오른쪽 장갑 안내 및 장착을 확인한다. 기존 저장 분리 페이지의 상태 전이 검사도 유지한다.
