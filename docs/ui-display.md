# 설정과 화면 배율

## 현재 설정 구성 (2026-10-15)

PC와 모바일 모두 화면 / 자동 진행 / 알림·기록 / 조작·메뉴 / 저장·계정으로 나눈다.
효과음 켜기와 음량은 모든 분류의 맨 위에서 조절한다. 창 배치 초기화는 조작·메뉴,
진행 삭제와 강제 클라우드 복원은 저장·계정 안의 접힌 영역에 둔다. 계정 진입 단추는 하나다.

- `js/settings-ui.js`: 일반 설정의 DOM 읽기·쓰기·동기화와 분류 선택. 이벤트가 발생한 필드만 저장한다.
- `js/main.js`: 저장 복원 뒤 `settingsUi.sync()`. 설정 창을 다시 열 때도 같은 동기화를 사용한다.
- `js/ui-audio.js`, `js/ui-display.js`, `js/icon-art-ui.js`, 기존 외형·저널·단축키 모듈은 각 전용 동작을 소유한다.
- `css/ui-premium.css`: 설정 배치와 분류 숨김. PC/모바일에 서로 다른 분류 로직을 두지 않는다.
- 새 일반 옵션은 기존 저장 필드와 `checks` 또는 `selects` 한 항목을 연결한다. 새 저장 필드라면 기본값과 저장 마이그레이션도 필요하다.

생명력·경험치·캐릭터 쉼표 4개는 한 체크박스로, 로그 집계·빈도 제한 2개는
‘반복되는 타격 기록 묶기’로 조절한다. 저장 필드 자체는 유지한다. 예전 값이 서로 다르면
체크박스에 혼합 상태를 표시하며, 해당 체크박스를 직접 바꿀 때만 모두 같은 값으로 바꾼다.
분류를 열거나 다른 설정을 바꿔도 숨은 항목·진행·장비를 덮어쓰지 않는다.
일반 설정 변경은 즉시 적용하고 기존 중요 저장 대기열로 저장한다.
오푸스의 이야기 로그 변경에 포함된 `showStoryLog`는 알림·기록의 ‘대사 표시’에 연결한다.
전투 로그 전체 표시와 별도로 조절하며, 기본값과 이전 저장의 선택을 유지한다.

하나뿐인 UI 스킨 선택 UI, 방 단위 전투에 해당하지 않는 몬스터 과밀 로그 선택 UI,
중복 계정 화면 단추를 제거했다. 과밀 로그의 이전 저장 선호와 비무대 콘텐츠 동작은 유지한다.
‘일시 정지’는 현재 구현대로 안내·선택 창에 적용하며 일반 메뉴 창 전체를 멈춘다고 안내하지 않는다.

## UI 배율

PC에서는 `최종 CSS 배율 = uiScale / 100 / (DPR / floor(DPR))`를 사용한다(DPR 최솟값 1).
Windows 125/150% 같은 소수 배율을 보정하며, 200%·Retina의 정수 배율은 유지한다.
창이 작아져도 사용자 설정을 자동으로 바꾸지 않는다. 가용 공간이 부족하면 기존 반응형 배치와
스크롤을 사용한다. 스마트폰·태블릿의 높은 DPR은 Windows 배율이 아니므로 역보정하지 않는다.

브라우저는 OS 배율과 브라우저 줌을 합친 DPR을 제공한다. 웹판의 기준은 브라우저 줌 100%이며,
크기는 게임 설정에서 변경한다. 모니터의 물리적 크기(mm)까지 같게 만드는 기능은 아니다.
향후 Steam 셸에서 OS 배율 API를 제공하면 DPR 읽기 경계만 교체한다.

## 소유와 좌표

- `js/utils.js`: 저장된 사용자 배율 정규화(80, 90, 100, 110, 125, 150, 175, 200, 225, 250; 기본 100).
- `js/state.js`, `js/save-migrations.js`: `settings.uiScale`. 모니터 배율 자체는 저장하지 않는다.
- `js/ui-display.js`: 디스플레이 배율, 루트 CSS zoom, 논리 화면 기준 media query, 설정 이벤트.
- 기존 창 관리자는 논리 좌표로 위치를 저장한다. 포인터/getBoundingClientRect 값은 화면 좌표다.
  CSS left/top에 넣을 때는 최종 배율로 나눈다. 캔버스 클릭은 표시 사각형과 논리 크기의 비로 변환한다.
- 전투·패시브 캔버스는 논리 크기와 실제 표시 배율을 함께 써서 불필요한 이중 고해상도 버퍼를 피한다.

레거시 CSS가 사용하는 vw/vh와 media query도 같은 논리 화면을 봐야 한다. 어댑터는 최초 로드와
head에 스타일시트가 추가될 때 기존 CSSOM 선언을 변환하고, 원래 media query는 별도로 보관한다.
매 프레임 DOM을 순회하지 않으며 스타일 속성 변경도 관찰하지 않는다. authored cascade는 그대로다.
새 인라인 스타일의 viewport 단위는 `calc(95vw / var(--ui-display-factor, 1))`처럼 작성한다.
JS의 UI 너비 조건은 `uiDisplay.matches()`를 사용한다. 컨테이너 질의로 전체 이전하면 CSSOM 변환을 제거한다.

## 검증

- 설정 변경 시 실제 게임에서 분류 이동, 설정 변경·재시작 복원, 작은 화면의 스크롤과 조작을 확인한다.
- 묶은 옵션은 이전 저장의 혼합 값 보존과 해당 옵션만 변경되는지 확인한다.
- 화면 배율 변경 시 PC/모바일의 글자·버튼, 창 이동과 캔버스 포인터를 확인한다.
- `npm test`, `npm run check:architecture`, `npm run check:css`, `npm run build`.

CSS 테두리와 네이티브 컨트롤의 소수점 픽셀 반올림은 허용한다. 게임 UI 설정은 보존하며,
테스트를 위해 사용자의 실제 저장이나 Windows 디스플레이 설정을 변경하지 않는다.
