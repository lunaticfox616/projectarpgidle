# 언어 바꾸기 준비(i18n)

기준: 2026-11-03. 게임은 한국어로 만들어졌고 화면 글, 데이터 이름, 저장 키의 상당수가 한국어다. 이 문서는 언어를 바꿀 수 있게 하려고 둔
기반 구조와 작업 규칙이다. 소유 코드는 `js/i18n.js`(핵심), `data/locales/`(언어팩), `js/settings-ui.js`(언어 선택 줄),
`scripts/check-i18n.js`(검사와 진행 보고)다.

- 영어·일본어·간체·번체의 효과 수치, 이상/이하 조건, 타격 간격과 총횟수, 칼날 관련 고유명사를 수정했다.

  작명 의도가 불명확한 `명사수의 경보`, `꿰뚫는 이`는 유지한다.
- 해금 카드의 이름·보상·설명·다음 해금·루프 유지/초기화 안내와 NPC 대사, 튜토리얼의 메뉴 이름을 표시 시점에 번역한다.
  단계 이름은 `그루터기 보관함 {n}단계`처럼 기존 숫자 템플릿을 사용한다. 해금 보드의 배치·렌더 캐시는 언어도 포함한다.
  저장되는 이름·해금 식별자·조건·재화 계산은 바꾸지 않았다.
- 모바일 능력치 분류, 하단 전체 메뉴와 작은 전투 화면, 능력치 출처 툴팁에도 같은 번역을 적용한다.
- 숫자 표시 설정의 `korean`·`korean_short`는 UI 언어와 관계없이 **조/억/만**을 사용한다.
  단위만 B/K로 옮기면 분모가 달라 잘못된 숫자가 되므로 번역하지 않는다. `english`는 기존 T/B/M/K 방식을 유지한다.
- 번역 표 가져오기는 빈 칸 판정에서만 앞뒤 공백을 제거한다. 저장할 값의 공백은 유지하며,
  기존 값의 위치를 JS 구문으로 찾아 바꾸므로 `{count}`가 든 복수형을 다시 가져와도 키를 중복 추가하지 않는다.
- 전수 검수와 수정 기록은 `artifacts/i18n-audit-20261107/`, `artifacts/i18n-fixes-20261107/`에 있다.
  대표 화면 확인은 전체 스토리 분기와 모든 화면 크기의 검증을 대신하지 않는다.

### 번역을 이어 가는 순서(한 묶음의 일)

1. 화면 글을 코드에서 `_t()`로 감싼다. 알림(`addLog`, `showGameToast`, `setCloudMessage` 따위)의 템플릿은 2026-11-04에 자동 변환했다(단순한 `${식}`은
   `{이름}` 자리로, 식에 문자열·조건식이 든 것은 손으로). 글만 바꾸는 데이터 이름은 보여 주는 자리(`escapeHTML(_t(x.name))`)에서 감싼다.
2. `node scripts/check-i18n.js --export <언어>`로 번역 없는 원문을 쓰인 자리와 함께 표(JSON)로 내보낸다. 새 글은 네 언어에 같이 없으므로
   한 언어의 표를 기준으로 네 언어를 한 번에 쓴다.
3. 표의 언어 칸을 문맥을 보고 채운다(이 저장소에서는 Codex/Claude가 직접 쓴다, 사용자 결정 2026-11-04). 숫자는 `{n}` 자리로 두고, 한국어 조사가
   붙는 글은 조사를 매개변수(`{particle}`)로 받아 다른 언어에서는 빈 글이 되게 한다(`{particle}` 자리는 번역에도 남긴다, 검사가 자리 불일치를 잡는다).
   이미 팩에 있는 비슷한 원문의 번역을 찾아 용어를 맞춘다(루프=ループ/循环/循環, 고유=ユニーク/传奇/傳奇, 액막이=魔除け/护符/護符 같은).
4. 언어마다 `--import <언어> 표`로 팩에 넣는다. 넣은 뒤 검사가 바로 돌아 모양과 코드에 없는 열쇠를 잡는다.
5. `npm run probe`로 그 화면을 각 언어로 띄워 본다(언어는 설정 창의 선택 상자, `?lang=ja`, `i18n.setLanguage('zh-TW')`).

## 설계 결정

### 언어팩은 선택할 때 읽는다 (2026-11-07)

한국어 시작에는 원문 메타데이터만 읽는다. 외국어 팩 네 개는 `index.html`의 `rel="rignin-language"` 링크로 선언하며,
`i18n.setLanguage`가 선택한 팩만 내려받는다. 로딩한 팩은 같은 페이지에서 재사용한다. `setLanguage`와 `applySaved`는 Promise를
반환하며, 이미 읽은 팩은 즉시 적용된다. 저장된 언어는 첫 화면을 공개하기 전에 적용한다. 15초 안에 받지 못하면 기존 언어로
화면을 열고 경고를 남긴다. 설정 창은 다운로드 성공 후에만 저장값을 바꾸며 실패하면 기존 선택을 유지한다.
다운로드가 끝났을 때 더 최근 언어 선택이나 다른 계정으로의 전환이 있으면 옛 요청을 적용하지 않는다.

웹 배포의 lazy 링크도 `scripts/lib/immutable-urls.js`가 내용 해시를 붙여 워커 캐시가 다른 배포의 팩을 섞지 않게 한다.
모바일·데스크톱 패키지는 같은 상대 경로의 로컬 팩을 읽는다. 언어 추가 시 아래 목록/링크/검사 절차도 함께 갱신한다.

### 한국어 원문이 열쇠다 (gettext 방식)

`_t('화면 배율')`처럼 **코드에 적힌 한국어가 그대로 열쇠**이고, 다른 언어 팩이 그 원문을 번역한다. 팩에 없는 글은 한국어로 보인다.
따로 지은 열쇠(`settings.display.scale`)를 쓰지 않는 까닭:

- 한국어로 먼저 쓰는 개발 흐름을 바꾸지 않는다. 글을 `_t()`로 감싸는 것이 유일한 규율이고, 감싸지 않은 글도 게임은 그대로 돈다.
- 데이터의 이름(`name: '첫 계약'`, `slot: '무기'`)이 저장 키이기도 해서 바꿀 수 없는데, 이 방식은 그 이름을 보여 주는 자리에서
  `_t(item.name)`으로 옮기면 끝난다. 열쇠를 새로 짓는 방식은 모든 데이터에 id를 더 달아야 한다.
- 원문이 바뀌면 번역이 떨어지는 것이 단점이라, `check:i18n`이 **코드 어디에도 없는 열쇠**를 실패로 알린다.

규칙(`js/i18n.js` 머리말에도 있다):

| 쓰기 | 뜻 |
| --- | --- |
| `_t('보유 {count}개', { count: 3 })` | `{이름}` 자리에 매개변수. 번역 뒤에 넣으므로 어순이 달라도 된다. 글을 `+`로 이어 붙이지 않는다. |
| `_t('접기|기록')` | 같은 한국어가 문맥마다 다르게 번역될 때 `|문맥`. 한국어로는 문맥을 떼고 보인다. |
| 팩 값 `{ one: '{count} item', other: '{count} items' }` | 복수형. `params.count`와 `Intl.PluralRules`로 고른다. 한국어 원문은 복수형이 없다. |
| `<b data-i18n>화면</b>` | 정적 HTML. **글만 든 요소**에 단다(자식 요소가 있으면 검사가 막는다). 원문은 처음 적용할 때 `data-i18n-source`에 남긴다. |
| `data-i18n-attr="data-tip aria-label"` | 그 속성도 옮긴다. |
| `i18n.locale` | `toLocaleString`, `localeCompare`에 넘기는 로캘. `'ko-KR'`을 직접 적지 않는다(검사가 막는다). |
| `window` 이벤트 `game:languagechange` | 번역한 글을 제 손으로 그려 둔 UI(선택 상자 꼬리표 등)는 이 이벤트에서 다시 그린다. 보기: `js/ui-display.js init`. |
| `i18n.enemyName(enemy.name)` | 적 이름은 말을 붙여도(`{name}의 기억`, `나이테 길잡이: {name}`, 앞 그림 글자, 뒤 `(변이)`) 한국어 원문으로 저장하고 보여 줄 때 이것으로 옮긴다. 생성 때 `_t`로 붙이면 언어가 섞이고 바꿔도 남는다(2026-11-05). 새 꼴은 `js/i18n.js` NAME_FORMS에. |
| 그려 둔 HTML을 서명으로 건너뛰는 UI | 서명에 `i18n.language`를 넣는다(보기: `js/equipment-triage.js render`). |

### 한국어 식별자는 저장 키다: 바꾸지 않고 보여 줄 때만 옮긴다

`game.equipment['무기']`, `settings.itemFilterSlots.무기`, `slots: ['신발']`, 고유 이름 `'첫 계약'`, 희귀도 글 `ITEM_RARITY_LABELS`
같은 한국어는 **식별자**다. 저장 파일과 서버 검사(`db/*.sql`의 추가 옵션·베이스 표)가 그 값을 알고 있어 바꾸면 모든 저장이 깨진다.

- 바꾸지 않는다. 영문 id로 옮기는 이관은 저장 마이그레이션·서버 표·클라우드 저장을 함께 바꾸는 별도 작업이고, 이 준비의 범위가 아니다.
- 보여 주는 자리에서만 `_t()`로 옮긴다. 부위는 `js/ui.js getItemSlotDisplayLabel`이 한 곳에서 옮기고, 영어 팩에 부위 이름이 들어 있다.
- **새 식별자는 영문으로 짓는다.** `check:i18n`이 한국어 식별자(변수·속성 이름, `.무기` 접근) 수를 `scripts/i18n-baseline.json`과 비교해
  늘면 실패한다. 줄였으면 `node scripts/check-i18n.js --baseline`으로 기준선을 내린다. 글자열 열쇠(`['무기']`)는 검사가 못 보니
  리뷰에서 본다.

### 언어팩 파일

`data/locales/<언어>.js`, 데이터 층(`safeExposeData`). `code`(언어 코드), `name`(그 언어로 적은 이름, 번역하지 않는다), `locale`(BCP 47),
`strings`(원문 → 글 또는 복수형). `ko`는 원문 언어라 `strings`가 비어 있고 이름과 로캘만 둔다.

언어를 더하는 절차:

1. `data/locales/<언어>.js`를 `en.js` 모양으로 만든다.
2. `index.html`에 다른 외국어와 같은 `rel="rignin-language"`, `data-language`, `href` 링크를 더한다. 부팅 스크립트나 `LOAD_ORDER`에 외국어 팩을 넣지 않는다.
3. `js/i18n.js`의 `LANGUAGE_PACKS`에 코드·이름·`safeExposeData`가 내보내는 전역 이름을 더한다. 설정 창의 목록은 `i18n.languages`에서 채워진다.
4. `npm run check:i18n -- --report`로 번역 없음이 0이 될 때까지 채운다.
5. 갈무리에 없는 글자를 쓰는 언어면 `css/tokens.css`에 `:root:lang(<언어>) { --font-cjk: … }` 줄을 더한다. 캔버스는 `i18n.fontFamily()`로 같은 값을 읽으니
   따로 고치지 않는다.
6. 저장 shape는 바뀌지 않는다(`settings.language`에 코드만 들어간다). 모르는 코드는 `mergeDefaults`가 `ko`로 바로잡는다.

### 저장

`settings.language`: `'ko' | 'en' | 'ja' | 'zh-CN' | 'zh-TW'`. 기본 `'ko'`(`js/state.js`). 불러올 때 `js/save-migrations.js mergeDefaults`가
`i18n.normalizeLanguage`로 바로잡는다(없거나 손상되면 `ko`, `scripts/smoke-save-migration.js`가 본다). 부팅은 `js/main.js applySavedPresentation`이
저장을 읽은 뒤 첫 렌더 전에 언어와 화면 배율을 함께 정한다. 설정 창에서 바꾸면 바로 적용되고 기존 중요 저장 대기열로 저장된다.

## 아직 남은 것 (언어를 내놓기 전 할 일)

- 화면 글 옮기기: 글이 많은 순서대로 `_t()`·`data-i18n`을 입힌다. 큰 덩어리는 `js/ui.js`, `js/combat.js`(전투 기록), `js/passives.js`,
  데이터의 `uniqueEffect`·설명 글(`data/items.js`, `data/skills.js`, `data/passives.js`). 데이터 글은 보여 주는 자리에서 `_t(def.text)`로 옮긴다.
  숫자가 든 글(`'소환수 최대 한도 +1'`)은 그대로 열쇠로 두거나 `{n}` 자리로 바꾼다.
- 이야기·대사(`data/story-journal.js`)는 2026-11-04에 팩에 넣었다(장면 글은 `scripts/check-i18n.js --export --descs`가 모으고, JSON 따옴표 글은 직접 모았다).
- 패치 노트(`changelog.md`)와 시작 화면의 약관: 한국어로 둔다. 영어판을 낼 때 정한다.
- CSS의 글은 `css/tokens.css`의 `--copy-*` 토큰이 소유한다(`:root:lang(en|ja|zh-CN|zh-TW)`에서 값을 바꾼다). 새 CSS 글은 토큰으로 두고 소유 스타일은 `var(--copy-…)`을 쓴다.
- 캔버스 글(`fillText`, `drawCrispCanvasText`)은 글을 넘기는 쪽에서 `_t()`를 쓴다. 글꼴 목록은 `i18n.fontFamily("'Galmuri11'")`처럼 받아
  `--font-cjk`가 붙게 한다(상수로 굳히지 않는다, 언어를 바꾸면 값이 바뀐다).
- Fusion Pixel 글꼴 갱신: 원본은 https://github.com/TakWolf/fusion-pixel-font (글꼴 OFL-1.1, 상위 글꼴 Ark Pixel·Misaki·MisekiBitmap·BoutiqueBitmap·
  Cubic 11·Galmuri도 OFL 또는 OFL 호환). 릴리스를 받을 수 없는 환경에서는 저장소를 받아 `uv sync` 뒤
  `uv run python -m tools.build_fonts --font-sizes 12 --width-modes proportional --font-formats otf.woff2`로 만든다(Ark Pixel 글리프는
  `assets/fonts/ark-pixel/version.json`의 커밋을 받아 `cache/ark-pixel-glyphs`에 두면 다운로드를 건너뛴다). `build/outputs/…-ja`, `-zh_hans`, `-zh_tw`를
  위 파일 이름으로 바꿔 넣는다. 굵은 글씨는 Fusion Pixel에 700 굵기가 없어 브라우저가 합성한다(갈무리 14와 같다).
- 영어는 한국어보다 길다. 고정 폭 조절에서 긴 글이 잘린다(2026-11-03 갈무리: 설정 창 선택 상자 `.cfg-select`의 `100% (recommended`,
  휴대폰 폭 설정 분류 단추의 `Display & Sou`). 글을 옮기면서 폭을 내용에 맞추거나 짧은 번역을 고른다.
- 피해 숫자 표기 `damageNumberFormat`의 `korean`·`korean_short`(억·만)는 한국어 전용 선택이다. 영어에서는 `english` 축약을 기본으로 둘지 정한다.
- 서버(`db/`)가 돌려주는 글(검사 사유, 채팅 금지 안내)은 서버가 한국어로 적는다. 코드로 받아 클라이언트가 `_t()`로 옮기는 쪽이 맞다.
- 새 플레이어의 기본 언어를 브라우저 언어(`navigator.languages`)로 정할지 결정한다(지금은 늘 `ko`).
- 업데이트 대응: 새 글이 생기면 위 "번역을 이어 가는 순서"대로 네 언어를 한 표에서 채운다. `npm test`의 `check:i18n`은 팩 모양과 자리만 보고
  번역 없음은 실패로 치지 않으므로, 내놓기 전 `--report`로 네 팩의 번역 없음이 0인지 본다.
- 긴 번역의 넘침: 일본어 하단 메뉴 이름표(`キャラ`·`ツリー`)와 영어 선택 상자처럼 고정 폭에서 잘리는 자리는 화면을 보고 폭을 맞춘다.

## 검사

```powershell
npm run check:i18n              # 언어팩 모양, 코드에 없는 열쇠, {자리} 불일치, 고정 로캘, data-i18n 자리, 한국어 식별자 기준선, i18n 행동
npm run check:i18n -- --report  # 번역 진행: 한국어 글이 든 줄 수, _t()·data-i18n 수, 팩마다 번역 없는 열쇠 목록
node scripts/check-i18n.js --export <언어> [파일] [--names] [--descs]   # 번역 없는 원문을 쓰인 자리와 함께 표로(기본 artifacts/i18n/<언어>-missing.json)
node scripts/check-i18n.js --import <언어> 파일                        # 표의 그 언어 칸을 팩에 넣고 검사(언어: en, ja, zh-CN, zh-TW)
node scripts/check-i18n.js --baseline   # 한국어 식별자를 줄인 뒤 기준선 내리기
npm test                        # 끝에 check:i18n도 돈다
```

실제 화면: `npm run probe -- --save none --size 1280x720 --script <파일>`로 설정 창을 열어 언어를 바꾸고 갈무리한다. 번역이 없는 글은
브라우저 콘솔에 `[i18n] en 번역 없음: …`으로 한 번씩 남고 `i18n.missingKeys()`로도 본다. 주소에 `?lang=ja`를 붙이면 저장을 바꾸지 않고 그 판만 그 언어로 뜬다.
