# 지도 UI 정리 · 2026-09-10

지도에서 현재 위치, 다음 진행 지역, 준비된 특수 지역과 입장 조건을 구분한다. 기존 콘텐츠의 해금 시점, 입장 비용, 전투·보상식 및 벌집의 10회 직접 선택은 유지한다.

## 변경

- 마지막으로 열린 액트를 선택하는 기존 경로는 전투력을 평가하는 추천이 아니므로 ‘추천 지역’ 대신 ‘다음 진행 지역’으로 표시한다.
- 지도와 우주계의 준비도는 ‘화력 / 생존력’과 ‘부족 / 적정 / 여유’로 표시한다. 수치 계산과 등급 경계는 유지하고, 근사 DPS·EHP 수치는 기존 툴팁에 남긴다.
- 액트 카드의 이름·보스·준비도 아래에 상태와 행동 버튼을 배치한다. 모바일 진행 지역 요약은 짧은 가로 배치를 사용한다.
- 탐험 상단에서 현재 전투로 돌아가거나 준비된 벌집·대균열·운석 안내를 바로 열 수 있다. 바로가기는 입장권을 소비하지 않으며 실제 입장 버튼이 기존 도메인 동작을 호출한다. 잠긴 콘텐츠는 바로가기에도 표시하지 않는다.
- 공허 균열 메뉴 이름에 대균열을 함께 표시한다. 메뉴명이 글자 중간에서 끊어지지 않게 한다.
- 벌집 입장 전에는 주요 전리품과 열쇠 비용/잔량, 입장 조건을 표시한다. 입장 후에만 누적 위험·확보 보상·여왕 처치 보상과 원정 포기가 나타난다.
- 지도에서 벌집 갈림길이 이미 보이면 같은 선택 팝업을 중복 표시하지 않는다. 전투 화면에서는 기존 팝업을 유지하고 최소화된 지도는 보이는 선택 화면으로 취급하지 않는다.
- 운석은 충전·준비·진행 상태를 구분하고 대균열은 개방 조건과 진행 상황을 표시한다. 단일 안내 패널은 카드 한 칸에 갇히지 않고 사용 가능한 너비를 채운다.
- 지속되는 메뉴 해금 테두리 광택을 줄이고, 라이트 모드의 지도 배경·완료 카드·탭·준비도 대비를 수정한다.

## 소유권과 호환

`js/side-encounter-ui.js`는 읽기 전용 안내를 조립한다. 입장·포기·이동은 기존 핸들러를 사용한다. 바로가기 HTML이 바뀔 때만 교체하며 전투 틱이나 별도 타이머를 추가하지 않는다. 저장 필드 및 저장 버전 변경은 없다. 전사 생성 시안은 이 변경과 별개이며 게임에 적용하지 않았다.

## 검증

- `npm test`: 181개 전체 스모크 통과.
- `npm run check:architecture`: 최종 런타임 구조·복잡도 검사 통과.
- Playwright 지도 입장/준비도/모바일 탐색과 기존 특수 전투 저장 복원: 7개 통과. 데스크톱에서 모바일 전용 검사 1개는 의도된 건너뛰기.
- 우주계 준비도 툴팁: PC·모바일 2개 통과.
- 실제 지도 스크린샷: PC 1440×900, Pixel 5 화면 크기에서 다크/라이트, 일반 지역 및 벌집·대균열·운석을 확인했다. 기기 성능이나 실제 플레이어 재미를 검증한 결과는 아니다.
- 중복 팝업 회귀 검사는 수정 전 PC·모바일 모두 원정 포기 버튼이 가려져 실패했으며 수정 후 통과한다.

## 후속 리뷰와 수정

- **벌집 닫기 반복:** 닫기 버튼이 DOM만 지우므로 다음 UI 갱신에서 같은 갈림길 창이 다시 생성됐다. 현재 선택 객체에 대한 닫기만 UI 소유 `WeakSet`에 기록한다. 지도에서 선택은 계속 가능하고, 다음 갈림길이나 저장을 새로 불러온 뒤에는 다시 안내한다. 저장 필드는 추가하지 않았다.
- **벌집 조작 상태:** 동일한 패널 HTML을 매번 교체해 선택 버튼 포커스가 사라졌다. 내용이 같으면 DOM을 유지하며 변경 시에는 기존 접기 상태 보존 함수를 사용한다. 지도와 팝업은 기존 선택 버튼 생성기를 공유하므로 이전 2개 선택 저장도 동일하게 처리한다.
- **PC 전투 복귀:** 전투 탭으로 직접 전환하면 화면만 숨겨지고 창 관리자의 열린 상태가 남아, 지도 재클릭이 열기 대신 닫기로 처리됐다. 데스크톱 전투 복귀 시 기존 창 정리 함수를 먼저 호출해 화면과 창 상태를 함께 닫는다. 모바일의 탭 전환 방식은 유지한다.
- **대균열 진행 가독성:** 중복 처치 수를 없애고 진행 단계·처치 수·군주 격파 보상을 한 영역에서 간격을 두어 표시한다. 사전 시간 안내는 전투 데이터의 지속 시간을 사용한다.

후속 검증: 위 벌집 포커스/닫기 문제는 수정 전 PC·모바일 모두 실패함을 확인했다. 수정 후 지도 재열기, 실제 선택, 다음 갈림길 안내, 대균열 9→10마리 보상 표시와 군주 단계 전환을 포함한 브라우저 검사 4개 통과. 지도 준비도·모바일 탐색/채팅·창 배치 복원·특수 전투 저장 복원 8개도 통과했고 플랫폼 전용 4개는 의도적으로 건너뛰었다. 최종 전체 스모크 181/181 통과. 대균열 진행 화면과 다음 벌집 갈림길의 PC·모바일 캡처를 확인했다.
