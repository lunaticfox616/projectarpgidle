# 전사 주변 키스톤 변경

- 결투의 규율: 주문 피해 증가를 공격의 피해 증가 합계에 한 번 추가한다. 스킬 태그·주문 기본 피해·주문 속도는 바꾸지 않으며 이전 근접 피해 30% 증폭을 제거했다.
- 피빛 요람: 전사에서 공허로 향하는 `pt_spine_warrior_left_07` 옆에 선택형 키스톤을 추가했다. 기존 노드와 연결은 유지한다. 기존 상태 이상 재적용/전파 구조를 사용하고 출혈 상한을 5로 고정한다. 확률(치명타와 스킬·저주 보너스 포함), 강제 적용 확률, 출혈 피해에 각각 0.7배를 적용한다. 점화·중독의 상한은 유지한다.
- 야만: 장착 후보 판정에 공통 제한을 적용한다. 직접 장착, 빈 슬롯 자동 장착, 장비 프리셋 모두 무기를 거부한다. 패시브 할당/프리셋 및 저장 복원 시 이미 장착된 무기는 주무기·보조손 모두 인벤토리로 돌려보낸다. 가득 찬 경우에도 소유 아이템을 삭제하지 않는다. 설명의 공격력을 기본 피해로 변경했다.

장비 제한 정의는 `data/passives.js`, 장착 상태의 제한/복구는 `js/state.js`, 장착과 프리셋 적용은 기존 장비 도메인, 패시브 계산과 출혈 판정은 기존 패시브/전투 모듈이 소유한다. 새 저장 필드나 스크립트 순서 변경은 없다. 런타임 트리와 편집기 원본 JSON을 함께 수정했다. 새 키스톤은 기존 출혈 이미지와 키스톤 프레임을 사용한다.

검증: 전체 스모크 182개. 키스톤의 실계산·확률·5중첩·다른 상태 이상 유지, 무기 장착 경로·프리셋 실패 시 아이템 유지·저장 복원·반복 복구를 검사한다. 브라우저에서는 PC와 모바일의 결투 툴팁, 피빛 요람 위치/설명 및 실제 포인트 사용을 확인한다.
