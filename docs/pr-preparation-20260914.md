# 누적 변경 PR 준비

대상: 열린 PR #1027, `codex/gems-progression-crafting-review-20260912` → `main`.
이 문서는 누적 변경과 최종 검증 기록이다.

## 추가 변경 범위

- 207종 고유 장비의 베이스·부위·요구조건과 기존 소유/도감/추적 기록 호환.
- 계 전용 드랍 후보와 우주계 조건부 효과, 드랍 원본 지역 전달 및 레벨/요구조건 연결.
- 세계수 탐험과 권역별 지도 진입, 시련 강조, 보상 툴팁, 전투력/층수 표시.
- 벌집·군락지·균열·운석·시간의 균열의 입장, 완료, 보상, 복귀 흐름.
- 패시브·젬 연구·지하계·창공·심해·낚시·저널·사망 기록의 조작 및 표시 개선.
- 브라우저 검사에서 사용하던 로컬 전용 페이지/합성 빌드를 `tests/fixtures/`로 이동.
- 액트 저널 팝업의 ‘다음부터 표시하지 않기’와 기타 → 설정의 ‘액트 저널 자동 표시’를 연결.
  설정은 저장되며 프롤로그·저널 소유·보상·수동 읽기는 유지한다. 꺼둔 동안의 팝업은 재표시하지 않는다.
- 장비 요구조건 장착 실패는 기존 로그와 화면 알림에 이유를 표시한다. PC 젬 더블클릭 장착과
  금색 장착 버튼을 추가하고, 이미 장착한 젬의 더블클릭은 해제하지 않는다. 모바일은 상세 후 장착을 유지한다.

## 준비 중 발견 및 조치

- Git에서 제외된 시연 자료를 브라우저 테스트가 참조해 CI에서 404가 발생할 수 있었다.
  필요한 5개 파일만 테스트 자료로 포함하고 관련 검사 경로를 변경했다.
- 초기 저널이 열린 현재 동작과 오래된 잠금 기대값이 달랐다. 초반 고급 기능 잠금은
  계속 검사하며 저널 접근 기대값만 현재 저널 설계에 맞췄다.
- `js/skills-ui.js`의 공백 오류 4곳을 정리했다.
- 런타임의 정적 에셋 경로 중 PR 포함 목록에서 빠진 파일은 없었다.
- 통합 브라우저 검사에서 이전 UI를 가정하던 검사도 정리했다: 일반 장비가 아닌 제작 대상의
  실패 문구, 주얼 미해금 대균열 보상 안내, 접힌 최종 관문 목록, 벌집 선택의 표시 위험 인자,
  투자 요약의 읽기 전용 컨트롤. 잠금·재화 불변·실제 이동 검증은 유지한다.
- 우주 탐사 검사는 사망창의 CSS만 지우지 않고 실제 `closeDeathOverlay`로 네이티브
  모달도 닫는다. 캐릭터 툴팁 검사는 진행 중 튜토리얼에 간섭받지 않도록 전투 시간을 정지한다.
- 장비 프리셋·낚시·보스 선택 검사도 합성 진행도를 설정한 뒤 전투 시간을 정지하고
  UI 갱신으로 발생한 안내를 닫는다. 강제 클릭으로 팝업을 통과하지 않는다.
- 저널 40종 읽기 검사는 10종씩 나눠 실행한다. 삽화 로딩·본문 끝·닫기·포커스 복귀와
  보상 불변 검증을 유지하면서 단일 검사의 시간 초과를 줄였다.
