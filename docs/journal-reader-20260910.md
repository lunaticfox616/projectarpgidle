# 저널 열람과 키스톤 설명 폭

- 그림 경로는 `journal-style-unification-20260910.md`에서 연결한 통일본을 유지한다. 프롤로그 원본, 장면 순서와 본문은 변경하지 않는다.
- 저널 목록에는 제목·읽기 버튼과 기존 영구 효과를 표시한다. 잠긴 기록의 조건·이동 버튼은 유지한다.
- `storyJournalUi.openEntry(id)`가 해금된 기록만 네이티브 모달로 연다. 그림이 있는 기록은 장면별 그림과 문구를 짝지어 표시하고, 없는 기록은 기존 본문을 표시한다.
- 열람은 알림 큐, 전투 시간, 저널 보상, 저장 데이터에 쓰지 않는다. 닫기/ESC는 모달을 제거하고 원래 버튼으로 초점을 돌려준다. 이미지 DOM은 해당 기록을 열 때만 만든다.
- 캔버스 툴팁은 기본 최대 390 CSS px와 UI 배율을 반영한 뷰포트 중 작은 너비를 사용한다. 긴 문장은 줄바꿈하며 기존 모바일 패시브 상세 창은 유지한다.
- 스크립트 로드 순서와 저장 shape 변경 없음. 새 전역 대신 기존 `storyJournalUi` 공개 객체를 사용한다.

검증: 전체 스모크 182개, PC/모바일 저널 열기·닫기·두 장면 표시·삽화 없는 기록·미해금 접근 차단·보상 불변·초점 복귀, 가장 긴 키스톤 설명의 가로 넘침 및 줄바꿈, 실제 다크/라이트 화면 확인. 브라우저 검사는 `npx playwright test --grep 'journal entries open|long keystone descriptions|duel keystone tooltip'`.
