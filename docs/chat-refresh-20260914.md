# 채팅 갱신 중단 수정

2026-11-07: 전체 조회가 진행되는 동안 받은 실시간 행은 조회 응답과 함께 남기고, 조회 전에 이미 알던 행은 서버 결과로
교체한다. 삭제 표시가 있는 행은 어느 쪽에서도 되살리지 않는다. 접속자 수는 타인 채팅과 30초 주기 조회가 같은 조회 시각을
쓰며, 본인 전송과 목록 열기에는 즉시 갱신한다. 공개 프로필의 이름은 사용자가 올린 스냅샷 대신 서버의 닉네임 열을 쓴다.
전송 제한은 삭제 가능한 메시지와 분리한 비공개 `chat_send_state`에 기록한다. 계정별 행 잠금으로 동시 전송도 제한을 공유하고,
계정 삭제 시 같이 지워진다. 기존 서버 적용 파일은 `db/system-hardening-20261107.sql`이다.

같은 날 후속 감사: 채팅·접속자·알림·닉네임·공개 프로필 요청은 계정 ID와 로그인 세대에 귀속한다. 로그아웃이나
계정 전환 뒤 도착한 성공·실패 응답은 현재 화면과 요청 상태를 바꾸지 않는다. A→B→A 재로그인도 구분하며,
같은 계정의 정상 토큰 갱신은 진행 중인 요청을 유지한다. 계정을 떠날 때 조회 캐시와 프로필 창을 비우고,
해제된 실시간 채널의 콜백도 무시한다. 같은 프로필을 연속으로 열어도 마지막 요청의 결과만 표시한다.

코어 첨부의 설명은 정상 생산 규칙 `CORE_ITEM_RULES.lines`의 4줄까지만 읽는다. 서버도 `kind: core` 첨부의
`lines`를 문자열 배열 0~4개로 검사한다. 기존 메시지에 과도한 줄이 남아 있어도 수신 화면은 상한을 적용하며,
정상 4줄 코어의 표시와 원본 장비·저장은 바꾸지 않는다. 전체 첨부의 64KiB·아이템 3개 제한도 유지한다.

같은 표시 경계에 부적 설명 5줄, 주얼 옵션 8줄, 구형 카드의 옵션·효과 각각 8줄도 적용한다.
일반 장비는 베이스 8줄·추가 옵션 12줄·복합 옵션의 추가 능력치 4개·기름 2개·잿불 2개로 표시용 복사본을 만든다.
별표·방어도 계산도 이 복사본을 읽는다. 소켓 주얼의 옵션은 8줄, 표시용 소켓 배열은 앞 8개만 읽는다.
실제 장비·저장·소켓 배열은 변경하지 않는다. 이전 수확물을 보존하는 소켓은 8개를 넘을 수 있어 서버는 소켓의
총개수를 제한하지 않으며, 정상 주얼 소켓은 앞부분에 있어 표시가 유지된다. 서버는 송신 snapshot의 대응 배열과
중첩 주얼을 검사하고, 빈 부적·설명 줄이 없는 구형 부적·일반 장비의 12줄 옵션을 계속 허용한다.

2026-10-21부터 새 채팅은 Supabase Realtime으로 받는다(chat_messages INSERT, `js/social.js` syncLiveChat). 채팅 전용 클라이언트가
게임의 로그인 토큰으로 붙고(accessToken 옵션, 심장박동마다 다시 읽는다), 연결된 동안 채팅 조회(4초)와 닫힌 채팅의 알림 조회(15초)는
1분에 한 번 도는 안전 조회가 된다. 연결이 끊기거나, 안전 조회가 실시간으로 오지 않은 남의 채팅을 두 번 찾으면 예전 주기로 돌아간다.
페이지를 1분 가리면 연결을 놓는다(무료 요금제의 동시 연결 수). 서버는 chat_messages를 supabase_realtime 발행에 넣어야 보낸다
(`db/social.sql`, 이미 설치한 프로젝트는 `db/chat-realtime-20261021.sql`). 아래는 2026-09-14 조회 방식 때의 기록이다.

## 원인과 변경

`switchTab`이 채팅 이외의 탭으로 이동할 때 무조건 수신 타이머를 중단했다.
PC에서 채팅 도크가 열려 있어도 장비 등 다른 창을 열면 갱신이 멈췄고,
열린 채팅은 백그라운드 알림 확인에서도 제외돼 다시 열기 전까지 메시지가 보이지 않았다.

`social.js`의 `syncSocialChatPolling`이 기존 채팅 표시 상태와 로그인 여부를 기준으로
수신을 유지하거나 중단한다. 이미 실행 중인 타이머는 재시작하지 않는다.
UI는 탭 전환 후 이 공개 함수를 호출하며 채팅 DOM이나 작성 중인 문장을 다시 만들지 않는다.
기존 스크립트 순서와 저장 데이터, 백엔드 스키마는 유지한다.

## 검증

- 수정 전 PC 브라우저에서 다른 탭을 연 뒤 새 메시지가 표시되지 않는 회귀를 재현했다.
- `scripts/smoke-social-chat-incremental.js`: 열린 도크 유지, 닫기, 재개, 중복 타이머 방지, 로그아웃(이 검사와 아래 브라우저 검사는 2026-10 핵심 검사 정리로 빠졌다).
- `tests/browser/community-entry.spec.js`: PC와 모바일의 수신 재개, 입력 보존 및 기존 채팅 동작.
- `npm test`, `npm run check:architecture`.

브라우저 수신 검사는 격리된 네트워크 응답을 사용한다. 공개 채팅에 메시지를 보내지 않았으며,
실제 서버 연결 지연이나 휴대폰 백그라운드 타이머 제한까지 제거하는 변경은 아니다.
