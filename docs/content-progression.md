# 콘텐츠 선택 해금 — 현재 적용 정책 (원장 v9)

## 나무꾼의 잔상 측정 (2026-10-26)

- 잔상은 공격하지 않으며 생명력을 재생하지 않는다. 원본 나무꾼의 재생을 물려받아 이미 준 피해가 측정에서 지워지던 문제를 고쳤다.
  방어·저항과 30초 측정 조건, 입장 해금과 귀환 위치는 유지한다. 예전 저장의 대기 중·전투 중 잔상도 재생하지 않게 복원한다.
  공격하지 않는 잔상의 특성 도움말에는 원본 보스의 공격 패턴 설명을 표시하지 않는다.
- 잔상이 먼저 쓰러지면 마지막 피해를 기록하고 끝낸다. 경험치·전리품·그루터기 성장·무기 숙련·처치 효과는 주지 않는다.
  같은 측정을 다시 완료 처리해도 기록 횟수가 늘지 않으며, 귀환·다른 지역 이동·루프 전환은 진행 중 측정을 취소한다.
  귀환은 기록을 남기지 않고 원래 지역으로 돌아가며, 그곳의 재정비 뒤 행동은 기존 귀환 설정을 따른다.
- 최근 측정 두 개의 피해·실제 측정 시간·DPS를 전적에 남긴다. 둘 다 30초를 채운 경우에만 이전 대비 증감률을 표시한다.
  기존 최고 기록은 보존하고, 예전 저장에 없는 최근 기록은 만들지 않는다. 기록을 불러와도 전투 보상은 지급하지 않는다.
  모바일 혼돈계 화면의 작은 전투 창은 처음에 접으며, 펼쳐도 측정 버튼과 결과를 위로 스크롤할 수 있는 여백을 둔다.
- 문구: 지도 → 혼돈계 → 나무꾼의 잔상에 `30초 피해 측정`, `최근 DPS`, `이전 대비 +N.N%`(감소는 `-N.N%`).
  기록 창 → 기록 탭 → 나무꾼의 잔상에도 `최근 DPS`, `이전 대비 +N.N%`, 비교할 측정이 없으면 `N.N초 측정`을 표시한다.
- 검증: 전체 스모크 20/20, 구조 검사·CSS 검사·배포 빌드 통과. 재생·보상·마지막 타격·중복 정산·귀환·기록 비교·저장 호환
  13항목을 이전 코드와 비교했다. 귀환 뒤 중단과 재시도 설정을 각각 확인했으며, 취소한 측정은 기록을 바꾸지 않는다.
  실제 전투 루프의 100ms 단위 30초 완주와 브라우저의 30초 완주·중도 귀환을 확인했다. 390×844·1440×900 뷰포트에서
  결과 카드와 모바일 전투 창의 접기·펼치기를 확인했다. 휴대폰 하드웨어·터치와 장기 밸런스는 미검증이다.
  검수 자료는 `artifacts/content-pass-20261026/`에 있다.

## 미궁 준비와 층 입장 (2026-10-26)

- 고대 미궁의 층 선택은 미리보기다. 선택한 층의 권장 전투력, 해금된 화석·봉인편린과 출현 가능한 미궁 고유를 표시하고, 별도 입장 버튼으로 출발한다.
  미리보기는 진행 중인 층, 최고 층, 재화와 난수를 바꾸지 않는다. 보고 있던 층이 실제 진행 층이면 다음 층 돌파도 따라가고, 다른 층을 살펴보는 중에는 선택을 유지한다.
- 마지막 완료 층에서 실제 늘어난 재료만 `labyrinthLastResult`에 기록한다. 이 기록은 저장·복원 후 표시만 하며 보상을 다시 지급하지 않는다. 루프 전환 시 비운다.
  화석과 봉인편린의 획득 확률·해금 조건, 장비 드롭, 미궁 난도는 유지한다.
- 미궁·창공·혼돈계·지하계는 이동 거절 사유를 확인한 뒤 층을 바꾼다. 미궁은 최고 개방 층 밖의 입력을 거절한다.
  층 선택창을 띄운 사이 저장 객체·루프·지역이 바뀌면 이전 입장 요청을 취소하고, 확인 시에도 현재 입장 조건을 다시 검사한다.
- 휴대폰의 미궁 준비 화면에서는 작은 전투 화면을 처음에 접는다. 펼치더라도 마지막 입장·층 선택 버튼을 가리지 않도록 아래쪽 스크롤 여백을 둔다.
- 혼돈의 뿌리 권역을 고를 때는 현재 열린 콘텐츠만 나열한다. 개별 미궁·혼돈계 화면의 위쪽 띠에는 `최고 입장 N층`,
  혼돈 심화에는 `이번 루프 심화 N층`을 표시한다. 미궁 화면에서 미해금 혼돈계의 0층 기록은 표시하지 않는다.
- 미궁 화면에 추가한 문구: `입장 가능 1 ~ N층`, `확률 전리품`, `화석`, `복원용 화석`, `부적 재료`, `전용 고유`,
  `N층 돌파 보상`, `추가 재료 없음`, `최고 N층`, `살펴보기`, `화석 제작 미해금`.
  화석·편린·고유 이름은 기존 이름이며, 구체적인 획득 판정은 기존 데이터와 함수를 사용한다.
  범위 밖 입장에는 기존 다른 층 콘텐츠와 같은 `1~N 범위의 층수를 입력하세요.`를 쓴다.
- 검증: 전체 스모크 20/20, 구조 검사·CSS 검사·배포 빌드 통과. 수정 전 실패하던 입장 거절·열리지 않은 층·비정수 입력을
  작업 중 비교 검사로 확인했고, 완료 재료 기록의 저장·복원에서 재지급이 없음을 확인했다.
  실제 게임을 브라우저의 390×844·1440×900 뷰포트에서 열어 층 미리보기·입장·취소와 작은 전투 화면 펼침 상태를 확인했다.
  휴대폰 하드웨어·터치와 장기 밸런스는 이번 검증 범위에 포함하지 않는다. 검수 자료는 `artifacts/content-pass-20261026/`에 있다.

## 특수 맵과 원정 (2026-10-23)

군락지·운석·대균열·벌집은 현재 옆에서 보는 방 단위 전투를 사용한다. 적의 근접·사격 역할, 예고 범위와
상태이상 취소는 공용 적 공격 규칙을 따르며, 기존 전투 전술과 자동 이동으로 진행한다.
기존 전용 배경과 이동·공격 그림을 사용한다. 별도의 조작을 요구하는 미니게임은 추가하지 않았다.

- **군락지 방어전**: 33×13칸의 큰 방 하나에서 군락 핵을 지킨다. 세 진입로에서 나온 적은 핵을 향해 이동하고,
  실제 공격 사거리 안에서 핵을 공격한다. 핵 내구도가 0이면 실패·귀환하며 이미 주운 보상은 유지한다.
  웨이브를 돌파할 때 최대 내구도의 10%를 수리한다. 새 도전은 내구도를 채우고 1웨이브부터 시작한다.
  돌격 → 독침 사격 → 갑각 호위 → 혼합 → 지배체의 다섯 웨이브가 반복된다. 한 웨이브는
  12마리부터 웨이브마다 2마리씩 늘어나 최대 36마리다(2026-10-23 사용자 결정으로 예전 수). 진행 중인 저장의 처치 목표는 그대로 이어 받는다.
  편린·이슬과 10웨이브마다 흔적을 얻는 경로는 유지한다. 5웨이브마다 확정 액막이는 일반 옵션의 굴림 바닥이
  25%부터 시작해 지배체마다 10%p씩 올라 최대 75%가 된다. 옵션의 원래 최대치와 고유 액막이의 확률·범위는 유지한다.
  예를 들어 생명력 40~120 옵션의 5웨이브 최소값은 60, 30웨이브부터는 100이다.
  지배체 확정 액막이는 필터·자동분해·가방 용량 때문에 사라지지 않는다. 다른 웨이브의 28% 추첨과 편린 제작은 원래 범위를 쓴다.
  몬스터 드랍과 웨이브 보상은 보관했다가 5웨이브마다 지배체가 죽은 자리 주변에 한꺼번에 떨어뜨린다.
  지배체가 먼저 죽으면 즉시 방출하고, 남은 호위의 드랍과 웨이브 보상도 그 자리에서 방출한다.
  웨이브가 끝나도 바닥 전리품이 남아 있으면 다음 무리를 소환하지 않는다.
- **운석**: 외곽 무리 → 정예 사격 → 운석 핵의 순서로 돌파한다. 충전 중의 최저 단계로 난도가 고정되고,
  20단계부터 핵과 함께 정예 호위가 등장한다. 핵은 생명력 절반 이하에서 파쇄 강타에서 핵 폭주(연속 참격, 파쇄 강타, 격앙 순환,
  특수기 뒤 숨 고르기는 보통의 절반)로 바뀌며,
  이미 시작한 예고·예약 타격이 끝난 뒤 전환한다.
  20단계부터 희귀 이상 장비가 2개, 40단계부터 3개로 늘어난다(그 전은 1개). 이 정산 장비도 가방 초과 보관과
  자동분해 보호를 받는다. 운석 전용 고유와 아틀라스 패시브의 별자리 관측은 기존 출현 조건을 따른다.
- **대균열**: 35×15칸의 큰 방 하나에서 여섯 균열로부터 밀려드는 몬스터를 처치해 게이지를 채운다.
  일반 몬스터는 0.5%, 정예는 3%씩 올라 100%가 되면 증원이 멈추고 같은 전장에 군주가 한 번 소환된다. 군주를 부르기 전 쇄도는
  5분까지(`GRAND_BREACH_ENCOUNTER.survivalLimitSeconds`, 2026-10-23 사용자 결정)이고, 넘기면 패배처럼 실패한다(죽음으로 세지 않음).
  군주가 나온 뒤에는 시간 제한이 없다.
  기본 21×9칸 방의 약 2.8배 면적이며 가로·세로 카메라가 캐릭터를 따라간다. 처치 수가 군주의 압박과 격파 보상을 함께 올린다.
  첫 무리는 24기이며 0.9초마다 최대 10기씩 보충한다. 동시 출현 상한은 게이지 33.5% 미만 30기, 33.5~66.5% 36기, 67% 이상 40기다.
  10처치마다 압박이 하나씩 올라 최대 6단계다(단계당 군주 생명력 +6%, 피해 +5%, 관통 +2).
  군주 격파 시 공허의 끌은 2개부터 10처치마다 +1개, 주얼 결정은 15처치마다 +1개로 최대 3개다.
  처치 없이 기다리면 게이지는 오르지 않는다. 게이지는 정수 200점(일반 1점·정예 6점)으로 저장하고 처치 수는 별도 기록한다.
  기존 처치식 저장은 당시 1처치=1%의 진행률을 이어받고 이전 타이머는 제거한다.
  몬스터 전리품과 군주 보상은 군주 처치 때 같은 자리 주변에 한꺼번에 떨어진다. 바닥을 모두 수거한 뒤 귀환한다.
  이미 소환된 군주와 기존 완료 보상 기록은 유지한다. 제작 재화는 해당 기능 해금 조건을 지킨다.
- **벌집**: 열 번의 선택으로 전투와 보상을 이어 간 뒤 여왕과 싸운다. 돌격벌·정찰벌·유모벌·근위벌의 역할이
  구분되고, 선택한 군체 강화가 여왕의 난도와 정산에 반영된다. 이미 지급된 보상과 여왕 처치까지 보류된 보상은 따로 표시한다.
  여왕은 밀랍 1개와 독벌침 1개를 기본 지급하고, 군체 강화 6마다 밀랍 +1개, 10마다 독벌침 +1개다(정산 강화 최대 30).

대균열·군락지의 보관 전리품은 `grandRun.pendingLoot`·`colony.pendingLoot`에 실제 추첨 결과를 저장한다.
장비·주얼·코어·부적·룬·실타래·재화를 지급하거나 자동 해체하기 전에 보관하며, 경험치는 처치 때 받는다.
같은 도전을 저장 후 불러오면 보관·바닥 전리품과 수거 대기를 이어받는다. 포기·다른 맵 이동·실패·루프 전환 시
보관 중이거나 바닥에 남은 전리품은 폐기하며, 이미 수령한 보상은 회수하지 않는다.
원정 바닥 전리품의 수거 대기에는 시간 제한이 없다. 자동 이동을 꺼도 바닥이 비기 전 자동 진행하지 않는다.

입장 차단은 비용 지불 전에 검사한다. 처치 보상은 기존 완료 처리에서 한 번 지급되며, 철수·패배·루프 전환은
기존 원정 종료 경로를 따른다. 난도와 보상량은 플레이테스트 조정값이며 장기 경제·재미가 검증됐다는 뜻은 아니다.
소유: `js/state.js` 지역 정의, `data/bosses.js` 적 풀, `js/combat.js` 전투·완료, `js/colony-wards.js` 액막이,
`js/passives.js` 운석 보상, `js/side-encounter-ui.js` 진행·위험·보상 표시.
특수 맵 크기와 핵·균열 좌표는 `data/stage-room-plans.js`, 지형 조립은 `js/act-exploration-rooms.js`가 소유한다.
미니맵은 실제 방의 비율과 핵·진입로·균열 위치를 표시하고 누른 위치로 이동한다. 핵 칸은 이동할 수 없다.
이 변경 전에 저장된 진행 중 방 사슬은 해당 도전이 끝날 때까지 이어 받고 새 입장부터 단일 맵을 사용한다.

## 뜨개질과 콘텐츠 고유 장비 (2026-10-22)

뜨개질은 장비 제련을 연 상태에서 **루프 40**에 무료로 자동 해금된다. 액트 진행 조건은 없고 해금 포인트도 쓰지 않으며,
장비 창의 **실타래 보관함**으로 들어간다. 루프 40은 후반 34~45 구간에서 두 루프가 이어서 비는 유일한 자리(40~41)다.

해금 루프는 `hardMinLoop`로 고정한다. 이전 저장에 구매·상속·자동·레거시 해금 기록이 남아 있어도 루프 40 전에는
보관함·드롭·교환이 모두 닫힌다. 기록은 지우지 않으므로 루프 40이 되면 그대로 열린다. 닫혀 있는 동안에도 발견·교환
기록과 같은 루프의 보유 수량은 보관하며, 저장 경계에서 정산되는 바닥의 실타래는 수령된다.

한 번이라도 주운 종류만 이름·요구 수량·결과·발견 장소를 표시한다. 보유 0개가 되어도 기록은 남고, 못 본 종류의 자리나
전체 종류 수는 보여 주지 않는다. 루프가 바뀌면 보유 수량과 루프당 한 번 상한 표시를 초기화하고 발견·뜨개질 횟수는 보존한다.
기존 기억의 잎과 그 보유량은 별개로 유지한다.

드롭에 보장은 없다. 처치마다 등급별 확률(`KNITTING.chance`: 일반 0.4%, 정예 3%, 콘텐츠 보스 15%, 액트 보스 20%)로
한 조각이 나올 수 있고, 나오는 종류는 가치 가중치로 굴린다. 첫 세트 학습 보장과 액트 10 `끝자락`의 확정 지급은 없으며,
`끝자락`에는 루프당 최대 한 번이라는 상한만 있다. 해금 전에는 처치가 첫 확인에서 끝나 추첨 비용이 없다.
드롭·가중치·보상 계약은 [엔드게임 드랍](endgame-loot-20261009.md#뜨개질-현재-계약-2026-10-22)을 본다.

새 콘텐츠 귀속 고유 11종은 `data/items.js`의 `contentUnlock`과 `dropOnly`가 출현 조건이다.
미궁·전직 시련·운석·벌집·대균열·심해·군락지·창공의 탑·경계 너머에 분산했다.
해금 전에는 해당 고유를 만들지 않으며, 해금 후에도 다른 콘텐츠의 일반 풀이나 상점 풀로 섞지 않는다.
해당 장소의 층·드롭 등급 조건도 함께 적용한다. 특정 고유 강제 생성과 뜨개질의 고유 풀도
`contentProgression.canDropUnique`를 거친다. 보유한 기존 장비를 삭제하는 제한은 아니다.

드롭 요구 등급(`dropOnly.minTier`)과 장비 자체 등급은 별개다. 군락지·창공·경계 너머의 새 고유는
실제 드롭 상한 15에서 나올 수 있고, 장착 요구와 고유 성능은 유지한다. 도전자의 증표는 2차 시련부터,
미궁 수문장의 관과 층계참의 반지는 각각 5층·10층부터 나온다. 두 미궁 고유는 일반 베이스를 사용해
10층·30층 전용 베이스를 먼저 지급하지 않는다. 해구 작살은 메아리 창 베이스로 만든다.

## NPC 해금과 일반 해금 (2026-10-21)

NPC가 무료로 열어 주던 즉시 해금이 유료 해금 18개 가운데 17개를 맡아 해금 포인트가 쓰이지 않고 쌓였다(루프 3에 6점, 루프 5에 12점).
사용자 결정: NPC와 어울리는 초기 해금 몇 개만 NPC 해금으로 나누고, 나머지는 해금 탭에서만 포인트로 산다. 포인트 양도 다시 맞춘다.

- **NPC 해금**(카탈로그 `npc`, `cost` 0): 오르가 장비 제련, 화석 제작, 화석 복원 / 하켄 룬 연구 / 베른 고유 도감 / 이벨 고급 홀씨.
  그 NPC를 만난 뒤(`npcMet`, 해금 조건 줄 "오르가 조우") 그 NPC 창의 즉시 해금에서만 포인트 없이 연다(`contentProgression.gift`).
  해금 탭은 연결도에 NPC 얼굴을 달아 보여 주고, 단추는 그 NPC 창을 연다. 해금 탭에서 포인트로 사지 않는다.
- **일반 해금**(23점): 해금 탭에서만 포인트로 산다(`purchase`). NPC 창에는 나오지 않는다.
- 목표 안내는 살 수 있는 일반 해금이 없을 때 받을 수 있는 NPC 해금을 가리킨다(기록 → NPC).

## 전투 전술 통합 (2026-10-16)

전투 전술은 **액트 3 클리어 시 무료로 자동 해금**된다. 루프 2 도달, 장비 제련, 해금 포인트를 요구하지 않는다.
한 번 해금하면 다음 루프에도 유지되며 해금 목록의 진행 이정표에 표시된다.
**스킬 젬 → 전술 규칙**에서 기본 공격 대상·전투 거리와 조건부 행동을 함께 관리하며, 설정 화면에는 두지 않는다.
조건이 맞으면 대상·거리 각각 위에서 먼저 일치한 규칙이 기본값을 덮어쓴다. 맞는 규칙이 없으면 기본 전술을 쓴다.
생명력·보호막·적 수·보스 조건과 가까운 적·자동 거리의 기본 행동은 전투 전술과 함께 열린다.
고급 조건·행동의 단계별 해금은 유지한다.
기존에 전술을 해금한 저장은 이어 쓴다. 임시 유료 버전에서 지불한 전술 해금 비용은 복원 시 환급한다.
기본 대상·거리, 기존 규칙과 우선순위, 사용 여부도 보존한다. 액트 3 완료 기록이 있는 저장에도 자동 적용한다.
규칙의 저장 필드는 `skillAutoRules`, 기본 전술은 기존 `settings.combatTargetPriority`·`combatPositionMode`를 유지한다.

## 역할과 단계

- **성장 수단**: 루프 조건과 선행 선택, 필요한 발견 조건을 만족한 뒤 직접 구매한다.
- **전투 콘텐츠**: 기본적으로 루프·세계 진행 조건에 따라 자동으로 열린다. 전직 시련은 예외로 유료 전직 해금을 함께 요구한다.
- **편의·기록**: 진행에 맞춰 자동으로 제공한다.
- 새로 열린 기능 안의 제작·투자에는 기존 재료와 포인트를 사용한다. 기능 해금은 일회성이다.

첫 노드는 **장비 제련 하나**다. 루프 2에 오르가에게서 포인트 없이 받으면 기능과 마법의 새싹 1개를 얻고,
장비 심화·젬·대응·영구 성장 갈래가 열린다. 나머지 갈래는 장비 제련을 선행으로 요구한다.

노멀 장비가 없으면 사냥에서 획득하라는 안내를 제공하고, 재료는 그대로 보관한다.

  내부 능력치 투자는 기존 `loopDeepPoints`를 사용한다.
- 두 포인트는 기능이 잠겨 있어도 기존 보상 규칙으로 누적된다.
- 잠금 상태에서는 투자 UI와 투자 함수 모두 사용을 막는다.
- 심화 혼돈 전투와 등반 보상은 심화 패시브 선택 여부와 무관하다.

## 소유 구조

| 파일 | 책임 |
| --- | --- |
| `data/content-progression.js` | 성장 선택과 자동 기능, 비용·선행·진행·메뉴·유지/초기화 설명 |
| `js/state.js` | 새 게임 원장, 심화 투자 진입 조건 |
| `js/content-progression.js` | 잔액, 조건, 구매, 접근, 저장 원장 복원 |
| `js/save-migrations.js` | 이전 저장과 새 저장을 구분하는 복원 경계 |
| `js/content-progression-ui.js` | 성장 연결도, 이정표, 선택 상세, 클릭·알림·메뉴 표시 |
| `css/content-progression.css` | 기존 금색 테마를 쓰는 해금 화면과 잠긴 영역 |
| `js/ui.js` | 기존 루프 패시브 투자와 심화 강화 화면 연결 |

콘텐츠 잔액은 `min(남은 유료 기능의 비용 합계, max(0, earnedBy(max(최고 도달 루프, 현재 루프)) + carry - 유료 기능에 낸 비용 합계))`다.
남은 기능을 모두 해금할 만큼 모이면 지급을 멈추고, 넘는 몫은 그루터기 함 접붙이기 점수가 된다(`overflow`).
아직 루프·선행 조건을 충족하지 못한 유료 기능도 남은 비용에 포함하며, NPC 해금과 자동 콘텐츠는 제외한다.
모든 유료 기능이 열렸으면 잔액은 0이고 화면은 **전체 해금 완료**로 표시한다. 루프·심화 패시브 포인트에는 영향이 없다.
화면 갱신 때 포인트를 더하지 않으므로 같은 루프에서 중복 지급되지 않는다.

정의 필드:
- `cost:1/2`: 해금 탭에서 사는 일회성 성장 선택. `cost:0`: `npc`가 있으면 그 NPC가 주는 NPC 해금, 없으면 자동 기능.
- `npc`: NPC 해금을 주는 NPC(`STORY_NPCS` id).
- `minLoop`: 최초 조건. `after`: 유료 성장 가지의 부모.
- `branchStart`: 공통 제련 노드 이후 분야별 연결도를 시작하는 표시. 선행 조건을 우회하지 않는다.
- `requires`: 추가 필수 선행 조건. 자동 기능도 `after`로 연결된 성장 해금을 요구할 수 있다(거래소·장비 전당·전직 시련).
- `progress`: 기존 세계 진행 판정 키. 판정은 상태를 읽기만 한다.
- `routes` / `sections`: 메뉴 또는 일부 UI 영역.
- `gate` / `flags`: 기존 기능 플래그.
- `action`: 해금 후 바로 이동할 기존 메뉴·섹션.
- `rewardChoices` / `rewardText`: 기존 첫 선택 보상.
- `art`: 기존 이미지 자산. 없으면 같은 성장 가지의 이미지를 사용한다.
- `lifecycle`: 기능 안에서 유지되는 성장과 루프마다 초기화되는 항목. 기능 해금 자체는 모두 유지한다.
- `features`: 따로 구매하지 않는 내부 기능의 설명. 군주의 핵·창공의 정수·응축 창공은 젬 강화에 포함한다.

새 전역이나 스크립트를 추가하지 않으며 로드 순서는 유지한다.
카탈로그 변경 시 조건, 원장 복원, 메뉴 소비자를 함께 확인한다.

## 저장 호환성

원장 v9는 `version, highestLoop, legacy, carry, unlocked, paidCosts, inherited, automatic, grandfathered`를 저장한다.

- v9(2026-10-21): v8 이전 저장은 이전 표(루프 2~5에 4, 4, 3, 3점)로 받은 포인트가 지금 표보다 많은 몫을 처음 불러올 때 `carry`로
  고정해 받는다(최고 도달 루프 기준, 최대 7). 그래서 산 해금이 예산 검사로 빠지지 않고 접붙이기 점수(넘친 포인트)도 줄지 않는다.
  NPC 해금에 낸 포인트는 돌려주고, NPC에게서 무료로 받은 일반 해금(`paidCosts` 0)은 그대로 둔다.

- 원장이 없는 이전 저장은 기존 접근을 `inherited`로 보존한다. 이관은 무료다.
- v1–v4에서 이미 구매한 항목은 새 선행/최소 루프를 소급 적용하지 않는다.
  해당 ID를 `grandfathered`에 남기고, 현재 유료 항목은 기존 구매로 계산한다.
- v3에서 보조 젬과 루프 진행으로 무료 제공되던 연구·각인은 접근을 유지한다.
- 기존 루프 10 이상 저장의 심화 패시브 접근은 무료로 보존한다.
- 새로 자동화된 전투 콘텐츠의 과거 구매 비용은 현재 잔액 계산에서 반환한다.
- 새 구매 기록은 순서, 중복/알 수 없는 ID, 예산, 최소 루프와 선행 조건을 검사한다.
- v6 이전의 1P 구매는 기존 가격으로 보존한다. `paidCosts`에 실제 비용을 남겨 소급 청구하지 않는다.
- v7 이전의 젬 강화 소유자는 분리된 각인을 무료로 상속한다.
- 대응 갈래(컨디션 젬 · 생명력/특수 플라스크)는 보조 콘텐츠 통합에서 없어졌다(docs/aux-consolidation-20260930.md).
  쓴 포인트는 불러올 때 돌아온다.
- 전문가 · 가지치기 · 아르카나(각 2점)도 통합 7단계에서 없어졌다. 쓴 포인트는 불러올 때 돌아오고, 전문가 레벨로 이미 쓰던
  기능은 새 항목을 무료로 상속한다(균사학자 Lv.4 → 화석 복원, Lv.7 → 고급 홀씨, 젬 각인사 Lv.12 → 젬 각성).
- 이전 원장에서 성장 기능을 이미 해금한 플레이어는 새 공통 제련 노드를 무료로 상속한다.
  이전 선택을 막거나 추가 포인트를 청구하지 않으며, 마법의 새싹 보상은 이관 때 재지급하지 않는다.
- 기존 플레이어도 남은 해금 비용을 잔액 상한으로 적용한다. 상속 기능을 재청구하지 않으며, 장비·젬·재료·투자·실제 구매 기록은 보존한다.
- v3 이전 컨디션 젬 해금 저장의 긴급 회피 보완은 한 번만 적용한다.

첫 보조 젬·제련 재료 보상은 구매 트랜잭션에서만 지급한다. 제거된 컨디션 젬 보상은 현재 구매 대상이 아니다.
보물사냥은 2026-09-25에 삭제했다. 저장에 남은 진행·예약 보물은 불러올 때 지급 없이 버린다(`js/save-migrations.js`).
관련 재화·장비 드랍은 `contentProgression.canDropCurrency`와 해당 도메인의 해금 검사를 따른다.
전투 진입에 필요한 공유 열쇠와 발견 선행 재화는 유료 성장 해금 때문에 순환 잠금이 생기지 않도록 분리한다.
사용자 화면을 확인하려고 저장을 초기화하거나 루프를 강제로 올리지 않는다.
이전 저장과 신규 저장의 접근 항목 차이는 위 호환 정책 때문이다.

## 이동 스킬과 보스 회피

옛 긴급 회피 컨디션 젬은 이동 스킬 칸으로 통합됐다. 장착한 유효 이동 젬과 재사용 대기·행동 조건을
`js/mobility-skill.js`가 검사한다. 보스 예고가 현재 칸에 걸린 채 플레이어가 이동 스킬 키나 HUD 칸을 누르면
최대 3칸의 유효 탈출 경로를 찾는다. 누르지 않으면 피하지 않는다(2026-10-07: 저절로 피하니 보스 패턴이 의미가 없었다).
닿는 적이 없어도 예고가 걸려 있으면 누를 수 있다.
동결·기절·속박 또는 탈출로 부재로 실패하면 회피 재사용 대기를 쓰지 않는다. 무적은 추가하지 않는다.
수동 요청과 자동 접근도 같은 이동 젬을 사용하며 실제 타격·이동 판정은 기존 전투 코드가 소유한다.

기능 검사는 선택의 재미를 입증하지 않는다. 1/2점 가격과 선행 깊이, 후기 선택 시점은
실제 플레이테스트에서 첫 선택 분포·선택 보류율·진행 정체를 보고 조정한다.
