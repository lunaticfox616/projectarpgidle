# 콘텐츠 선택 해금 — 현재 적용 정책 (원장 v7)

새 게임의 루프 1은 캐릭터, 기본 스킬 트리, 장비 장착, 공격 스킬 젬을 중심으로 시작한다.
설정·커뮤니티·전적은 편의 기능이다. 생명력 플라스크는 직접 해금한 뒤 작동하며 슬롯도 그때 나타난다.
루프 2부터 매 루프 해금 포인트 2점을 얻는다. 작은 성장 기능은 1점, 큰 성장 기능은 2점이며,
미사용 포인트와 선택은 다음 루프 및 저장·복원 후에도 유지된다.

## 역할과 단계

- **성장 수단**: 루프 조건과 선행 선택, 필요한 발견 조건을 만족한 뒤 직접 구매한다.
- **전투 콘텐츠**: 기존 세계 진행 조건에 따라 자동으로 열린다. 유료 성장 선택을 요구하지 않는다.
- **편의·기록**: 진행에 맞춰 자동으로 제공한다.
- 새로 열린 기능 안의 제작·투자에는 기존 재료와 포인트를 사용한다. 기능 해금은 일회성이다.

첫 노드는 **장비 제련 하나**다. 루프 2에서 1P를 사용하면 기능과 마법의 새싹 1개를 얻고,
장비 심화·젬·대응·영구 성장 갈래가 열린다. 나머지 갈래는 장비 제련을 선행으로 요구한다.
남은 1P로 생명력 플라스크를 열거나 다음 루프까지 모을 수 있다. 실제 제련 완료나 노멀 장비 보유를 진행 조건으로 두지 않는다.
노멀 장비가 없으면 사냥에서 획득하라는 안내를 제공하고, 재료는 그대로 보관한다.
첫 재료를 다른 재료로 고르는 선택과 결과 되돌리기 등 별도 제련 규칙은 추가하지 않는다.
다음 표의 루프는 최소 루프 조건이며 자동 지급 시점이 아니다. 선행 선택과 포인트도 필요하므로
2P 기능인 보조 젬·컨디션 젬·루프 패시브는 새 게임에서 가장 빨라도 루프 3에 선택한다.

| 분야 | 선행 선택 → 후속 선택 (최소 루프) |
| --- | --- |
| 젬 | 보조 젬(2) → 젬 연구(3) → 젬 강화(4) → 젬 각인(4) |
| 대응 | 제련 → 컨디션 젬(2), 생명력 플라스크(2) → 특수 플라스크(3) |
| 장비 | 장비 제련(2) → 화석 제작(3), 전문가(4), 고유 도감(5) |
| 장비 심화 | 화석 제작 → 주얼(5), 혼돈 주입기(10·나무꾼 조우/기록) |
| 장비 구성 | 주얼 → 부적(6) → 코어 큐브(20·지하계 10층 클리어), 생장판(25) |
| 영구 성장 | 루프 패시브(2) → 직업 전직(3), 심화 패시브(10) |
| 직업 성장 | 직업 전직 → 별쐐기(7·액트 7 도달), 재능(10·재능 개화) |
| 후기 영구 성장 | 심화 패시브 → 가지치기(18) → 아르카나(20·카드 발견) |

선행 관계는 카탈로그의 `after`가 단일 출처다. 화면의 단계 열은 깊이를 나타내며,
정확한 선행 항목과 발견 조건은 오른쪽 상세에서 확인한다.
기존 저장의 이미 열린 기능은 아래 호환 정책에 따라 유지한다.

## 자동 전투 개방과 루프 이정표

| 최소 루프 | 콘텐츠 / 추가 조건 |
| --- | --- |
| 1 | 전직 시련: 액트 3 도달. 지도 메뉴는 루프 2부터 제공 |
| 2 | 보물사냥: 보스 10회 처치마다 보물 탐색 |
| 3 | 고대 미궁, 대전 |
| 7 | 운석 낙하 지점: 액트 7 도달 |
| 8 / 9 | 벌집 원정 / 공허 균열 |
| 10 | 심화 혼돈: 현재 루프 혼돈 20층 클리어 |
| 10 이상 | 혼돈계·지하계·우주계: 각 콘텐츠의 기존 세계 진행 조건 필요 |
| 11 | 심해, 낚시 |
| 13 | 시간의 균열 |
| 15 | 군락지, 창공(기존 입장 조건 적용) |
| 50 | 경계 너머: 경계의 관측자 처치 조건 |

전직 시련 입장과 전직 패시브 투자는 분리한다.
운석 조사와 별쐐기 성장 기능도 분리한다.
혼돈계·지하계·우주계를 루프 10만으로 바로 열지는 않는다.
조건 판단은 기존 도메인의 판정 함수 또는 정규화된 진행 기록을 읽는다.

편의 기능: 거래소·장비 전당은 루프 2부터 장비 제련(1P)을 해금하면 추가 비용 없이 함께 열린다.
저널은 루프 2, 전적은 루프 1에 열린다. 기존 저장에서 이미 열린 거래소·장비 전당 접근은 유지한다.
특수 서비스의 주얼·생장 보관함 확장은 해당 성장 기능의 실제 해금을 요구하며, 확장한 칸은 루프가 바뀌어도 유지된다.
자동 개방 기록은 원장의 `automatic`에 유지한다. 메뉴가 유지돼도 실제 입장·보상 조건은
각 전투 도메인이 계속 검사한다.

루프 이정표는 선택 화면의 **진행 · 이정표**로 통합한다.
각 루프에 필요한 진행 조건, 자동 개방, 성장 선택 후보를 함께 보여준다.
현재 및 다음 네 루프를 기본으로 표시하고 전체 1–50 이정표를 펼칠 수 있다.
루프 도달, 개별 조건 달성, 선택 가능, 해금 완료를 구분한다.
기존 이정표의 심화 전투·생장판 확장 등 추가 단계 설명도 함께 유지한다.

## 루프 패시브와 심화 패시브

- 루프 패시브는 루프 2 이상과 제련 해금이 조건이다. 새 게임에서는 루프 3부터 선택 가능하다.
  내부 노드 투자는 기존 `seasonPoints`를 사용한다.
- 심화 패시브는 루프 10 이상과 루프 패시브 해금 이후 선택한다.
  내부 능력치 투자는 기존 `loopDeepPoints`를 사용한다.
- 두 포인트는 기능이 잠겨 있어도 기존 보상 규칙으로 누적된다.
- 잠금 상태에서는 투자 UI와 투자 함수 모두 사용을 막는다.
- 심화 혼돈 전투와 등반 보상은 심화 패시브 선택 여부와 무관하다.

## 소유 구조

| 파일 | 책임 |
| --- | --- |
| `data/content-progression.js` | 성장 선택과 자동 기능, 비용·선행·진행·메뉴·유지/초기화 설명 |
| `js/state.js` | 새 게임 원장, 심화 투자 진입 조건 |
| `js/content-progression.js` | 잔액, 조건, 구매, 접근, 저장 원장 복원 |
| `js/save-migrations.js` | 이전 저장과 새 저장을 구분하는 복원 경계 |
| `js/content-progression-ui.js` | 성장 연결도, 이정표, 선택 상세, 클릭·알림·메뉴 표시 |
| `css/content-progression.css` | 기존 금색 테마를 쓰는 해금 화면과 잠긴 영역 |
| `js/ui.js` | 기존 루프 패시브 투자와 심화 강화 화면 연결 |

콘텐츠 잔액은 `(max(최고 도달 루프, 현재 루프) - 1) × 2 - 실제 구매 비용 합계`다.
화면 갱신 때 포인트를 더하지 않으므로 같은 루프에서 중복 지급되지 않는다.

정의 필드:
- `cost:1/2`: 일회성 성장 선택. `cost:0`: 자동 기능.
- `minLoop`: 최초 조건. `after`: 유료 성장 가지의 부모.
- `branchStart`: 공통 제련 노드 이후 분야별 연결도를 시작하는 표시. 선행 조건을 우회하지 않는다.
- `requires`: 추가 필수 선행 조건. 자동 전투에는 유료 선행을 두지 않는다.
- `progress`: 기존 세계 진행 판정 키. 판정은 상태를 읽기만 한다.
- `routes` / `sections`: 메뉴 또는 일부 UI 영역.
- `gate` / `flags`: 기존 기능 플래그.
- `action`: 해금 후 바로 이동할 기존 메뉴·섹션.
- `rewardChoices` / `rewardText`: 기존 첫 선택 보상.
- `art`: 기존 이미지 자산. 없으면 같은 성장 가지의 이미지를 사용한다.
- `lifecycle`: 기능 안에서 유지되는 성장과 루프마다 초기화되는 항목. 기능 해금 자체는 모두 유지한다.
- `features`: 따로 구매하지 않는 내부 기능의 설명. 군주의 핵·창공의 힘·응축 창공은 젬 강화에 포함한다.

새 전역이나 스크립트를 추가하지 않으며 로드 순서는 유지한다.
카탈로그 변경 시 조건, 원장 복원, 메뉴 소비자를 함께 확인한다.

## 저장 호환성

원장 v7은 `version, highestLoop, legacy, unlocked, paidCosts, inherited, automatic, grandfathered`를 저장한다.

- 원장이 없는 이전 저장은 기존 접근을 `inherited`로 보존한다. 이관은 무료다.
- v1–v4에서 이미 구매한 항목은 새 선행/최소 루프를 소급 적용하지 않는다.
  해당 ID를 `grandfathered`에 남기고, 현재 유료 항목은 기존 구매로 계산한다.
- v3에서 보조 젬과 루프 진행으로 무료 제공되던 연구·각인은 접근을 유지한다.
- 기존 루프 10 이상 저장의 심화 패시브 접근은 무료로 보존한다.
- 새로 자동화된 전투 콘텐츠의 과거 구매 비용은 현재 잔액 계산에서 반환한다.
- 새 구매 기록은 순서, 중복/알 수 없는 ID, 예산, 최소 루프와 선행 조건을 검사한다.
- v6 이전의 1P 구매는 기존 가격으로 보존한다. `paidCosts`에 실제 비용을 남겨 소급 청구하지 않는다.
- v7 이전의 젬 강화·플라스크 소유자는 분리된 각인·특수 플라스크를 무료로 상속한다.
- 이전 원장에서 성장 기능을 이미 해금한 플레이어는 새 공통 제련 노드를 무료로 상속한다.
  이전 선택을 막거나 추가 포인트를 청구하지 않으며, 마법의 새싹 보상은 이관 때 재지급하지 않는다.
- 포인트와 장비·젬·재료·투자 기록을 삭제하지 않는다.
- v3 이전 컨디션 젬 해금 저장의 긴급 회피 보완은 한 번만 적용한다.

첫 보조 젬·컨디션 젬·재련 재료 보상은 구매 트랜잭션에서만 지급한다.
보물사냥은 보스 처치 누적을 사용하며 해금 보너스 보물을 만들지 않는다. 미수령 보물은 다음 루프 진행 전에 받는다.
관련 재화·장비 드랍은 `contentProgression.canDropCurrency`와 해당 도메인의 해금 검사를 따른다.
전투 진입에 필요한 공유 열쇠와 발견 선행 재화는 유료 성장 해금 때문에 순환 잠금이 생기지 않도록 분리한다.
사용자 화면을 확인하려고 저장을 초기화하거나 루프를 강제로 올리지 않는다.
이전 저장과 신규 저장의 접근 항목 차이는 위 호환 정책 때문이다.

## 보스 회피 계약 (유지)

보스 예고만으로 자동 이동하지 않는다. 긴급 회피 컨디션 젬의 활성 규칙이 충족되어야 이동한다.
최대 3칸, 기존 경로 탐색과 충돌 규칙, 군중 제어·재사용 대기·거리 조건을 유지한다.
무적을 추가하지 않으며 실패 시 재사용 대기를 소비하지 않는다.
규칙은 `js/condition-patterns.js`, 위험 칸은 `js/combat-patterns.js`,
이동과 시전은 `js/combat.js`가 소유한다.

## 검증

- `node scripts/smoke-content-progression.js`: 구매 실패의 상태 보존, 단계, 무료 전투,
  패시브 투자 제한, 저장 이관·환급·중복 지급 방지.
- `npx playwright test tests/browser/content-progression.spec.js tests/browser/loop-settlement.spec.js`:
  PC·모바일 실제 클릭, 재접속, 루프 전환, 자동 전투 이동, 패시브 투자, 이정표, 밝은/어두운 테마.
- `npm test`, `npm run check:architecture`.

기능 검사는 선택의 재미를 입증하지 않는다. 1/2점 가격과 선행 깊이, 후기 선택 시점은
실제 플레이테스트에서 첫 선택 분포·선택 보류율·진행 정체를 보고 조정한다.
