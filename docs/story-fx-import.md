# 제공된 저널·PixelLab 이펙트 적용

원본: `리그닌 저널.zip`, `world-tree-pixellab-mz-effects-45-v3.7.zip`.
압축 안의 RPG Maker 플러그인은 게임에 설치하지 않는다.
현재 게임의 Canvas와 실제 전투 이벤트에 제공된 그림 및 원본 배치·모션 규칙을 연결한다.
원본 시뮬레이터 코드는 검수용 비교 화면과 기준 좌표 추출에서만 실행한다.

## 저널

`data/story-journal.js`가 제공된 문구와 삽화 경로, 표시 시점을 소유한다.
프롤로그, 액트 2 완료, 3 시작, 4·5·6 완료, 7·8·9 시작, 9·10 완료의 11장이다.
액트 1 삽화는 제공되지 않아 기존 기록을 유지한다.

기존 알림 큐로 한 번씩 표시하고, 해금된 저널의 그림을 눌러 다시 볼 수 있다.
이전 저장은 현재까지 지난 장면을 새 알림으로 쏟아내지 않는다.
저널 ID·해금 조건·기존 보상은 유지한다. 방치 계산 중에는 그림 표시를 처리하지 않는다.
삽화는 필요할 때 로드하며, 모든 장면을 전투 에셋 선로딩에 넣지 않는다.

## 이펙트

`data/skill-fx-atlas.js`는 이름과 64×64 프레임 좌표를 매핑한다.
`js/canvas-world-tree-fx.js`는 확정된 이동 경로·공격 범위·시점만 읽어 그린다.
기존 43개 공격 젬에 적용하며, 기본 공격·소환수·적의 이펙트는 기존 표현을 유지한다.
판정 범위, 대미지, 쿨타임, 연타 횟수는 변경하지 않는다.
범위 이펙트는 적 수에 따라 복제하지 않는다. 지진은 시전자 칸을 제외한다.
눈보라는 범위 안에 최대 6개의 낙하를 표시한다. 전체 추가 이미지 그리기는 프레임당 48회로 제한한다.
사용자 요청으로 불투명도는 85%로 유지한다. 소멸은 원본 프레임을 따르며 임의의 추가 페이드는 넣지 않는다.
원본의 중간 지점 베기, 칸별 배치, 연쇄 연결, 눈보라 낙하, 포물선 투척과 귀환 경로를 재현한다.
한 장을 범위 사각형에 늘리는 대신 원본의 균일 배율을 사용하고, 카메라 투영만 적용한다.
범위 표현과 절반 크기 피격 표현을 분리하며 원본이 먼저 그리는 범위 표현을 우선한다.
사용자의 접촉 피드백 변경 요청에 따라 실제 플레이어 스킬 타격에서는 절반 크기 스킬 그림의
재생을 생략한다. 주 공격 이미지와 확정 타격의 대미지 숫자를 사용하며 원본 아트 자체는 유지한다.
예약 타격이 소유하는 일시적 `contactState.resolved`를 이동 표현이 읽어, 고정 전투 틱 사이에
투사체가 미확정 타격 지점을 지나 사라지지 않게 한다. 확정 시에는 히트 스톱 중에도 해당 지점까지
진행한다. 렌더러는 판정·피해를 만들지 않으며 빗나간 타격도 스케줄이 끝나면 이동을 계속한다.
이 상태는 저장하지 않는다. 기본 공격, 소환수, 피해량, 범위, 반복 횟수, 방치 계산은 유지한다.
플레이어의 직선 관통/이동 파동은 타격 시점을 유지하면서 중간 시각 좌표를 하나의 직선 위로 투영한다.
적의 칸 중심을 차례로 잇는 꺾임을 제거하며, 왕복·연쇄·포션 포물선은 각 스킬의 고유 궤적을 유지한다.
`projectilePattern.trajectory: 'stages'`는 기존 단계별 출발점·도착점 표현을 선택한다. 기본 관통은 직선이며,
연쇄·왕복·산탄 및 `combatPattern.stages`로 작성한 복합 공격은 자동으로 단계별 경로를 유지한다.
이 설정은 시각 경로만 선택한다. 새 튕김·관통 후 분기 공격의 판정과 피해 단계는 기존 전투 패턴에 정의해야 한다.
임의의 65ms 연타 지연과 중복된 기존 타격 장식은 제거했다.
실제 이벤트의 범위·시간을 사용하므로 원본 시뮬레이터의 예시 전투 스케줄을 게임 판정에 덮어쓰지 않는다.
전투 연결의 기본 분류·그룹 규칙은 원본의 선택적 `consumeBattleFx` 어댑터에서 가져왔다.
이 어댑터의 결과는 원본 갤러리의 실제 재생과 같지 않으므로 전체 스킬의 원본 재생 검증을 대신하지 않는다.
연속 베기는 실제 갤러리를 우선하여 시전자 준비 동작, 260ms 베기, 180ms 피격으로 수정했다.
준비 시간은 실제 시전 속도를 따르며 원본 기본 공격 속도 1.8에서 360ms다.
다른 스킬의 전체 재생 순서까지 갤러리와 동일한지는 아직 검증되지 않았다.
연발은 전체 공격 칸에서 방향별 끝점을 찾고,
직선 장판은 원본처럼 끝점으로 방향을 정한다. 같은 시전·단계의 반복은 주 효과 하나와 개별 피격으로 표시한다.
피격 좌표는 실제 적중 시점의 칸을 보존하고, 렌더가 늦어져도 원래 이벤트 시작 시간에서 재생한다.
집중 ID는 시전부터 피격까지 전달하며 중단/초기화 시 남은 표현을 취소한다. 전투 시계와 애니메이션 시계는 섞지 않는다.
추가 낙뢰·지연 폭발은 실제 추가 타격 후 원본 `confirmedPeriodic`의 180ms 장면을,
사망 시 지속 피해 이전은 `confirmedTransfer`의 220ms 이동을 표시한다. 원래 시전 스킬 출처를 보존한다.
기존 저장의 출처 정보 없는 추가 타격에는 현재 장착 젬의 그림을 임의로 붙이지 않는다.

새 아트 `탄성 플라스크`, `광창 강림`은 현재 게임에 공격 젬 정의가 없고
제공 자료에 대미지·쿨타임 값도 없어 체험 페이지의 아트 미리보기까지만 포함한다.
신규 젬의 게임 규칙은 별도 결정 후 연결한다.

## 파일·초기화

삽화: `assets/journal/`의 WebP 11개, 원본 1254×1254 유지, 합계 약 6.49MB.
이펙트: `assets/effects/world-tree-skills.webp`, 1024×1728 무손실, 약 127KB.
`scripts/import-story-fx-assets.py`는 로컬에 풀어둔 원본을 이 형태로 패키징한다.

데이터는 기존 maps/skills 뒤, 표현 모듈은 기존 tutorial/signatures 뒤에 로드한다.
`scripts/lib/game-runtime.js`의 테스트 로드 순서도 같다.
새 저장 필드를 추가하지 않고 기존 `seenTutorials`의 장면 키를 사용한다.

## 검증

- `node scripts/smoke-world-tree-native-motion.js`: 원본 코드에서 추출한 215개 이벤트·1,505개 시점의 위치, 크기, 회전, 프레임 좌표 및 불변 상태 비교. 기준 파일에 원본 SHA256을 기록한다.
- `node scripts/smoke-world-tree-combat-bridge.js`: 43개 실제 스킬 시전에서 나온 이동·피격을 원본 연결 함수에 넣은 결과와 비교한다. 적 한 마리에서의 5방향 발사, 집중 중단, 젬 교체 후 지연 효과 출처, 지속 피해 이전도 검증한다. 원본 함수 본문과 SHA256은 `scripts/fixtures/world-tree-v37-bridge.cjs`에 보존한다.
- 기존 visual-overhaul 검사에서 대체된 43개 스킬의 옛 절차형 렌더러만 직접 호출하던 검사는 위 원본 비교 및 실제 시전 검사로 대체했다. 기본 공격·소환수 등 나머지 검사는 유지한다.
- `node scripts/smoke-story-fx-import.js`: 새 게임/기존 저장/액트 경계/방치 복귀, 중복 보상 방지, 프레임 경계·그리기 상한.
- 기존 연속 베기·스킬 시전·범위·VFX 스모크: 새 그림과 기존 판정·진행 시점 연결.
- `npx playwright test tests/browser/story-fx-import.spec.js tests/browser/first-session.spec.js`: PC·모바일 새 게임, 실제 전투/첫 젬 장착, 삽화 다시 보기, 43개 매핑의 Canvas 렌더.
- `npm test`, `npm run check:architecture`.

체험 페이지: `/artifacts/story-fx/index.html` (실제 저장과 분리한 로컬 확인용).
동일 입력 원본 비교: `/artifacts/story-fx/native-compare.html` (검수용; 양쪽 불투명도 85%).
연속 베기 실제 갤러리 비교: `/artifacts/story-fx/slash-gallery-compare.html`.
이 비교 화면은 접촉 피드백 변경 전, 원본 갤러리와 실제 게임 시전을 같은 배치·공격 속도·85%
불투명도로 재생한 23개 시점의 RGBA가 일치했던 기록이다. 현재 게임에서는 요청에 따라 피격 복제 이미지를 생략한다.

현재 검사는 피격 복제를 제외한 준비·범위 표현을 비교한다. `smoke-skill-contact-feedback.js`는 실제 관통 시전의
타격 직전/확정/빗나감, 히트 스톱, 중복 피해 방지와 피격 이미지 재생 제거를 검증한다.
