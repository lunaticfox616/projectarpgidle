# 그루브 UI 자산 (나무·매듭 인터페이스)

상태: **자산 준비 완료, 게임 미반영.** 게임 CSS·JS는 아직 이 자산을 로드하지 않는다.
시안은 `artifacts/grove-ui/preview.html`(예시 데이터)에서 확인한다.

## 구성

| 원본 (`assets/ui/grove/source/`) | 용도 | 출력 |
| --- | --- | --- |
| `ui-kit-v1.png` 512×512 | 공통 UI 부품 시트 | 부품 9종 `*-v1.png` |
| `hp-orb-frame-v1.png` 384×384 | 둥근 HP 게이지 틀(가운데 투명) | `hp-orb-frame-v1.png` 768×768 |
| `stump-board-v1.png` 256×256 | 그루터기 함 5×5 판 | `stump-board-v1.png` 512×512 (칸 간격 통일) |

- 원본은 이진 알파, 19~25색의 1x 픽셀아트다. 출력은 **최근접 이웃 2배** 확대라서
  픽셀 경계가 유지된다. 부드러운 확대(AI·Lanczos)는 픽셀 전장과 어긋나 쓰지 않는다.
- 부품 시트에서 같은 모양이 여러 개(긴 판 3, 정사각 칸 4, 매듭 판 2, 작은 칸 2)인 것은
  손그림 변형이며 상태 이미지가 아니다. 대표 1개씩만 출력한다. 마우스 올림·누름·비활성은
  CSS 밝기·테두리로 표현한다.
- 좌표·크기·9-slice 값은 `assets/ui/grove/manifest.json`이 단일 출처다(@2x 픽셀 기준).

## 부품과 늘리기 규칙

| 부품 | 용도 | border-image-slice(@2x) |
| --- | --- | --- |
| `panel-large` | 대화 창·알림 카드·보스 이름판 | 88 — 안쪽 매듭 장식은 가운데와 함께 늘어난다 |
| `button-plate` | 주 버튼·메뉴 탭 | 24 |
| `tab-plate` | 넓은 버튼·하위 탭·목표 머리판 | 24 / 88 (좌우 매듭 유지) |
| `field-plate` | 검색창·선택 목록·라벨 | 20 / 28 |
| `icon-slot` | 창 버튼·작은 아이콘 칸 | 28 |
| `gauge-frame` | 경험치·진행도 게이지 | 18 / 184 (가운데 구간만 채움) |
| `slot-socket`, `label-knot`, `socket-round` | 젬 칸·장식 머리판·원형 버튼 | 고정 크기 |

`border-width`를 slice의 절반으로 두면 화면 1px = 원본 1px, 같게 두면 2배로 보인다.
확대 비율은 정수배만 쓰고 `image-rendering: pixelated`를 함께 둔다.

## HP 오브

틀 PNG의 투명 구멍은 `manifest.orb.hole`(x 118, y 120, 530×526, @2x)이다.
겹침 순서는 빈 배경 → 액체(`height: var(--hp)`, 아래에서 위로) → 에너지 보호막 → 틀 → 숫자다.
게임에 반영할 때는 기존 `#ui-hp-bar`의 `--gauge-fill`을 높이로 쓰면 체력 계산은 바뀌지 않는다.
에너지 보호막 표시(안쪽 파란 빛 / 안쪽 고리)는 시안에 두 안을 모두 두었고 아직 정하지 않았다.

## 그루터기 함 칸 간격 통일

원본은 칸 27~29px, 칸막이 3~4px라서 칸마다 간격이 30~32px로 달랐다. 격자 영역
151px을 `칸 5 × 27px + 칸막이 4 × 4px`로 다시 그려 **간격 31px(출력 62px)로 고정**했다.
바깥 틀과 칸막이의 놋쇠 음영은 원본 칸막이의 색을 같은 위치에서 가져와 유지한다.

출력 기준 격자: 시작점 (104, 106), 칸 54px, 칸막이 8px, 간격 62px. DOM 칸은 이 값으로
`display: grid; gap: 8px`를 두어 판 위에 겹친다. 모바일 폭에서는 전체를 같은 비율로 줄인다
(시안은 0.68배, 칸 약 37px). 손가락 터치 기준 44px에 못 미치므로 실제 화면에서는
칸 선택 후 확대 또는 판 크기 조정을 따로 정해야 한다.

기능 자체는 [그루터기 함 설계안](stump-cube-game-design.md) 기준 **미구현**이다.

## 재생성과 검사

```powershell
python scripts/process-grove-ui-assets.py   # Pillow 필요
node scripts/smoke-grove-ui-assets.js       # npm test에 포함
```

스모크는 출력 크기가 manifest와 같은지, 그루터기 함 25칸이 모두 같은 크기·같은 간격의
투명 칸인지, HP 오브 가운데가 비어 있는지를 실제 PNG 픽셀로 확인한다.
원본을 바꾸면 스크립트를 다시 실행하고 manifest 변경을 함께 커밋한다.
