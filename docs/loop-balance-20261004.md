# 루프 전투·장비 보상 조정 1차

작업본: `main-work-20261004`, 브랜치 `codex/main-work-20261004`.
사용자 요청: 루프별 난이도 상승을 고려하면서 재미를 반복 조정하고 DeepSeek와 협업한다.
현재 수치는 첫 플레이테스트용 조정이다. 자동 검사는 재미 또는 모든 직업의 균형을 확정하지 않는다.

## 유지한 성장 규칙

- 기존 `MONSTER_LOOP_POWER_SCALE` 생명력·피해 곡선, 액트 루프 상한, 혼돈 층수 상승을 유지한다.
- 루프 관문, 콘텐츠 해금, 고정 난이도·지도·벤치마크 보스는 난도를 변경하지 않는다.
- 장비 기본 드롭 확률, 고유 장비의 조건부 확률, 재화·경험치 확률과 페널티는 유지한다.
- 이번 변경 전의 즉시 아이템 획득, 이동 속도, 피격·가독성 변경은 보존한다.

## 실제 변경

1. 일반 액트·혼돈 보스의 기본 물리 피해 감소 상단 75 → 60, 원소 저항 상단 80 → 65.
   기존 지역 티어 곡선으로 보간하므로 첫 보스의 10/15는 유지된다. 특성과 지역 수호 보너스는 별도다.
   생명력·공격력·장갑·회피·재생과 루프별 증가량은 유지된다.
   `fixedSeason`, `loopScaleExempt`, `difficultyBenchmark`, `milestonePinnacle`은 제외한다.
2. 정예 장비의 조건부 희귀도: 고유 2%, 희귀 22 → 28%, 마법 38 → 50%, 일반 38 → 20%.
   보스: 고유 4%, 희귀 32 → 46%, 마법 44 → 50%, 일반 20 → 0%.
   이것은 **장비가 나온 뒤**의 품질 분포다. 장비 확정 지급이 아니며 미획득 보정과 지도 희귀도는 별도다.
3. 장비·장비 미획득 보정에만 레벨 차이 감쇠 계수 0.085 → 0.06.
   몬스터보다 20레벨 높을 때 약 42.7 → 54.9%, 30레벨 높을 때 약 18.3 → 30.1%를 받는다.
   부적, 별도 영역 보스 고유 보상, 재화, 경험치는 기존 감쇠를 유지한다.

희귀 장비 비중이 늘면 해체를 통한 재화 공급도 증가할 수 있다. 직접 재화 드롭 확률이 같다는 것이
시간당 경제 수익까지 같다는 뜻은 아니다. 이전 지역의 고유 장비 총량도 장비 수량 증가에 따라 늘 수 있다.
새 저장 필드는 없고 이미 소유한 아이템은 변경하지 않는다. 기존에 생성된 적은 다음 생성부터 새 방어 규칙을 쓴다.

## 재현 가능한 측정

```powershell
npm run benchmark:balance
node scripts/benchmark-loop-balance.js --loops 10,20,30 --zones 29 --seeds 17 --powers 160000,640000
```

기본 측정은 루프 1/3/5/10/20/30/50 × 액트10/혼돈20/심화30 × 물리·냉기 스킬 × 화력 입력 3종 × 난수 3종,
총 378개 전투다. 실제 `coreLoop`로 100ms씩 실행하며 60초 제한, 처치·사망·중단·시간 초과를 구분한다.
플레이어 입력은 레벨100/젬10, 고정 명중·저항과 세 단계 화력·생명력의 **인공 측정 조건**이다.
실제 획득 가능한 완성 빌드나 권장 클리어 시간이 아니다. 소환·지속 피해·패시브 빌드 전반은 아직 비교하지 않았다.
서로 다른 스킬의 계수가 있으므로 이 표로 직업 우열을 판정하지 않는다.

드롭 측정은 루프 1/10/30/50 × 레벨차 0/20/30 × 일반/정예/보스 각각 2만회, 총 72만회다.
생성된 적의 실제 드롭 판정·미획득 보정·희귀도 규칙을 쓴다. 옵션 조합과 인벤토리 필터·해체 수익은 포함하지 않는다.

변경 전 소스는 로컬 `artifacts/loop-balance/before-sources.json`에 보존했다.
`--sources artifacts/loop-balance/before-sources.json`을 두 측정 스크립트에 전달하면 변경 전 규칙으로 재현한다.
기본 결과는 `artifacts/loop-balance/latest.json`, `loot-latest.json`이다. 이전 측정 파일은 덮어쓰기 전에 따로 보관한다.

## 이번 결과

- 변경 전후 각 378전: 처치 성공 216 → 224, 사망한 조건 115 → 110. 나머지는 시간 제한 내 미처치다.
- 양쪽에서 처치에 성공하고 기존 전투가 5초 이상인 조건: 혼돈20 39개, 시간비 중앙값 0.623;
  심화30 27개, 시간비 중앙값 0.636. 액트10 16개는 중앙값 1.0이다.
  전체 공통 성공 216개의 시간비 중앙값도 1.0이다. 빠른 전투와 낮은 티어의 변화는 작다.
- 같은 난수·화력 조건에서 이전에 성공한 전투가 실패로 바뀐 경우는 없었다.
- 혼돈20 보스 생명력: 루프1 478,892 → 10 4,413,398 → 30 27,523,472 → 50 43,254,953.
  변경 전후 동일하며, 상위 루프는 여전히 더 높은 화력·생존력을 요구한다.
- 루프10, 레벨차0, 보스 2만회: 장비 총량 3,995개·고유146개 동일, 희귀1,794 → 2,221개.
  정예 2만회: 총량1,029개·고유21개 동일, 희귀364 → 414개. 일반 몬스터 분포는 동일하다.

이는 조건부 비교 수치이며 평균 플레이어의 실제 사망률·시간당 획득량이 아니다.

해체 경로도 확인했다. 일반·마법 장비는 새싹 1개, 희귀 장비는 이슬 1개와 추가 이슬 확률을 준다.
위 보스 표본에서 늘어난 희귀 427개를 모두 해체하면 확정 이슬도 427개 늘고 새싹은 427개 줄어든다.
희귀 장비에서 나오는 확정 이슬 기준 +23.8%이며, 추가 이슬·고유 해체·시간당 처치 증가까지 포함한 수치는 아니다.

## 협업과 검증

Hive DeepSeek V4.1 Flash가 실제 프로젝트 파일을 읽고 초기 검토와 최종 코드 검토를 했다.
초기 답변의 "후반 루프 총 난이도가 하락한다"는 해석은 단일 보정 곡선만 본 오류였다.
실제 적 생성 결과를 전달해 정정했고, 생명력·공격력 강화와 보정 임계치 증가 제안은 적용하지 않았다.
광범위한 후속 요청 한 번은 시간 초과했으며, 범위를 좁힌 최종 검토는 완료됐다.
DeepSeek의 최종 결론은 첫 조정으로 수용 가능이며, 해체 재화와 설정 객체 순회 여부를 추가 확인하라는 것이었다.
설정 객체를 통째로 순회하는 소비자는 없고, 생명력·피해·보스 방어를 명시적으로 읽는 것을 확인했다.
응답 원문: 로컬 `artifacts/loop-balance/deepseek-initial.txt`, `deepseek-final-review.txt`.

전체 스모크 267/267, 구조 검사, CSS 검사, 웹 빌드, 변경 파일 공백 검사가 통과했다.
4240 테스트 페이지에서 저장 불러오기, 일반전 진행, 지역 이동, 혼돈 보스전을 확인했고 해당 실행 구간 콘솔 오류는 없었다.
측정 로그와 브라우저 캡처는 `artifacts/loop-balance/`에 있다. 현재 변경은 커밋·푸시하지 않았다.

## 다음 조정의 기준

실제 플레이에서는 루프·지역·주 공격·표시 DPS·생명력·주요 방어와 함께 다음을 기록한다.
한 번의 운보다 같은 구간 3회 이상의 보스 시간, 10분 사망 횟수, 교체 후보 장비 수를 비교한다.

- 보스만 길고 생존은 안정적: 방어·재생과 관통 의존부터 확인한다. 전체 몬스터 생명력을 함께 낮추지 않는다.
- 일반 무리부터 자주 사망: 피격 집중·저항·지역 진입 단계와 해당 루프의 공격력을 확인한다.
- 처치는 빠른데 장비 교체 기회가 없음: 수량보다 옵션 티어·조합과 필터에서 사라지는 비중을 먼저 조사한다.
- 이전 지역이 상위 지역보다 계속 유리함: 처치시간 대비 품질·고유·입장 재료·해체 수익까지 합쳐 확인한다.

한 번에는 전투 또는 보상 중 주된 축 하나를 바꾸고 같은 조건으로 재측정한다. 측정 스크립트는 개발 시만 실행하며
게임 중 매 프레임 측정이나 외부 LLM 호출을 추가하지 않는다.

## 2026-10-05 사용자 결정으로 바뀐 부분

- **보스 방어 특화**(`data/maps.js` BOSS_DEFENSE_SPECIALTIES, `js/combat.js` getBossDefenseCaps): 위 1번(모든 방어 상한 60/65)을 대체한다.
  액트 · 혼돈 보스는 물리 피해 감소 · 화염 · 냉기 · 번개 저항 중 1~2개만 원래 상한(75 / 80)까지 오른다.
  첫째는 보스 속성(물리 → 피해 감소, 화염/냉기/번개 → 같은 저항, 카오스는 지역 시드), 둘째는 지역 시드로 50%.
  나머지와 카오스 저항은 40 / 45까지만. 모두 기존 지역 티어 곡선(제곱)을 따라 티어 20(혼돈 20 · 심화)에서야 상한에 닿는다.
  고정 난이도 · 벤치마크 · 정점 지역과 다른 콘텐츠 보스는 예전처럼 모두 75 / 80. 지역 속성 수호 같은 기존 추가 저항은 그대로 더해진다.
- **희귀도 분포**는 위 2번 이전의 원래 값으로 되돌렸다(정예 고유 2 · 희귀 22 · 마법 38 · 일반 38%, 보스 4 · 32 · 44 · 20%).
- **디아블로식 판정 횟수**(`data/items.js` EQUIPMENT_DROP_PICKS): 정예와 보스는 장비 드랍 판정을 한 번 더 받는다.
  첫 판정만 미획득 보정과 첫 액트 보스 보장을 쓰고, 추가 판정은 같은 기본 확률로 따로 굴린다(정예 3.4% → 기대 장비 약 2배, 보스 13% → 약 2배).
  각 판정의 희귀도와 드랍 변형은 따로 추첨한다. 수치는 플레이테스트 전 가설이다.
- 검사: `scripts/smoke-loop-balance.js`(보스 특화 · 고정 지역 · 원래 희귀도 경계 · 추가 판정), `smoke-loot-rewards.js`.
