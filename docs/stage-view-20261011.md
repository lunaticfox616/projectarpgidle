# 옆에서 보는 무대와 던파식 캐릭터 (2026-10-11 시작)

사용자 결정(2026-10-11): 주인공을 던파식 캐릭터 묶음(직업 6 × 무기 자세 7)으로 바꾸고, 전장도 옆에서 보는 무대로 바꾼다.
대검은 자세 그림이 없어 검방패 자세로 대신한다. 몬스터와 지도는 나중에 같은 밀도로 다시 그린다.

## 원칙
- 전투 규칙과 격자는 그대로 둔다. 바뀌는 건 그리는 법뿐이다: 격자의 가로는 무대의 좌우, 세로는 무대의 깊이.
- 깊이 한 칸은 화면에서 가로 한 칸의 `STAGE_VIEW.depth`배(0.5) 높이다. 지도 그림, 안개, 칸 자리, 누른 자리 → 칸 계산이 함께 눌린다.
- 캐릭터와 몬스터는 옆모습으로 서고 좌우로만 돈다. 위아래(깊이)로 움직일 때는 마지막에 보던 쪽을 그대로 본다.

## 1단계: 시험판 (이 문서를 만든 변경)
- 켜는 곳: 설정 `battleView = 'stage'`. 지금은 테스트 패널(로컬에서 주소 끝에 `?dev=1`)의 "옆에서 보는 무대(시험판)"에서만 켠다.
  크기(자동, 또는 캐릭터 도트 하나의 화면 px 1, 1.5, 2)와 들 자세도 거기서 고른다.
- 그림 폴더(`assets/playable/stage/`)가 서버에 없으면 설정이 켜져 있어도 위에서 보는 전장 그대로다(`stageActors.available`).
  시험판 세이브가 그림 없는 빌드로 넘어가도 화면이 깨지지 않는다. 그림은 배포 가능 여부를 확인할 때까지 저장소에 넣지 않는다(.gitignore).
- 가져오기: `node scripts/import-stage-characters.cjs <정리 묶음 폴더>` → `assets/playable/stage/<직업>/<무기>/<모션>.png`,
  `data/stage-characters.js`(프레임 수, ms, 반복, 타격 프레임, 피격과 이동 공용 규칙).
- 주인공(js/canvas-stage-actors.js):
  - 낀 무기의 대분류 → 자세(`STAGE_VIEW.stanceByCategory`). 곡도에 방패를 끼면 검방패, 무기가 없으면 맨손.
  - 공격은 휘두를 때마다 공격 → 공격2 → … 순서로 돌고, 주문 젬은 시전, 던지는 플라스크 젬은 투척 그림을 쓴다.
    타격 프레임이 실제 타격 순간에 오도록 준비 구간을 줄여 맞춘다(Hana 그림과 같은 규칙). 준비 시간이 320ms보다 짧으면 9장 이하 그림만 쓴다.
  - 걷기는 이동 속도에 맞춰 0.5배에서 2배로 재생한다. 사망은 맨손 사망 공용.
  - 피격은 그림 없이 붉은 외곽선과 밀림이다(규격의 공용.피격). 몸 전체를 붉게 칠하던 표시는 무대에서 쓰지 않는다.
  - 그림은 지금 쓰는 직업 × 무기 묶음만 들고 있는다(전부 풀면 약 196MB, 한 묶음 최대 9MB).
- 투영: 탐험 지도(js/canvas-act-exploration.js projection)와 고정 전장(js/ui.js getFixedBattleGridProjection)이 `stageView.depth()`를 쓴다.
- 칸 크기(`stageView.tile`): 캐릭터 도트 하나가 캔버스 픽셀의 정수배가 되는 크기 가운데, 가로로 15칸(좁은 화면 8칸) 이상 보이는 가장 큰 것.
  1080p 125% 화면(게임 안 너비 1920)에서는 칸 128, 캐릭터 2배(키 약 180px, 화면 높이의 17%)다. 주인공은 화면 높이의 46% 자리에 선다(아래는 HUD).
- 스킬 이펙트 판(js/canvas-fx-remake.js): 판은 정사각 칸(칸당 48) 그대로 두고 화면에 옮길 때만 깊이를 누른다. 이펙트가 지도처럼 바닥에 눕는다.
- 몬스터: 무대용 시트(data/monster-sprites.js MONSTER_STAGE_SHEETS)가 있으면 그것으로 그린다: 오른쪽을 보는 한 줄, 캐릭터와 같은 도트 크기,
  왼쪽은 좌우 반전. 지금은 견본 세 종(액트 1 수액 슬라임, 뿌리 일개미, 뿌리 웜)뿐이다. 없는 몬스터는 기존 시트의 좌우 줄만 쓴다(`stageView.facing`).
  그리는 도구: `node scripts/build-stage-monsters.cjs [--write] [id]`(scripts/stage-monsters/render.cjs가 입체 몇 개를 광선으로 쏘아 도트로 찍고
  밝기를 다섯 단계로 끊는다. 정의는 scripts/stage-monsters/act1.cjs). 미리보기는 artifacts/stage-monsters/preview.png.

## 남은 일
1. 지도: 지금 그림(칸 16도트, 위에서 본 화풍)을 눌러 쓰고 있어 벽 앞면과 소품이 납작하다. 무대용으로 다시 그린다(칸이 2:1, 더 높은 밀도, 뒷벽 앞면).
2. 몬스터: 옆모습, 캐릭터와 같은 밀도로 다시 그린다. 견본 세 종의 화풍을 확인받은 뒤 나머지(시트 약 60개와 보스)로 넓힌다.
3. 스킬 이펙트: 칸이 정사각형이라고 보고 그리는 이펙트(48px 판 좌표)를 무대의 깊이에 맞춘다. 그림에 이펙트가 같이 그려진 모션 98개와 겹치는 것도 정리한다.
4. 손 좌표: 새 그림에는 손 위치가 없다. 투사체가 나가는 자리, 향로가 걸리는 자리를 정한다.
5. 다른 화면의 주인공: 공개 프로필 인형, 직업 선택, 유령 대전, 시작 화면.
6. 기본값으로 켜기: 위 항목이 끝난 뒤. 그때 위에서 보는 전장 코드를 걷어 낸다.

## 확인 (임시 스크립트)
- 42개 직업 × 자세 묶음이 모두 불러와지고 그려진다. 피격 외곽선이 켜졌다 꺼진다. 사망 그림이 나온다.
- 눌린 격자에서 화면 자리 → 칸이 맞는다. 고정 전장은 칸이 140×70(1536×864 기준)으로 화면 안에 든다.
- 그림 폴더를 막으면 위에서 보는 전장 그대로이고 오류가 없다.
