# 계 전용 고유 목록 — 2026-09-13

현재 개발본의 드랍 지역 지정 기준으로 총 98종이다. 계 도감은 아래 전부를 표시한다.
기존 일반 도감에 포함되던 28종은 일반 도감 기록·보너스·추적 대상을 유지하면서 계 도감에서도 조회된다.
계 도감 자체의 별도 수집 보너스는 없으며, 동일 획득 기록을 공유한다.

## 드랍 및 효과 규칙

- 혼돈계·지하계·우주계 보스 처치 시 일반 장비 드랍과 별도로 3% 확률로 해당 계 고유를 판정한다.
- 플레이어가 몬스터보다 높은 레벨일 때 기존 보상 감소를 적용한다. 일반 장비 배율 및 지하계 50% 감소는 이 별도 판정에 중복 적용하지 않는다.
- 별도 드랍 성공 중 1%는 해당 지역에서 가능한 초희귀 고유 풀을 선택한다. 기본 조건에서 초희귀 전체 확률은 0.03%이며, 해당 풀 내 개별 아이템은 균등 추첨한다.
- 후보는 현재 드랍 티어 조건을 유지한다. 우주계는 G1에서 계 도감 고유 10종, G5에서 50종이 후보가 된다.
- 폭풍의 눈·만화경·대지의 태동·무한한 허기는 드랍 요구 티어를 해당 계 상한인 15에 맞췄다. 고정 베이스와 장착 요구사항은 그대로다.
- 별도 드랍은 자동 해체·습득 필터·공간 부족으로 유실되지 않도록 보호하며, 획득 시 계 도감에 등록한다. 방치 전투도 동일 획득 경로를 사용한다.
- 우주계 은하 보스 20종 및 아스트라의 파편은 기존 전용 보상 판정도 유지한다.
- 우주계 고유 효과는 지역 제한 없이 적용된다. 50종의 오해를 유발하던 ‘우주계 전용 효과 #’ 접두문구를 제거하고 기존 저장 장비도 갱신한다. 타격·치명타·소환 등 효과 자체의 발동 조건은 유지한다.

검증: 전체 스모크 188/188, 구조·린트 검사 통과. PC·모바일 브라우저에서 계 도감 98종 표시,
아스트라 등록, 기존 일반 도감 보너스 유지, 저장 복원 뒤 우주계 효과 설명을 확인했다.
드랍 검사는 실제 지역 생성과 전리품 지급 경로를 사용하며 난수 경계만 제어한다.
실제 플레이 시간에 따른 획득 체감은 아직 플레이테스트가 필요하다.
