# 별쐐기 노드 및 범위 표시

- 실제 트리의 슬롯에 장착 별쐐기 이름과 식별 번호를 표시한다. 슬롯 툴팁은 원래 허브 옵션 대신 장착 효과를 보여준다.
- 중앙 슬롯은 실제 좌표 거리의 변성 구간을 금색, 청록색, 보라색으로 구분한다. 장착 시 한 번 펼쳐지고 유지되며, 해제하면 제거된다. 이동 및 확대는 기존 오버레이 변환을 재사용한다.
- 일반 구간은 160/240/320이다. 고유 별쐐기의 비례 구간과 소행성대의 빈 중심도 판정과 같은 반경을 사용한다. 태양과 외곽 성률에는 존재하지 않는 변성 범위를 그리지 않는다.
- 중앙 공허 패시브로 향하는 무효 경로도 변성된다. 투자한 경로만 스탯에 반영되며, 해제하면 효과 없음으로 돌아간다. 공허 패시브 자체는 기존처럼 보호한다.
- 변성 전 효과가 없으면 툴팁은 `효과 없음`을 표시한다. 이전 변성 캐시는 v3 서명으로 다시 계산하며 저장 형식은 바꾸지 않는다.

검증: 별쐐기 무결성 및 실제 패시브 트리 회귀 검사, 전체 스모크, PC/모바일 장착/해제/툴팁 확인. 테스트 세이브에서 무효 경로의 생명력 +17 변성에 투자했을 때 실제 전투 생명력 907 → 924를 확인했다. 실제 저장과 분리한 `artifacts/star-wedge/` 페이지는 같은 프로덕션 코드를 사용한다.

최종 결과: `npm test` 199/199 통과, `npm run check:architecture` 통과. 일반 및 고유 7종, 외곽 성률, 범위 애니메이션 종료 후 유지, 화면 이동 시 재생 방지, 장착 해제 후 제거를 브라우저에서 확인했다.
