# 별쐐기 확장 (2026-09-15)

## 적용 규칙

- 외곽 성률의 각 생성 패시브는 별쐐기에 기록된 수치의 2배를 적용한다. 중앙 변성 수치는 유지한다.
- 첫 세 경로는 각각 1~3개 노드로 구성된다. 세 번째 노드가 있는 경로는 직렬 또는 분기로 연결된다.
- 배치는 생성 시 결정하고 `outerLayout.counts/forks`에 저장한다. 재접속, 장착 위치 변경, 옵션 재굴림으로 배치를 무료 교체할 수 없다.
- 기존 별쐐기는 ID로 결정한 배치를 한 번 부여한다. 기존 네 노드의 ID와 투자는 보존한다.
- 혜성의 경로 수치는 6/10/14%, 핵심 수치는 기존 24%다. 외곽에서는 각각 2배다.

| 고유 | 적용 |
| --- | --- |
| 암흑물질 | 일반 옵션이 정확히 한 줄인 공허 패시브 효과 100% 증가. 초월 효과 제외. 중복 장착해도 증가는 한 번 적용. |
| 명왕성 | 외곽 전용. 공허 패시브 1~5개. 각 노드에 투자한 뒤 기존 공허 제작 사용. |
| 초신성 | 네 옵션 모두 핵심에 적용. 반경 없음. 외곽에서는 네 옵션을 가진 핵심 노드 하나 생성. |
| 안드로메다 | 800~900 거리의 고리 안에서 경로 없이 할당 가능. 포인트와 기존 해금 조건은 필요. 별쐐기 자체의 옵션 없음. |

명왕성의 개수 확률은 1개 80%, 2개 16%, 3개 3.2%, 4개 0.64%, 5개 0.16%다.
기존 재굴림 비용(기본 운석 파편 23개와 기존 전문가 할인)을 적용하며 줄 고정 재굴림은 사용할 수 없다.
암흑물질, 안드로메다, 혜성의 고정 효과는 재굴림할 수 없다.

## 연결 및 저장

블랙홀의 무료 연결 거점과 안드로메다 고리는 현재 장착 상태에서만 권한을 부여한다.
장착 변경, 해제, 파괴 후 연결되지 않은 투자 경로는 반환한다. 다른 정상 경로로 이어져 있으면 유지한다.
외곽 경로의 첫 노드는 독립적으로 투자하지만 그 뒤 노드는 부모를 거쳐야 한다.
모든 연결 판정은 헌신의 서약의 장식 연결선을 통로로 사용하지 않는다.

명왕성 노드는 `star_pluto_<별쐐기 ID>_<0~4>`로 식별한다. 해제하거나 개수를 낮게 재굴림하면
투자는 반환하고 해당 노드의 제작 옵션은 보존한다. 다시 등장했을 때 재투자해야 효과가 적용된다.
명왕성 자체를 파괴하면 해당 노드도 삭제된다. 루프 시 공허 제작 초기화는 기존 규칙을 유지한다.
추가 장비 슬롯 등 초월 효과는 투자 중인 공허 노드에서만 작동한다.
공허가 부여한 추가 포인트가 사라져 투자량이 보유량을 넘으면 최근 투자를 반환하고 연결을 재검사한다.
전체 초기화나 재투자를 반복해 추가 포인트를 복제할 수 없다.

`js/star-wedge.js`는 배치, 수치, 연결 검증을 소유한다. `js/passives.js` 이전에 로드한다.
트리 원본 버전(`layoutVersion`)은 바꾸지 않고 `starWedgeGraphVersion`으로 인접 목록 캐시를 갱신한다.
저장 복원은 생성 노드를 먼저 복구한 뒤 투자 ID와 공허 제작 데이터를 복원한다.
암흑물질은 저장된 옵션을 변경하지 않고 전투 계산과 표시에서 파생 수치를 사용한다.

## 기존 획득처 확인

새 네 종류는 기존 일곱 종류와 같은 고유 풀에 포함된다. 선택 가중치는 모두 동일하다.

- 별쐐기 완성 제작: 불완전한 별쐐기 1개, 운석 파편 77개.
- 운석 낙하 지점: 첫 클리어 이후 천문학자 Lv.4부터 완성된 별쐐기 드랍 가능.
- 두 경로 모두 성핵 조각(`astralCore`)의 제작 직전 보유량마다 고유 확률 +2%p, 최대 35%.
  보유 중이면 1개를 자동 소모한다. 보유량 0이면 고유 확률도 0이다.
- 성핵 조각은 우주계에서만 균열 게이지를 채운 운석 도전에서 천문학자 Lv.10 이상,
  첫 클리어 이후 정산 시 6% 확률로 획득한다. 획득률 자체는 이번 변경에서 조정하지 않았다.

## 검증

- `scripts/smoke-star-wedge-expansion.js`: 확률 구간, 2배 수치, 경로 비용, 반환, 저장 복원,
  명왕성 제작 보존, 잘못된 장착/재굴림의 재화 보존, 초월 포인트 회수, 암흑물질 실전 스탯,
  초신성 중첩 옵션, 블랙홀/안드로메다 권한 회수.
- 전체 스모크: 200/200 통과.
- 동일 구조 검사 규칙의 인접 목록 탐색 버전과 정규 `npm run check:architecture`: 모두 통과.
- 실제 브라우저 PC 1280×900 / 모바일 412×915: 설명, 클릭/터치 투자, 생성 노드, 반경 확인. 페이지 오류 없음.
- 테스트 페이지: `artifacts/star-wedge/index.html`. 실제 게임 로직과 저장 분리 재료 사용.
  명왕성은 5개 예시로 시작하며 실제 재굴림으로 확률을 시험할 수 있다.

2배는 노드별 값이다. 총 효율은 경로 개수, 투자 포인트, 옵션 구성에 따라 달라진다.
실제 후반 빌드에서 네 고유의 최종 균형과 재미는 플레이테스트가 더 필요하다.
