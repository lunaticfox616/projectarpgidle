# 누적 변경 통합 점검

기준: main의 #1025 이후 작업. 실제 사용자 저장을 읽거나 변경하지 않고 분리된 합성 저장과 브라우저로 확인했다.

## 이번 점검에서 수정

- 플레이어 관통 투사체가 적의 칸 중심을 차례로 이으며 꺾이던 표현을 같은 직선 위의 좌표로 수정했다. 타격 시점·범위·피해는 유지한다.
- 기본 관통만 직선 통합한다. 연쇄·왕복·산탄·복합 단계는 고유 경로를 유지하고, `projectilePattern.trajectory: 'stages'`로 특수 투사체도 기존 단계별 경로를 선택할 수 있다.
- 외형 식별자가 같은 적의 공격 역할을 고정했다. 위습은 유도 사격, 정예의 끝까지 관통 사격만 900ms 시전이다. 외형 없는 기존 적의 배정은 유지한다.
- 일반 공격의 캐스팅바는 게임에서 원래 없었다. 일반 사격에도 시전을 붙였던 체험 페이지를 게임과 맞췄다.
- 초반 보스 설명을 실제 긴급 회피 컨디션 젬에 맞췄다.

## 검사 결과

- 전체 스모크 181/181 및 런타임 구조·lint 래칫 검사 통과.
- 장비·젬·컨디션 피드백·우주계·지역·저널·배율·첫 플레이 PC/모바일: 68개 통과, 기존 기기 전용 6개 제외.
- 플레이어 비스듬한 관통·적 시전 취소·접촉 피드백 PC/모바일: 추가 대상 검사 6개 통과.
- HUD·기존 콘텐츠·장비 밀도 확장 검사: 수정 항목 재검사 포함 151개 통과, 기기 전용 9개 제외. Android 터치 스크롤·장착 검사 1개 통과(PC 대상 제외). 터치 시작점은 고정 하단 도크에 겹치지 않는 위쪽 장비다.
- main의 상태 기본값/복원 코드로 만든 초반 및 후반 합성 저장을 새 복원 코드에 입력: 장비, 재화, 패시브, 스킬/보조 젬, 해금, 저널, 지하계 진행 유지.
- 우주계 스모크는 이전 항로 버전과 손상 저장, 5은하 125곳 진행, 새로고침 및 중복 보상 방지를 검사한다.
- 루프 1/10/50의 고정 물리 공격 100회: 방어도 감소, 회피 90%의 누적 회피, ES 선흡수 확인. 이는 방어 처리 검증이며 난이도 균형을 보장하는 실전 빌드 비교는 아니다.
- main의 계산 함수와 비교한 총 스탯 동등성 통과. 합성 후반 8소환수 조건에서 수치 계산 5.75→2.06ms(약 64% 감소). 환경별 결과는 달라진다.
- 장비 분석만 교체한 별도 비교는 120개 점수가 일치했고 약 466→505ms였다. 저장/실시간 상태 격리 비용이 있어 이 부분만 빨라졌다고 주장하지 않는다.
- 기존 UI 테스트의 `IF/THEN`, 접힌 관리 패널, 예전 분석 안내 문구 기대를 현재 선택값·일괄 해체 메뉴의 실제 조작 계약으로 갱신했다. 복구 검사는 별도 전투 타이머를 중단해 테스트용 장비가 사냥 진행에 영향받지 않도록 했다.

## 군중제어와 남은 설계

동결은 실제 냉기 타격에서 부여된다. 확률·피해/최대 HP 비율·저항 판정을 거친 뒤 시전을 취소한다.
기절·침묵은 수신/취소 처리를 지원하지만 현재 플레이어 부여 스킬은 없다. 체험 버튼으로 적용한 검사가 실제 부여 스킬 구현을 의미하지 않는다.

고정 보스 HP, 타격당 최대 HP 1%, 동결 확률 스탯 100%, 60초 상태이상 단독 실험:
초당 0/5/20타 조건에서 보스 공격 20/19/18회, 동결 시간 비중 0/4.5/10.5%.
이 조건에서는 무한 취소가 없었다. 보스 HP를 고정한 격리 실험이며 모든 실제 빌드의 무한 제어 가능성을 배제하지 않는다.
새 기절/침묵 부여 수단 및 보스 저항 체계를 추가할 때 제어 반복 제한을 함께 설계해야 한다. 이번에 임의의 면역 시간이나 확률은 추가하지 않았다.

원본 스킬 이펙트는 제공된 좌표·모션 기준 검사를 유지하지만 모든 스킬의 전체 연출이 원본 갤러리와 완전히 같다는 검증은 완료되지 않았다.
누적 변경은 로컬 체험 페이지 자체가 아니라 실제 게임 코드·자산과 회귀 검사로 PR에 포함한다.
