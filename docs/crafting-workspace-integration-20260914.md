# 제작실 본편 통합 — 2026-09-14

## 현재 제작 연구 기능 (2026-10-18)

- Craft of Exile의 목표 조합·가능 옵션·확률 실험 방식을 현재 게임 제작 규칙에 맞춰 추가했다. 대상 장비의 실제 옵션 풀에서 등장 가능한 티어·가중치와 제외 이유를 확인한다.
- 목표는 최대 3개이며 모두 만족/하나 이상 만족을 선택한다. 이전 한 개 목표 저장은 그대로 복원한다. 기존 목표 자동 제작도 같은 판정을 사용한다.
- 1회 연습과 2,000회 표본 실험은 장비 사본에서 실제 제작과 공통인 기본 제작 함수를 사용한다. 장비·재화·제작 통계는 변경하지 않는다. 지원하는 기본 재화만 실험하고, 실제로 불가능한 제작은 같은 이유로 거절한다.
- 표본 결과에 성공률·95% 구간을 표시하고 성공이 5회 미만이면 평균 비용 추정을 제시하지 않는다. 50회씩 나눠 계산하며 창을 닫으면 중단한다. 표시 비용은 실제 제작 시 비용이고 연습 소모가 아니다. 표본은 보장 확률이나 전체 최적 제작 경로 계산기가 아니다.
- 책임: `equipment-crafting.js` 공통 제작, `crafting-goal-options.js` 옵션/모의실험, `crafting-workspace-state.js` 목표 저장, `crafting-workspace-ui.js` 화면. 브라우저에서 2,000회 실험 완료와 결과·신뢰 구간 표시를 확인했다.

## 제작 뿌리 (2026-10-18)

- 화면 이름은 뿌리, 코드 이름은 omen이다. 정의와 수치는 `data/items.js` `CRAFT_OMENS`(효과, 쓰이는 제작, 보스, 몬스터 확률). 걸어 둔 뿌리는 `game.craftOmen { key, side }`이고 저장 경계는 `normalizeCraftOmen`이다.
- 규칙은 `js/equipment-crafting.js` 한 곳(omenFor, spendOmen, rollOmenLine, pickAddMod, pickPruneLine, craftBasic)이다. 실제 제작(`js/passives.js` useCurrency)과 제작 연구의 연습(`rehearse`)이 같은 함수를 쓴다. 뿌리는 자기가 바꾼 제작이 끝난 뒤 `spendOmen`으로 한 번만 줄고, 연습은 쓰지 않는다(`scripts/smoke-crafting-economy.js`).
- 얻는 곳: 최종 보스 보상(`data/atlas-endgame.js`), 뿌리를 품은 몬스터(`js/atlas-endgame.js` markOmenBearer, 처치 보상은 `js/atlas-run.js`), 지도 기운 뿌리의 메아리(`data/loot-omens.js`). 모두 쓰러뜨린 최종 보스의 뿌리만 준다. 암거래상은 팔지 않는다(사용자 결정).
- 성화의 뿌리: `craftBasic`이 결과 셋을 `game.craftChoice { itemId, options }`에 두고 아이템은 첫 결과를 받는다. `pickChoice`는 같은 아이템의 제작 칸(`CRAFT_FIELDS`: 등급, 이름, 추가 옵션, 혼돈 주입, 지키기)만 바꾸고, 그사이 아이템이 바뀌었거나 없으면 기다림을 버린다(`pendingChoice`). 기다리는 동안 제작실은 제작을 막고 고르기 창은 닫히지 않는다.

## 기억 조각칼 (2026-10-18)

- 화면 이름은 기억 조각칼(재화)과 기억 새겨짐(새긴 장비, `craftingWorkspaceUi.imprintMark`), 코드 이름은 memoryImprint, imprint다. 체이싱 티어 재화다(`data/loot-omens.js` moments). `item.imprint`는 제작 칸(`CRAFT_FIELDS`)의 사본이다. `engrave`는 1개를 쓰고 이전 새김을 덮고, `restoreImprint`는 한 번 되돌린 뒤 새김을 지운다. 타락, 고유, 융합 유물, 전당 소장품은 둘 다 막는다. 같은 아이템의 칸만 바꾸므로 아이템이 늘지 않는다(`scripts/smoke-crafting-economy.js`).
- 불러올 때 `normalizeItem`이 깨진 새김을 지운다. 얻는 곳은 기억 싸움 보상(`data/memory-dungeon.js` rewards).

## 2026-09-14 통합 이력

누락 감사에서 `artifacts/crafting-flow`에만 남아 있던 제작 UI를 본편 `index.html`의 장비 → 제작실에 연결했다. 이 작업은 제작실 통합 범위다. 이식 제작의 실제 기능, 융합 규칙 변경, 벌집 전용 배경, 플레이어 기절·침묵 공급원은 별도 미완료 항목으로 남는다.

## 적용 내용

- 제작실과 화석 제작대를 통합. 기존 장비 선택, 생장 제작 대상, 벌꿀 고정, 소켓, 잠식 해방, 화석 정제·복원은 유지한다.
- 재화 인벤토리에 검색·분류·소진 재화 보기·주 재화 4칸 편집을 제공한다. 처음 얻지 않은 재화와 아직 해금하지 않은 재화는 목록에서 숨긴다. `기타 재화`에는 직접 제작에 쓰는 재화만 표시한다.
- 기본 주 재화는 형체 없는 이슬, 수액 봉오리, 황금률, 마름병 포자. 발견 기록·주 재화·목표 옵션은 저장하고, 이전 화석 탭 저장은 제작실로 복원한다. 이전 저장에서 이미 모두 소진한 재화의 과거 획득 여부는 추측하지 않는다.
- 실제 옵션 풀에서 목표를 선택하고 최소 티어를 정한다. 재화마다 기존 제작 검증·확률·소모량을 사용한다. 고정 옵션은 T0다.
- 목표 자동 사용은 최대 100회까지 설정하고, 목표 달성·재료 소진·횟수 도달·대상 또는 화면 변경·백그라운드 전환 시 멈춘다. 자동 사용 상태 자체는 저장하지 않는다.
- 목표 일치 확인창은 장비 옵션만 보여주고, 잠깐의 확인 대기와 닫힘 지연으로 연타가 다음 제작으로 전달되지 않게 한다. 벌꿀 고정과 별개의 무료 옵션 고정 기능을 추가하지 않는다.
- 제작 경과, 이전 옵션, 옵션 옆 수치 범위, 소수 값, T10 이상/최고 티어 강조를 적용한다. 움직임 감소 설정에서는 회전 강조를 끈다.
- 어두운/밝은 테마, PC/모바일 배치와 버튼 줄바꿈을 확인했다.

## 경계와 리뷰에서 수정한 문제

- `crafting-workspace-state.js`: 발견·저장 설정. `crafting-goal-options.js`: 비용·난수 없는 후보 계산. `crafting-catalog-ui.js`, `crafting-workspace-ui.js`: 표시와 입력.
- 실제 제작은 `useCurrency` 및 기존 화석·특수 제작 함수에 위임한다. UI 입장 판정과 제작 대상 선택은 기존 `ui.js` 어댑터를 재사용한다.
- 홀씨 선택을 실제 `game.sporeCraftModes`에 전달하도록 수정했다.
- 같은 탭을 다시 그리는 기존 갱신 경로가 자동 제작을 멈추지 않도록 실제 탭 변경 때만 중지한다.
- 재료 영역 추가 뒤 장비 목록의 지연 렌더가 엉뚱한 `details`를 참조하던 문제를 명시적 목록 클래스 선택으로 수정했다.
- 화석 고정 옵션·균열 화석의 목표 후보와 제작 경과의 품질/베이스 변화, 잠식/혼돈 주입 표시를 보존했다.
- 삭제된 화면 구조를 검사하던 기존 테스트는 본편의 새 입력 경로로 이전했다. 확률·재화 사용·고정 제한 검사는 유지했다.

## 검증

- `npm test`: 전체 스모크 195개.
- `npm run check:architecture`: 기존 복잡도·의존성 기준. 빠른 재검토에는 같은 검사 구현의 그래프 탐색만 인덱싱한 로컬 진단을 사용했다. 기준 완화 없음.
- Playwright: `crafting-workspace`, `special-crafting`, `craft-picker-search`, `craft-lazy-lists`, `mobile-crafting`과 `core-ui`의 제작 경과/제작 출처 제한 사례.
- 실제 PC·모바일 화면에서 재화 선택, 소비, 자동 정지, 목표 확인, 테마 전환을 확인한다. 브라우저 검사는 로컬에서 실행하며 GitHub 브라우저 CI를 복구하지 않았다.
- `artifacts/crafting-flow/index.html`은 저장이 격리된 테스트 재화만 주입하고 본편 UI를 그대로 로드한다. 이전 `lab.js`/`catalog.js`/`style.css`는 이 페이지에서 더 이상 로드하지 않는다.
