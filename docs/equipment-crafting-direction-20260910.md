# 장비 옵션 표시와 특수 제작 방향 — 2026-09-10

## 적용한 변경

- 일반 고정 옵션의 `고정` 문구를 `[T0]` 배지로 변경한다. 실제 티어 계산/수치는 바꾸지 않는다.
- 화석·균열 홀씨의 젬 레벨/보조 젬 한도 +1 및 이전 저장의 특수 옵션도 T0로 표시한다.
  모든 티어에서 같다는 정의가 있어야 T0다. 한 티어의 최소/최대가 같다는 이유만으로 T0로 만들지 않는다.
  기존 고유 장비의 tier 0 `[U]` 표시는 유지한다.
- 장비 상세/비교에서 현재 주력 스킬에 적용되지 않는 공격·주문 전용 옵션을 흐리게 표시한다.
  이유 문구는 추가하지 않는다. 결투의 규율은 주문 피해 증가만 공유하고 주문 기본 피해/치명타 피해/흡수까지 공유하지 않는다.
  생명력 흡수를 막는 혼의 성소도 반영한다. 방어·속성 전환·소환수 등 미검증 옵션은 무효라고 단정하지 않는다.
  소환 젬을 함께 장착한 경우에는 혼합 피해 경로를 오판하지 않도록 흐림 표시를 보수적으로 생략한다.
- 기존 cachedTooltipStats를 읽고 상세창을 렌더할 때만 판정한다. 옵션마다 전체 스탯을 재계산하거나 전투 틱 작업을 추가하지 않는다.
- 속성 홀씨 후보에 해당 속성 기본 피해를 추가한다. 피해 홀씨에는 일반/물리/주문/속성 기본 피해 및 공격·주문 피해 증가를 추가하고 물리 피해 감소(dr)를 제외한다.
  부패 홀씨의 원소 옵션 제거 후보에도 원소 기본 피해를 포함한다.
- 홀씨 보장 옵션은 `getCraftTierRangeForItem(item, 'spore')`의 전체 범위에서 굴린다.
  T20 장비는 기존 T19~20 보장에서 T9~20으로 변경한다. 기존 장비 수치는 소급 변경하지 않는다.
  나머지 옵션은 기존 일반 제작 규칙을 사용한다.

## 종류별 제한과 재제작 — 적용한 정책

- 사용자는 장비 하나에 홀씨 효과 1개, 화석 효과 1개, 이식 효과 1개가 공존하는 방향을 선택했다.
- 홀씨·화석은 같은 출처의 옵션이 있으면 추가형 제작을 차단하고, 전체 재련은 다시 사용할 수 있다.
  전체 재련은 기존처럼 잠기지 않은 옵션을 다시 굴린다. 다른 출처라는 이유만으로 자동 보존하지 않는다.
- 균열 홀씨는 재료가 홀씨여도 **화석 옵션 1개 제한**에 포함한다. 홀씨 옵션과 공존할 수 있지만 기존 화석 옵션이 있으면 추가할 수 없다.
- 잠긴 같은 출처 옵션이 남아 중복되는 재련은 차단한다. 균열 화석의 표식+증폭은 두 줄을 차지하는 하나의 효과다.
  같은 균열 화석의 재련은 기존 표식을 유지하며 허용한다. 증폭 자체가 잠겼다면 차단한다.
- 보장 옵션을 넣을 공간이 부족한 재련도 차단한다. 모든 거절은 재화 소비·장비 변경 전에 처리한다.
- 새 홀씨/화석 보장 옵션에는 `craftSource`를 저장하고 상세창에 출처를 표시한다.
  제작창, 모바일 선택기, 결과의 ‘다시 사용’ 버튼은 동일한 규칙을 사용한다.
- 이식은 이식 옵션이 있는 장비에 재이식 불가로 확정했다. 공통 출처 규칙에는 반영했지만 실제 이식 기능은 아직 구현하지 않았다.
- 이식 제안: 군락지 클리어로 접목 재료를 얻고, 장비 제작에서 같은 부위의 재료 장비를 소모해 일반 옵션 한 줄을 옮긴다.
  대상의 장비 티어 상한을 적용하고, 고유 효과/다른 특수 제작 효과의 복사는 막는다.
  해금 시점·보상량·비용·실패 여부·일반 6옵션에 포함되는지는 미확정이며 아직 변경하지 않았다.
- 출처 추적이 없는 이전 제작 옵션은 티어/수치만 보고 홀씨산이라고 추측하거나 삭제하면 안 된다.
  알려진 화석·균열 홀씨 표시는 저장 복원 시 화석 출처로 인식한다. 출처를 모르는 기존 일반 홀씨 옵션은 그대로 유지한다.
  출처 규칙은 `js/equipment-crafting.js`, 상태 계약은 `js/state.js`, 실제 소비·재련은 기존 제작 도메인이 소유한다.

## 융합 구현과 의도의 차이

사용자 의도는 '고유 효과만 이전'하여 완성 희귀 장비와 고유 장비가 경쟁하는 것이다.
현재 `js/items.js`의 `resolveTimeRiftFusion`은 고유 아이템 전체를 복제한 뒤 희귀 옵션을 덧붙인다.
따라서 고유의 일반 추가 옵션도 남는다. 이번 표시/홀씨 패치에서는 이 규칙과 기존 융합 장비를 변경하지 않았다.
고유 경쟁력 조정 전 이 차이를 해결해야 한다.

## 분갈이 — 장비 세공 설계안 (2026-11-21)

> 일반 접미어 하나를 빈 접두어 칸으로 옮깁니다. 옵션의 등급과 수치는 유지됩니다.

접미어 세 줄이 모두 마음에 드는 장비에서 네 번째 종류의 접미어 효과를 노릴 때 쓴다. 대가는 무기라면 공격력, 반지라면 최대 생명력 등을 붙일 수 있었던 접두어 한 자리다. 방향은 접미어에서 접두어로 고정한다. 아래 해금과 가격은 첫 플레이테스트 제안값이다.

2026-11-22에 첫 플레이테스트의 적용 부위를 확정했다. 분갈이·천칭 제련·금줄은 마법·희귀 등급의 [일반 장비 9부위](../modules/data/equipment-runtime-tables.mjs)에 적용한다. 무기, 투구, 갑옷, 장갑, 신발, 완갑, 반지, 목걸이, 허리띠가 대상이다. 천칭은 그 부위와 베이스에 원래 붙는 후보 중에서 굴리고, 금줄은 그 장비의 기본 재화 제작 후보에만 적용한다. 비기 각인은 같은 룬 강화 효과가 여러 부위에서 중첩되는 것을 피하기 위해 첫 플레이테스트에서 마법·희귀 무기에만 허용한다.

| 항목 | 설계 |
| --- | --- |
| 해금과 재료 | 루프 5부터 열 수 있는 기존 **화석 복원**을 해금하면 복원 화면에 전이석 교환을 표시한다. 미궁 화석 10개와 봉인편린 1개로 전이석 1개를 확정 교환한다. 봉인편린은 고대 미궁에서 루프 6부터 떨어지므로 교환 화면에 획득 조건을 안내한다. 전이석을 처음 얻으면 제작실 재화 보관함에 칸이 드러나고, 분갈이 한 번에 전이석 1개를 쓴다. |

| 결과 | 선택한 줄 하나에만 분갈이 출처를 기록한다. 성공은 확정이며 난수 굴림은 없다. 옵션 ID와 태그·T·값·굴림 범위·전체 줄 수는 그대로다. 원래 접미어였던 능력치의 중복 제한도 계속 적용한다. |
| 다시 사용 | 같은 장비에 분갈이 줄이 남아 있으면 재사용을 막는다. 수치만 바뀌면 출처가 남는다. 줄 자체가 제거·교체되면 다시 쓸 수 있다. 다른 세공의 줄과 각각 공존할 수 있다. |

### 실제 무기와 제작 화면

아래는 현재 베이스인 희귀 혈각 한손검에 붙을 수 있는 추가 옵션 예시다. 베이스 자체의 능력치는 표에서 생략했다.

| | 분갈이 전 | 정확도를 선택하고 적용한 뒤 |
| --- | --- | --- |
| 접두어 | 물리 기본 피해 +38 · 화염 피해 +18% · 빈 칸 | 물리 기본 피해 +38 · 화염 피해 +18% · **정확도 +330 [분갈이]** |
| 접미어 | 공격 속도 +15% · 치명타 피해 배율 +45% · **정확도 +330 (T4)** | 공격 속도 +15% · 치명타 피해 배율 +45% · **빈 칸** |

옮긴 정확도는 T4다. 사용 직후 무기의 전투 능력과 추가 옵션 수(5/6)는 같다. 이 예시에서 수액 봉오리를 한 번 더 쓰면 남은 접미어 한 칸에 적법한 일반 옵션을 굴린다. 치명타 확률을 노릴 수 있고 다른 접미어가 나올 수도 있다. 빈 접두어를 물리 피해에 쓸 계획이라면 분갈이 전에 이 선택을 비교할 수 있어야 한다.

희귀 반지에서는 기존 일반 접미어인 '모든 원소 저항 +8%'를 빈 접두어로 옮길 수 있다. 빈 접미어에서는 치명타 확률을 노릴 수 있고, 옮긴 칸을 최대 생명력에 쓸 기회는 소모한다.

장비를 고르고 재화 보관함의 **특수 제작 → 장비 세공 → 전이석**을 누르면 기존 선택 영역에서 '분갈이'와 옮길 수 있는 줄을 보여 준다. 줄 선택 후 기존 **사용** 버튼의 확인창에 이름·수치·등급, 전후 칸 수(`접두 2/3 → 3/3`, `접미 3/3 → 2/3`), 전이석 보유량과 비용을 표시한다. 모바일에서는 같은 정보를 위아래로 놓는다. 재료가 없으면 **전이석 부족 (0/1)**을 붉게 표시한다. 빈 접두어가 없거나 이미 분갈이한 장비면 해당 사유를 보여 준다. 확인 직전에 장비·선택 줄·잔액을 재검사한 뒤 한 번만 적용하고 제작 결과에 남긴다.

### 구현과 인수 조건

- 출처는 아이템 플래그 대신 옮긴 옵션의 `craftSource`에 둔다. 유효한 분갈이 줄의 현재 자리는 [종류 판정](../modules/domain/equipment-craft-rules.mjs)의 `craftStoredAffixKind`가 접두어로 반환한다. 원래 옵션 정의는 그대로 사용한다. 이미 붙은 줄을 대상으로 할 때 `row.mod.type`을 직접 읽는 [무기 세공](../modules/domain/weapon-finishes.mjs) 등도 이 판정을 사용한다. 새로 뽑을 후보의 기본 자리는 기존 정의를 따른다.
- 접두어만 대상으로 하는 허기의 뿌리 제작에서는 옮긴 줄이 선택될 수 있고, 접미어만 대상으로 하면 남는다. 황금률로 수치만 바꾸거나 잠금으로 보존되면 자리와 출처를 유지한다. 전정 가위로 줄을 지우거나 전체 재련으로 줄이 사라지면 분갈이가 다시 열린다. 메아리 복사가 허용되는 경우 복사 줄에는 메아리의 출처를 쓰고 원본의 분갈이 자격을 복제하지 않는다.
- 저장 왕복·기억 조각칼 복원·장비 전당 등록과 열람에서 T4 정확도, 접두/접미 개수, 재사용 제한을 비교한다. 전당 검증에서도 해당 부위와 베이스에 허용된 일반 접미어만 분갈이 줄로 인정하고, 수치 범위와 분갈이 줄 한 개 제한을 검사한다. 출처가 없는 옛 저장은 이전 규칙으로 센다. 잘못된 표식 때문에 기존 장비를 삭제하거나 정상 분갈이 권한을 부여하지 않는다.
- 무기·방어구·장신구에서 미리보기와 실제 제작이 같은 부위 조건을 따르는지 확인한다. 완갑은 기존 저장 부위 키를 그대로 사용한다. 반지 예시에서 분갈이는 허용되고 비전서는 무기 전용 안내와 함께 보유량이 유지되어야 한다.
- 희귀 5줄 예시의 실제 장착 능력치 전후 일치, 봉오리로 여섯째 줄을 붙여도 정확도 중복 없음, 마법 1/1 제한, 접두 가득 참·잠긴 대상·이미 사용·재료 부족·확인 중 대상 변경·연속 탭에서 장비와 재화가 중복 변경되지 않는 것을 검증한다. 첫 밸런스 검토에서는 분갈이 후 선택하는 네 번째 접미어 종류와 포기한 공격 접두어의 가치를 비교한다.

### 재화 보관함에서의 세공

기존 **특수 제작** 탭 안에 **장비 세공** 묶음 네 칸을 둔다. 칸과 제작법은 `전이석 → 분갈이`, `비전서 → 비기 각인`, `천칭의 추 → 천칭 제련`, `금줄 → 금줄`로 고정한다. 제작실에서는 선택한 완성 재화 한 개만 차감한다. 원재료는 각 콘텐츠에서 교환할 때 차감한다. 기존 퀄리티 탭의 기폭제를 누르면 종전처럼 퀄리티 제작이 선택된다.

비전서의 기술, 추의 계열, 금줄의 속성은 획득할 때 정해진다. 보관함은 같은 재화의 보유량을 합산해 한 칸에 표시하고, 누르면 기존 선택 영역에 보유한 종류와 수량을 보여 준다. 한 종류만 있으면 바로 선택한다. 예를 들어 이중 베기 비전서 1권과 강타 비전서 2권을 가졌을 때 칸에는 3권, 이중 베기를 선택한 사용 버튼에는 1/1이 표시된다. 사용 시 해당 종류만 하나 차감한다. 저장에는 종류별 실수량만 두고 합계는 표시할 때 계산한다.

네 세공은 [재화 보관함](../modules/ui/crafting-stash-view.mjs)에서 선택하고 [제작실](../modules/ui/crafting-workspace-controller.mjs)의 사용 버튼으로 적용한다. 미리보기에서 대상 줄과 변화를 확인한 뒤 승인하면 선택한 종류의 재화 한 개를 쓴다. 세공한 줄이 사라지면 그 종류를 다시 쓸 수 있다. [체험용 게임](../tests/fixtures/world-tree-atlas/index.html?review=finishes)에는 희귀 대검과 반지, 세공 재료가 들어 있다.
