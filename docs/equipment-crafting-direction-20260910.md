# 장비 옵션 표시와 특수 제작 방향 — 2026-09-10

## 적용한 변경

- 일반 고정 옵션의 `고정` 문구를 `[T0]` 배지로 변경한다. 실제 티어 계산/수치는 바꾸지 않는다.
- 화석·균열 홀씨의 젬 레벨/보조 젬 한도 +1 및 이전 저장의 특수 옵션도 T0로 표시한다.
  모든 티어에서 같다는 정의가 있어야 T0다. 한 티어의 최소/최대가 같다는 이유만으로 T0로 만들지 않는다.
  기존 고유 장비의 tier 0 `[U]` 표시는 유지한다.
- 장비 상세/비교에서 현재 주력 스킬에 적용되지 않는 공격·주문 전용 옵션을 흐리게 표시한다.
  이유 문구는 추가하지 않는다. 결투의 규율은 주문 피해 증가만 공유하고 주문 기본 피해/치명타 피해/흡수까지 공유하지 않는다.
  생명력 흡수를 막는 혼의 성소도 반영한다. 방어·속성 전환·소환수 등 미검증 옵션은 무효라고 단정하지 않는다.
  소환 젬을 함께 장착한 경우에는 혼합 피해 경로를 오판하지 않도록 흐림 표시를 보수적으로 생략한다.
- 기존 cachedTooltipStats를 읽고 상세창을 렌더할 때만 판정한다. 옵션마다 전체 스탯을 재계산하거나 전투 틱 작업을 추가하지 않는다.
- 속성 홀씨 후보에 해당 속성 기본 피해를 추가한다. 피해 홀씨에는 일반/물리/주문/속성 기본 피해 및 공격·주문 피해 증가를 추가하고 물리 피해 감소(dr)를 제외한다.
  부패 홀씨의 원소 옵션 제거 후보에도 원소 기본 피해를 포함한다.
- 홀씨 보장 옵션은 `getCraftTierRangeForItem(item, 'spore')`의 전체 범위에서 굴린다.
  T20 장비는 기존 T19~20 보장에서 T9~20으로 변경한다. 기존 장비 수치는 소급 변경하지 않는다.
  나머지 옵션은 기존 일반 제작 규칙을 사용한다.

## 종류별 제한과 재제작 — 적용한 정책

- 사용자는 장비 하나에 홀씨 효과 1개, 화석 효과 1개, 이식 효과 1개가 공존하는 방향을 선택했다.
- 홀씨·화석은 같은 출처의 옵션이 있으면 추가형 제작을 차단하고, 전체 재련은 다시 사용할 수 있다.
  전체 재련은 기존처럼 잠기지 않은 옵션을 다시 굴린다. 다른 출처라는 이유만으로 자동 보존하지 않는다.
- 균열 홀씨는 재료가 홀씨여도 **화석 옵션 1개 제한**에 포함한다. 홀씨 옵션과 공존할 수 있지만 기존 화석 옵션이 있으면 추가할 수 없다.
- 잠긴 같은 출처 옵션이 남아 중복되는 재련은 차단한다. 균열 화석의 표식+증폭은 두 줄을 차지하는 하나의 효과다.
  같은 균열 화석의 재련은 기존 표식을 유지하며 허용한다. 증폭 자체가 잠겼다면 차단한다.
- 보장 옵션을 넣을 공간이 부족한 재련도 차단한다. 모든 거절은 재화 소비·장비 변경 전에 처리한다.
- 새 홀씨/화석 보장 옵션에는 `craftSource`를 저장하고 상세창에 출처를 표시한다.
  제작창, 모바일 선택기, 결과의 ‘다시 사용’ 버튼은 동일한 규칙을 사용한다.
- 이식은 이식 옵션이 있는 장비에 재이식 불가로 확정했다. 공통 출처 규칙에는 반영했지만 실제 이식 기능은 아직 구현하지 않았다.
- 이식 제안: 군락지 클리어로 접목 재료를 얻고, 장비 제작에서 같은 부위의 재료 장비를 소모해 일반 옵션 한 줄을 옮긴다.
  대상의 장비 티어 상한을 적용하고, 고유 효과/다른 특수 제작 효과의 복사는 막는다.
  해금 시점·보상량·비용·실패 여부·일반 6옵션에 포함되는지는 미확정이며 아직 변경하지 않았다.
- 출처 추적이 없는 이전 제작 옵션은 티어/수치만 보고 홀씨산이라고 추측하거나 삭제하면 안 된다.
  알려진 화석·균열 홀씨 표시는 저장 복원 시 화석 출처로 인식한다. 출처를 모르는 기존 일반 홀씨 옵션은 그대로 유지한다.
  출처 규칙은 `js/equipment-crafting.js`, 상태 계약은 `js/state.js`, 실제 소비·재련은 기존 제작 도메인이 소유한다.

## 융합 구현과 의도의 차이

사용자 의도는 '고유 효과만 이전'하여 완성 희귀 장비와 고유 장비가 경쟁하는 것이다.
현재 `js/items.js`의 `resolveTimeRiftFusion`은 고유 아이템 전체를 복제한 뒤 희귀 옵션을 덧붙인다.
따라서 고유의 일반 추가 옵션도 남는다. 이번 표시/홀씨 패치에서는 이 규칙과 기존 융합 장비를 변경하지 않았다.
고유 경쟁력 조정 전 이 차이를 해결해야 한다.
