# 고레벨 젬 성장과 강화 확률

## 레벨의 가치

1~19레벨은 유지한다. 19→20부터 레벨 상승으로 얻는 증가량을 기존보다 10% 높인다.
장비와 퀄리티를 포함한 최종 피해에 1.1을 곱하지 않는다.

예를 들어 기존에 레벨당 3 증가하는 보조 젬은 20레벨부터 3.3씩 증가한다.
기존 성장 스텝은 19레벨 18, 20레벨 19, 30레벨 29였고,
변경 후에는 각각 18, 19.1, 30.1이다. 실제 젬 레벨 표시는 정수 그대로다.

- 공격 젬의 피해, 속도, 레벨별 치명타 증가와 보조 젬의 효과 및 레벨별 한도에 적용한다.
- 주문 내장 피해의 선형 성장과 기존 로그 곡선은 각각 19레벨 이후 증가분만 높인다.
- 소환수는 피해, 생명력, 방어도, 회피의 기존 성장 곡선을 유지하며 19레벨 이후 증가분만 높인다.
  특히 21~30과 31 이상 구간의 성장 차이를 유지한다.
- 장비에서 추가한 고정 피해와 고정 효과, 기존 레벨 20 특전은 별도로 유지한다.
- 컨디션 젬은 최대 5레벨이므로 해당 구간이 없다. 경험치 요구량도 바꾸지 않는다.

계산은 `skills.js`의 공통 성장 함수가 소유하며 전투와 툴팁이 같은 함수를 사용한다.
주문 내장 피해의 기존 중복 계산을 공통 함수로 모았다. 추가 순회나 매 프레임 UI 갱신은 없다.

## 강화

군주의 핵과 창공의 힘 모두 +1부터 100%, 60%, 40%, 20%, 10%로 시작한다.
첫 실패는 10%p, 이후 증가폭은 9.6, 9, 8.2, 7.2, 6%p로 줄어들고 최소 5%p를 유지한다.
+5는 10→20→29.6→38.6→46.8→54→60% 이후 5%p씩 증가해 100%에 도달한다.
저장 시 실패 횟수 상한도 단계별 기본 확률에서 계산해, +5는 14회 실패까지 유지한다.
기존 성공 단계와 실패 횟수는 유지하고, 다음 시도부터 새 기본 확률을 사용한다.

## 검증

- `scripts/smoke-gem-level-value.js`: 61종 스킬과 50종 보조 젬의 19/20 경계와 보너스 레벨,
  소환수 곡선, 장비 고정 피해 불변, 실제 보조 젬 한도, 양쪽 강화 시작 확률.
- `scripts/smoke-gem-core-forge.js`: 실패 후 저장 복원과 천장 성공, 재료 소모, 최대 강화 차단.
- `tests/browser/gem-selection-flow.spec.js`: PC와 모바일에서 확률 표시와 실패 누적, 최대 강화까지 조작.
- `npm test`, `npm run check:architecture`.
