# 저널 삽화 그림체 통일 · 2026-09-10

프롤로그를 기준으로 나머지 저널 삽화 10장을 내장 image_gen 도구로 편집하고 개발본에 연결했다.
프롤로그와 기존 10장 원본은 수정·삭제하지 않았다. 생성 모델의 실제 버전은 도구 인터페이스에서 확인되지 않았다.

## 기준과 범위

스타일 기준은 `assets/journal/prologue.webp` 한 장이다.
밝은 상아색 종이, 가는 검은 펜선, 성긴 곡선 해칭, 제한적인 교차 해칭, 섬세한 꽃무늬 테두리에 맞췄다.
후반부의 검은 면과 긁어낸 듯한 굵은 목판화 질감을 밝은 종이 위의 펜선으로 다시 그렸다.
각 이미지의 장면·시점·인물 배치·서사 소품을 유지하도록 지시하고 결과를 원본과 비교했다.
보랏빛 길과 금빛 후광은 작은 서사 포인트로 유지했다. 모든 픽셀이 보존되는 색상 필터 방식은 아니다.

- 기준 원본: `assets/journal/prologue.webp` (변경 없음).
- 새 게임용 파일: `assets/journal/unified-20260910/`의 act-2, act-3, act-4, act-5, act-6,
  act-7, act-8, act-9-start, act-9-end, act-10 WebP 10장.
- 원본 및 출력 규격: 모두 1254×1254, 실제 불투명 이미지.
- 출력은 생성 결과를 필요한 경우 같은 크기로 리샘플링하고 WebP 품질 92로 인코딩했다.
  코드로 선·색·그림을 덧그리거나 생성 결과 일부를 합성하지 않았다.
- 새 10장 합계 6,804,072바이트(기존 6,035,018바이트). 가는 선 보존을 위해 기존보다 약 12.7% 큰 출력을 채택했다.

## 게임 연결

`data/story-journal.js`에서 이미지 경로 10개만 바꿨다.
장면 id·제목·본문·act·phase·journal, 해금·보상·재생 규칙은 유지한다.
`index.html`에서 해당 데이터 스크립트 버전만 갱신해 이전 캐시를 피한다.
스크립트 순서·게임 전역·의존성·저장 shape·CSS·표시 로직은 추가하거나 변경하지 않았다.
프롤로그는 계속 원본 경로를 사용한다.

현재 act-9-start/end 파일과 장면 문구의 기존 연결 관계도 그대로 유지했다.
파일명과 실제 그림 내용의 관계를 이번 스타일 작업에서 임의로 재배치하지 않았다.

원본 크기 열기 및 파일 다운로드.

주소: http://127.0.0.1:4216/artifacts/journal-style/index.html
저장소의 `scripts/serve-test.js`를 PLAYWRIGHT_PORT=4216 환경 변수와 함께 실행한다.
비교 화면은 catalog.json을 읽으므로 HTTP 서버로 연다.

작업용 자료는 gitignored `artifacts/journal-style/`에 있다.

- `catalog.json`: 원본 경로·SHA-256·장면 메타데이터와 새 경로.
- `generations/*.json`: 각 장의 **최종 전체 프롬프트**, 내장 도구의 생성 파일 경로.
- `generated/*.png`: 채택한 생성 원본을 작업 폴더에 복사한 파일.
- `pack.cjs`, `asset-report.json`: 출력 인코딩과 해시·용량.
- `verify.cjs`, `verification.json`: 원본 보존, 규격, 내용·연결·표시 상태 검사.
- `runtime.html`, `runtime.js`: 실제 story-journal-ui.js와 story-journal.css를 불러오는
  독립된 렌더링 검증 페이지. 저장/게임 진행을 실행하지 않는다.
  escapeHTML만 js/ui.js에서 그대로 복사한 QA 의존성으로 제공하며 프로덕션에서는 사용하지 않는다.

## 검증

- 11개 원본 SHA-256 유지, 10개 출력 전체 디코딩·1254×1254·불투명도 확인.
- 원래 장면 문구·id·메타데이터 유지, 실제 renderTutorial의 새 이미지 출력과 게임 상태 불변 확인.
- `node scripts/smoke-story-fx-import.js`: 통과.
- `node scripts/smoke-journal-progression.js`: 통과.
- `npm test`: 최종 재검사 182/182 통과. 동시 진행 중이던 별도 패시브 작업의 변경 이후 확인했으며,
  이번 저널 변경에서 해당 패시브 파일·검사는 수정하지 않았다.
- 실제 브라우저: 프로덕션 저널 표시 함수를 통해 11개 장면의 이미지·본문 정상 로드, 최종 검증 페이지 오류·경고 없음.
- 390×844 모바일에서 삽화와 본문이 세로로 배치되고 본문 가로 넘침이 없음을 확인.
- JS 구조 변화 없이 이미지 경로와 캐시 버전만 변경해 아키텍처 검사는 별도로 반복하지 않았다.

그림체 일치도는 원본과 생성 결과의 시각적 검토에 근거하며 자동 검사 수치로 보장하지 않는다.
원복하려면 catalog.json의 original 이미지 경로로 데이터 연결만 되돌리면 된다.
