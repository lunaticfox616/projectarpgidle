# 룬 강화

창공의 정수로 룬을 20강까지 올린다(2026-11-02 사용자, 군주의 핵 강화는 없앴다). 수치와 표는 `data/gem-core-forge.js`가 소유한다.

- 효과: 단계마다 공격/시전 속도 +2%, 10강 위로 단계마다 피해 +4%, 5강마다 룬 레벨 +1. 다른 계수와는 곱한다. 소환 공격 룬은 소환수 피해와 공격 주기에 적용한다.
- 성공률, 비용, 파괴 확률은 단계별 표다. 파괴는 10강부터 있고, 성공 확률이 오르면 남은 몫 안에서만 파괴된다.
- 실패 보정: 실패할 때마다 표대로 오르고(10강부터 0.75배) 성공하거나 파괴되면 초기화한다. 룬 기록의 `enhanceFailures`에 저장한다.
- 군주의 핵: 한 번에 10개까지, 하나당 성공 확률 +2%p. 실패해도 소모한다.
- 담금질(미니게임): 값은 멈춘 뒤에 치르고, 칸 안에서 멈추면 성공 확률에 1.05를 곱한다. 닫거나 오래 두면 값을 치르지 않고 접는다.
- 파괴: 강화가 +0이 되고 여분(`runeSpares`)을 하나 쓴다. 여분이 없으면 룬이 목록과 장착 칸에서 빠진다. 룬 레벨, 퀄리티, 각인은 이름에 남아 다시 얻으면 이어진다.
- 저장: `gemData[이름].enhanceLevel`. 옛 저장의 `bossCoreLevel`, `skyCoreLevel`은 불러올 때 합쳐 옮긴다(`normalizeRuneEnhanceLevel`). 강화와 여분은 루프가 비운다.

## 여러 개 소지

`game.skills`는 이름 목록 그대로이고, 같은 룬을 더 얻으면 `runeSpares[이름]`만 는다(`js/gem-drop-rewards.js`). 강화와 레벨은 쓰는 하나에 쌓인다.
가진 공격 룬도 드랍, 하켄, 암시장, 시련 보상에 나온다. 액트 보상의 룬은 이미 있으면 스킬트리 포인트로 바뀌는 규칙을 유지한다. 보조스킬룬은 여러 개를 갖지 않는다.

## 구현 경계

- `js/gem-core-forge.js`: 효과, 가능 여부, 강화 상태 전이. UI 의존 없음.
- `js/gem-core-forge-ui.js`: 강화 창과 담금질. 판정과 지불은 멈춘 순간 끝나고, 결과는 연출 뒤에 공개한다. 상시 타이머는 없다.
- `css/gem-core-forge.css`: 단계 색(5, 10, 15, 20강), 창의 연출, 룬 그림의 단계 표시(`data-forge-tier`). 픽셀 스킨이 모서리를 없애므로 고리는 그라디언트로 그린다.
- `js/canvas-stage-skill-polish.js`: 주 공격 룬의 시전 빛(10강부터)과 주인공 몸의 빛(15강부터). 그림만 더한다.
