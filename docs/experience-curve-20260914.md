# 레벨별 경험치 분리

## 적용

- 필요 경험치와 몬스터 기본 경험치를 `data/level-progression.js`의 독립된 수치표로 분리했다.
- 레벨 1~10의 필요 경험치와 몬스터 보상은 유지한다.
- 11~100은 기존 필요 경험치에 점진적인 증가분을 반영한 실수치다.
  10레벨 단위 누적 증가분은 20레벨 +5% / 30레벨 +15% / 40레벨 +30% /
  50레벨 +50% / 60레벨 +75% / 70레벨 +105% / 80레벨 +140% /
  90레벨 +180% / 100레벨 +225%다. 각 구간 안에서는 증가분을 선형으로 연결했다.
  런타임에서 기존 필요 경험치에 배율을 곱하지 않는다.
- 101부터는 새 100레벨 필요 경험치에 기존 상승식
  `floor(4200 * (level - 100)^1.85 + 900 * (level - 100)^2)`를 더한다.
- 몬스터 1~100레벨의 기본 보상은 기존 수치를 고정했다. 101~200은
  `7272.36 + 200.4*d + 1.2*d²`로 설계한 독립 실수치표다 (`d=level-100`).
  이전의 레벨당 72.72 보상 증가안은 후반 반복 부담이 커서 완화했다.
  200 이후는 마지막 증가 폭인 439.2로 선형 연장한다.
  고레벨 필요 경험치의 급등이 보상에 복제되지는 않는다.
- 기본 보상의 소수 부분은 루프 가속을 적용하기 전의 기존 반올림 순서를 보존하기 위한 것이다.
  실제 지급은 기존처럼 각 단계에서 내림한 정수다.

## 비교

현재 레벨에서 다음 레벨로 가는 필요 경험치다. 처치 수는 같은 레벨의 일반 몬스터만
잡는 계산이며 루프 가속과 장비 보너스와 정예/보스 보상은 제외한다.
실제 시간이나 플레이 난이도 측정은 아니다.

## 경계와 영향

- 저장 필드는 바꾸지 않는다. 기존 레벨과 획득 경험치와 패시브 포인트를 그대로 보존한다.
  필요 경험치가 늘어난 레벨에서는 경험치 게이지 비율이 낮아질 수 있다.
- 정예/보스 보너스와 루프 가속과 레벨 차이 감소 규칙은 그대로다.
- 온라인과 방치 정산은 같은 보상 함수를 사용한다.
- 몬스터 1~100레벨에서 받는 젬 경험치는 유지한다.
  101 이상 몬스터에서는 기본 보상을 분리한 만큼 젬 경험치도 분리 전보다 적어진다.
  젬 자체의 후반 필요 경험치는 아래 표로 별도 조정한다.
- 레벨에 따른 장비 착용과 패시브 포인트 획득은 후반에 늦어진다.
  필요 경험치의 10%인 기존 사망 경험치 손실도 함께 증가한다.
- 스크립트 순서는 유지한다. `skills.js`의 `gainGemExperience`를 명시적으로 노출하여
  전투의 세 젬 종류가 같은 경험치 이월 규칙을 사용한다.

## 젬 성장

루프마다 젬을 다시 키우는 현재 규칙을 고려하여 초반 재육성은 빠르게 유지하고
최종 레벨은 추가 투자 목표로 둔다. 이미 얻은 젬 레벨은 내려가지 않는다.

| 성장 구간 | 필요 경험치 |
| --- | ---: |
| 1→14 | 각 레벨의 기존 요구량 유지 |
| 14→15 | 10000 |
| 15→16 | 28000 |
| 16→17 | 75000 |
| 17→18 | 190000 |
| 18→19 | 480000 |
| 19→20 | 1200000 |

레벨업할 때 초과 경험치를 버리던 처리를 제거했다.
한 번의 보상으로 여러 레벨을 오를 수 있으며 20레벨에서 멈춘다.
공격/소환/보조 젬에 동일하게 적용하고 품질과 각성 등의 다른 필드는 보존한다.
보조 젬의 각인사 경험치는 실제 오른 레벨 수만큼 기존 행동 보상을 적용한다.

### 밸런스 검증의 한계

이 수치는 플레이테스트 전 첫 조정안이다. 분당 처치 수를 실제 유저 속도로 단정하지 않는다.
기존 초반 전투 재생 검사에서 8레벨의 세 직업을 각각 난수 시드 3개로 60초씩 실행했다.
시나리오별 4~8마리 처치와 사망 0회를 확인했다. 이 초반 수치를 후반 시간으로 환산하지 않는다.
후반은 같은 레벨에서의 처치 부담과 루프 가속 적용을 비교했다.
루프 41의 최대 가속을 포함하면 150레벨의 일반 몬스터 기준 다음 레벨까지 약 140마리다.
같은 조건에서 젬 19→20은 약 44마리다. 캐릭터 최종 성장과 젬 완성을 같은 시간 목표로 두지 않았다.
고정 시드의 액트 1~10 진행에서 캐릭터는 루프 1에 레벨 19 / 루프 10에 레벨 23 /
루프 41에 레벨 29로 나왔다. 기존 초반 진행 검사도 통과한다.

참고한 ARPG 원칙은 사냥 난이도를 높일 때 경험치 보상도 함께 늘어나되
캐릭터 요구량과 별도로 관리하는 것이다.
[Last Epoch 공식 경험치 안내](https://support.lastepoch.com/hc/en-us/articles/46361669693595-Player-Experience)는
적 등급에 따른 보너스와 높은 지역에서 얻는 경험치 제한을 별개로 설명한다.
해당 게임의 레벨 상한이나 수치를 이 게임에 그대로 복사하지 않았다.

## 검증

- `node scripts/smoke-experience-curve.js`: 초반 보존과 구간별 상승과 101 이후 증가분 보존.
  정예/보스와 루프 보너스 적용. 기존 저장 복원. 한 경험치 부족 및 정확한 레벨업 경계.
- `node scripts/smoke-level-progression.js`: 기존 레벨 차이 보상과 장비 요구 조건.
- `node scripts/smoke-gem-growth.js`: 세 젬 종류의 경계와 이월 경험치와 여러 레벨 상승과 최대 레벨과 저장 복원.
- `npm test`: 197개 통과.
- PC와 모바일에서 새 경험치 표시와 젬 14→15 전투 레벨업 후 경험치 이월을 확인했다.
  브라우저 오류 없음. 검증 결과는 `artifacts/gem-growth-*.log`에 기록한다.
- `npm run check:architecture`: 구조 및 린트 검사 통과.
- PC와 모바일에서 초기 진입 및 10/11/20/50/100/101/150레벨 경험치 게이지와 필요 경험치 표시를 확인했다.
  브라우저 오류 없음. 결과는 `artifacts/experience-browser.log` 및
  `artifacts/experience-architecture.log`에 기록했다.
