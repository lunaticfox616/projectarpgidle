# 권역별 탐험 진입 개편

## 변경 의도

하나의 세계수 배경 위에 나무·지하계·심해·우주계를 얹었던 화면을 제거한다.
해금한 권역만 별도 전투 배경, 이름, 실제 진행 기록을 가진 카드로 표시한다.
새 아이콘이나 새 전투 규칙은 추가하지 않는다.

## 적용 범위

- `data/world-tree-journey.js`: 기존 권역 정의가 배경 경로·주변 콘텐츠 분류를 소유한다.
  기존 좌표는 제거했다. 계별 배경은 현재 사용하는 refined-20260910 WebP를 재사용한다.
- `js/exploration-atlas-ui.js`: 전체 목록과 권역 상세를 분리한다. 목적지가 하나면 바로 진입하고,
  여러 개면 그 권역의 탐험·주변 콘텐츠만 표시한다. 별도 지역에도 전용 배경과 진행 요약을 표시한다.
  기존 지도 전환 handler, 해금, 입장권, 전투 결과는 재사용한다.
- `css/exploration-atlas.css`: PC 2열/모바일 1열 카드와 지역별 색상을 사용한다. 전체 그림 지도와
  절대좌표 배치는 제거했다. 기존 지도 이미지 숨김 규칙은 권역 배경에 적용하지 않도록 한정했다.
- 신규 저장의 지도 기본 선택은 액트 사냥터다. 첫 사냥터 발견 전 지도 잠금은 유지한다.
  기존 저장에 명시된 마지막 지도 선택은 유지하며 저장 형식은 추가하지 않는다.
- 시연의 `첫 여정`은 루프 1의 기본 캐릭터로 전투부터 시작한다. `후반 권역`은 진입 확인용
  강화 장비와 해금 상태를 사용하며 실제 저장과 분리된다. `?review=regions`는 후반 권역으로 시작한다.

## 권역 내부 보강

- 전체 목록 아래 최종 관문을 제거했다. 실제 보스는 기존 `강대한 적` 목록에 유지한다.
  사용하지 않는 관문 선택 상태·전역 메서드·CSS·권역의 pinnacle 연결도 함께 제거했다.
- `액트를 따라 전진` 등 진행 안내와 전체 목록의 장식 문구를 삭제했다.
- 나무 상세의 액트 사냥은 도달한 액트의 실제 배경·이름·열린 액트 번호·수령 가능한 보상 수를 표시한다.
  보상 수는 기존 해금 필터를 거친 getAvailableActRewardZoneIds를 사용한다.
- 보스는 실제 격파 기록과 조건/입장권 충족 수, 전직은 완료한 시련 수,
  벌집은 열쇠와 진행 갈림길, 군락지는 최고 도달 웨이브와 보유 흔적을 표시한다.
- 카드 클릭은 해당 콘텐츠의 준비 화면을 열며 재화를 사용하지 않는다. 실제 입장 버튼이 기존 비용·조건을 판정한다.
- 상단 배경 높이를 낮추고, 선택 카드의 제목·특징·현재 상태·행동을 구분했다.
- 현재 화면의 HTML만 만들어 비교하며, 숨겨진 다른 권역 내부 요약은 계산하지 않는다.
  스탯/DPS 계산·타이머·새 저장 필드는 없다. 기존 전역 스크립트 순서도 유지한다.

## 경계와 성능

UI는 기존 진행 필드와 공개 지도 정의를 읽는다. 새 스탯 계산·전투 타이머·보상 지급은 없다.
권역 카드는 지연 이미지 로딩과 기존 DOM 변경 시그니처를 사용한다. 같은 배경 URL은 재사용한다.
벌집·균열·운석의 기존 발견/해금 규칙을 유지하며, 모든 권역에 새 경로 생성 시스템을 만든 것은 아니다.
기존 지역 내부의 층 선택·잠수·항로 시스템도 유지한다. 이번 변경의 중심은 구분감과 탐험 진입이다.

## 동선·보상 중심 후속 리뷰

- 현재 사냥터와 `전투로 돌아가기`를 전체 목록과 권역 상세에 표시한다. 이는 기존 전투 화면 전환이며
  현재 전투를 다시 시작하거나 입장권을 소모하지 않는다. 별도의 최근 사냥 기록은 저장하지 않는다.
- 액트 카드에 `이 지역 사냥`과 `사냥터 선택`을 나누고, 받을 보상 버튼은 기존 보상 선택창을 직접 연다.
  이미 사냥 중인 같은 액트로 이동할 때는 진행을 초기화하지 않는다.
- 직접 입장은 열린 정수 액트만 허용한다. 루프 대기·벌집 원정 잠금·경계 너머 도전 중에는 이동하지 않는다.
  실제 이동은 기존 changeZone 경계를 거치며, 유료 콘텐츠의 입장은 여전히 준비 화면에서 한다.
- 보스 카드에 조건/입장권을 충족한 미격파 보스를 우선 표시하고 기존 보상 정의를 읽는다.
  보상이 숨겨진 성장 기능에 연결되면 표시하지 않고, 최초 보상과 이미 수령한 보상을 구분한다.
- 벌집의 옵션 고정, 군락지의 방어 부적, 전직의 최초 포인트 보상을 짧게 구분한다.
  도감에 이미 지정한 파밍 목표는 기존 uniqueHuntRuntime.getEntry와 uniqueHuntUi.getSource로 해당 카드에 표시한다.
  최대 3개만 조회하며 새 추적 상태·타이머·스탯 계산은 없다. 두 생산 스크립트는 atlas UI보다 먼저 로드된다.
- 리뷰 중 상태 숫자가 바뀌면 키보드 포커스가 사라지는 문제를 발견했다. 버튼 문구 대신 동일한 동작을 기준으로 복원한다.
- 나무 제목의 중복 배경을 접고 액트 배경을 중심으로 공간을 배분한다. 아이콘과 새 애니메이션은 추가하지 않았다.
- 모바일 전투 미리보기가 표시되면 탐험 카드의 복귀 버튼을 숨겨 중복 조작을 줄인다.
  미리보기 설정을 끄면 복귀 버튼을 다시 표시한다. 기존 미리보기 DOM의 display 계약을 CSS에서 사용한다.

검증 범위: PC/모바일 직접 입장과 중복 진입, 잘못된 액트/루프 대기 거부, 전투 복귀 시 상태 유지,
실제 파밍 추적 표시, 숫자 갱신 후 포커스 유지, 보상 선택창 직접 열기·나중에 닫기, 기존 보스 입장권과 진행 조건.
남은 UX 과제는 보스 목록 내부의 개별 보상 비교이며, 이번에는 권역 선택 화면과 연결 동선을 개선했다.

검증 결과: 관련 브라우저 12/12, 모바일 중복 버튼·설정 해제 후 복원 추가 검사 2/2,
전체 스모크 190/190, runtime architecture/lint 검사 통과. 공개 배포·PR 변경은 하지 않았다.

## 공간 밀도 조정

- 탐험 헤더·현재 사냥터·지역 제목의 여백, 지역 카드의 최소 높이와 카드 사이 간격을 줄였다.
- 콘텐츠 진입 문구는 제목 오른쪽에 배치하고 보상·입장 조건은 전체 폭으로 유지한다.
- 액트 사냥 버튼은 가로로 배치하되 좁은 폭에서는 줄바꿈한다. 모바일 사냥 버튼 높이는 최소 36px이며 본문 글자 크기는 유지한다.
- 1048×742 PC 미리보기의 같은 나무 상세 구성은 높이 약 675px에서 500px로 감소했다.
  393×851 모바일에서도 권역 목록, 하단 콘텐츠 스크롤 및 보상 버튼이 추가되는 상태를 시각 확인했다.
- CSS와 캐시 버전만 변경하여 저장·입장·보상 규칙과 초기화 순서 영향은 없다.

검증: exploration-regions 브라우저 검사 PC/모바일 6/6, 전체 스모크 190/190,
git diff --check 통과(CRLF 정규화 경고만 존재). JS 구조 변경이 없어 architecture 재실행은 생략했다.

## 콘텐츠 정체성과 읽기 순서

- 첫 권역 선택 화면은 유지한다. 상세에서는 작은 동등한 텍스트 줄이 반복되어 콘텐츠 성격과 보상이 구별되지 않는 문제를 수정했다.
- 보스전·갈림길 원정·생존전·루프 등반·영구 등반 등 플레이 방식과 한 문장 설명을 기존 WORLD_TREE_JOURNEY 데이터가 소유한다.
  UI의 중복 routeDescription 사전과 사용하지 않는 summary.detail을 제거했다.
- 콘텐츠 이름은 21px로 강조하고 플레이 방식의 색조, 짧은 행동 설명, 주요 보상, 하단 입장 조건 순서로 구분한다.
  색상만으로 구분하지 않으며 같은 정보는 텍스트로도 표시한다. 아이콘·애니메이션·추가 이미지 요청은 없다.
- PC에서는 같은 분류를 가로 2열로 묶고 모바일에서는 1열로 전환한다. 조건 갱신·파밍 목표 표시와 한 번 클릭해 기존 준비 화면으로 이동하는 동작을 유지한다.
- 정적 표시 데이터만 추가했다. 새 전역·저장 필드·타이머는 없으며 기존 데이터 스크립트가 UI보다 먼저 로드되는 순서도 유지한다.

검증: PC/모바일 탐험 브라우저 검사 6/6, 전체 스모크 190/190, runtime architecture/lint 및 diff 공백 검사 통과.
브라우저에서 나무/혼돈의 뿌리의 글자 대비·줄바꿈·가로 분류와 모바일 가독성을 확인했다.

## 새 전직 시련 안내

- 기존 시련 목록의 미완료·해금된 일반 전직 시련(`trial-pending`, 현재 시련 제외)을 읽어 안내한다.
  목록은 atlas 렌더 전에 갱신되므로 reqZone/unlockedTrials/재능 개화의 별도 조건을 중복 구현하지 않는다.
- 실제 사냥터 이동 제한(루프 대기·벌집 원정 잠금·경계 너머 진행 중)이 있으면 강조하지 않는다.
  재도전권이 없는 3차 시련도 최초 도전은 무료인 기존 규칙을 유지하며 완료 후 재도전은 새 안내 대상이 아니다.
- 전직 시련 카드에 금빛 테두리와 `시련 확인`을 가리키는 화살표, `새 시련 도전 가능` 상태를 표시한다.
  완료 기록이 갱신되면 사라지고 다른 미완료 시련이 열리면 다시 표시된다. 클릭만으로 완료 처리하거나 저장 상태를 추가하지 않는다.
- 작은 장식 요소의 opacity/transform만 CSS로 움직인다. 동작 줄이기 설정에서는 정적 강조로 바뀐다.
  화살표와 장식 테두리는 클릭을 가로채지 않고, 화살표는 스크린리더에서 제외한다.
- 브라우저 검사: PC/모바일 8/8, 화살표 CSS 우선순위 수정 후 관련 2/2.
  잠긴 시련, 도달 지역 확장, 완료 후 제거, 루프 대기, 최초 무료 3차 입장, 현재 시련 제외와 동작 줄이기를 검증했다.
- 전체 스모크 190/190, runtime architecture/lint 및 diff 공백 검사 통과. PC/모바일에서 테두리·화살표 표시와 클릭 가림 없음을 확인했다.

## 2026-09-14 — 액트 직접 진입과 하위 콘텐츠 정돈

- 첫 화면 상단에 나무/액트 사냥을 전체 폭으로 분리했다. 나무 또는 사냥터 선택을 한 번 누르면 실제 액트 목록이 열린다.
  기존 즉시 사냥·미수령 액트 보상 버튼도 유지한다. 나머지 나무 콘텐츠는 `도전과 원정` 카드로 묶는다.
- 새 시련 안내는 카드 상단 중앙의 하향 화살표로 변경하고 움직이는 테두리를 제거했다.
  기존 버튼의 overflow 때문에 화살표가 잘리던 충돌도 수정했다. 안내 조건과 동작 줄이기 설정은 유지한다.
- 권역 상세와 실제 콘텐츠의 제목 크기·행간·지역 배경·경로 버튼을 맞췄다. 이전 패널의 중복 제목만 숨기고
  반복 사냥 등 실제 조작과 탐험 진행 알림은 보존한다. 페이지를 바꾸면 탐험 창의 스크롤을 맨 위로 돌린다.
- 강대한 적 목록의 네 분류가 좁은 네 열에 몰리던 구조를 해소했다. 분류는 세로로 쌓고 개별 보스는 최대 두 열,
  좁은 창에서는 한 열로 표시한다. 기존 테마의 분류 헤더 배경과 충돌하던 스타일은 콘텐츠 전용 스타일에서 정돈한다.
- 보스·전직 시련의 이름, 완료 상태, 화력/생존력, 보상, 입장 조건과 버튼을 분리했다.
  카드 본문을 누르는 것만으로 입장하지 않고 명시적인 도전 버튼으로 입장한다. 최초 무료 시련과 재도전권 규칙은 그대로다.
- 기존 atlas UI의 보스 보상 표시 함수를 같은 UI 계층의 실제 보스 목록에서도 사용한다.
  새 전역·타이머·저장 필드·도메인 규칙은 없으며 스크립트 순서는 유지한다.

검증: PC 1048×742 및 모바일 393×851에서 첫 화면, 상단 화살표, 전직 시련과 보스 목록을 직접 확인했다.
전체 스모크 190/190, runtime architecture/lint 통과. 탐험 회귀 검사는 최초/후반 해금, 액트 한 번 진입,
보상창, 시련 안내, 첫 무료 도전, 보스 입장권, 본문 클릭의 무소모, 공통 제목 스타일과 카드 넘침을 검증한다.
실제 게임 소스에 반영했으며 테스트 페이지는 같은 소스를 격리된 상태로 사용한다. PR·공개 배포는 수행하지 않았다.

## 2026-09-14 — 보상창과 안내 후속 조정

- 액트 클리어 보상 오버레이를 탐험과 같은 녹흑색 바탕, 금색 경계, 6px 모서리와 제목 서체로 맞췄다.
  보상 목록은 한 열로 유지하고 화면 높이를 넘으면 내부 스크롤한다. 보상 지급·선택 가능 조건과 나중에 닫기는 기존 함수 그대로다.
- 도전과 원정 등 권역 상세의 이중 여백을 제거했다. 경로 버튼, 지역 배경 제목, 현재 위치 순서로 배치하여
  실제 하위 콘텐츠의 헤더와 읽는 순서와 폭을 맞췄다.
- 탐험의 현재 사냥터→현재 위치, 이 지역 사냥→즉시 이동, 사냥터 선택→세부 지역, 사냥 시작→이동으로 바꿨다.
  이동의 실제 동작은 변경하지 않아 도착 후 기존 자동사냥이 이어진다.
- 새 전직 시련 카드의 위쪽 화살표와 함께 180도 간격의 빛 두 개가 테두리를 따라 돈다.
  작은 CSS 가상 요소 두 개의 motion path만 사용하고 타이머·캔버스·대형 회전 레이어는 추가하지 않는다.
  동작 줄이기를 요청하면 움직이는 빛은 숨기고 정적인 테두리와 화살표를 유지한다.
- JS 변경은 기존 UI 템플릿·문구·배치에 한정되며 저장 shape, 전투, 보상 및 스크립트 순서 영향은 없다.

검증: 탐험 브라우저 PC/모바일 8/8(보상창 화면 내 크기·실제 선택 후 수령 상태 포함), 전체 스모크 190/190,
runtime architecture/lint 및 변경 파일 diff 공백 검사 통과. PC/모바일에서 보상창·헤더·두 줄기 테두리 빛을 직접 확인했다.

후속 요청: 새 시련의 위쪽 화살표, 전용 애니메이션과 화살표용 여백을 제거했다. 두 줄기 테두리 빛과
동작 줄이기 설정은 유지한다. PC/모바일 시련 안내 검사 2/2, 전체 스모크 190/190 통과.

액트 보상 버튼에는 완료 표시와 같은 오른쪽 자동 여백을 적용하여 두 상태 모두 왼쪽에서 시작하고 이동 버튼은 오른쪽에 남긴다.
