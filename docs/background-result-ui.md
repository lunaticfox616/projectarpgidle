# 백그라운드 전투 결과 UI

2026-09-08

- 결과 창은 기존 tutorial-card의 파란 배경 대신 공통 ui-surface/ui-line/ui-gold 토큰을 사용한다. 시간, 주요 장비, 정산 내역, 하단 행동을 분리하고 본문만 스크롤한다. 보상 계산은 그대로다.
- 주요 장비는 이름·부위·보관 위치와 짧은 획득 사유만 표시한다. 등급은 왼쪽 색상선과 접근성 이름에 남기며, 반복 안내 문장을 제거한다.
- 인벤토리·장착 장비·방치 보관함에서 해당 장비를 찾아 기존 전투 로그의 스냅샷/장비 툴팁을 재사용한다. 이후 장비가 바뀌어도 결과 표시 시점의 옵션을 확인할 수 있다.
- PC 포인터·키보드 포커스·모바일 탭을 지원한다. 터치 종료에 합성되는 마우스 이탈로 툴팁이 닫히지 않게 pointer 이벤트를 구분한다. 결과 창 위에 툴팁을 표시하고 하단 버튼으로 닫을 때 함께 닫는다.
- 스냅샷 상한 80개를 유지하면서 열린 결과 창의 최대 5개 장비를 로그 정리에서 보호한다. 찾을 수 없는 장비의 요약은 유지하되 옵션 버튼은 비활성화한다.
- 검증: 전체 npm test, check:architecture, PC/모바일 실제 브라우저에서 옵션 내용·장비 변경 후 스냅샷 유지·100개 추가 로그 후 유지·보관함 장비·연속 터치·키보드·창 닫기·빈 결과·라이트 모드 확인. 이전/이후 스크린샷을 비교했다. 스크립트 순서와 저장 형식은 바꾸지 않았다.
