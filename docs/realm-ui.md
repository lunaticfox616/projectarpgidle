# 콘텐츠 화면 정리

정산 창은 기존 표면·선·글자 색상 토큰을 사용한다. 가속은 남은 유효 전투 시간 절반 포기,
즉시 종료는 남은 시간 전부 포기이며 획득한 결과를 기존 저장 경계에서 한 번 확정한다.

가지치기는 별도의 콘텐츠 화면이 원래 존재했다. 모바일의 두 줄 메뉴 자동 배치와 저장된
`bottom` 위치 때문에 기타로 들어갈 수 있었다. 기본 메뉴로 고정하고 이전 PC·모바일 배치를
복원할 때 가지치기만 `top`으로 이행한다. 다른 사용자 지정 메뉴 순서와 위치는 유지한다.

지하계는 입장 정보를 먼저 표시하고 룬 제작·성장과 장비 가공을 구분한다. 보유 룬을 모두
확인할 수 있으며 터치로도 설명을 연다. 심해는 다음 가디언·체크포인트·산소·잠수/복귀를 앞에
놓고 영구 강화는 카드로 비교한다. 낚시는 채집 전략과 제작 이동을 먼저 제공하고 도감은
수령 가능 보상 수를 보여주는 접이식 영역으로 만든다.

우주계는 은하·상태 필터가 있는 목적지 목록과 선택 상세가 기본이다. 탐사 버튼과 전투 준비도를
상단에 두고 별지도·환경 수치·전체 진행 기록은 펼쳐볼 수 있다. 신호 선택, 성도술, 우주석,
최종 관문 및 기존 입장 조건은 유지한다. 동적으로 생성한 우주계 패널을 창 본문에 붙여
상단 메뉴와 겹치던 문제도 수정했다. 신규 저장 도메인이나 스크립트 순서 변경은 없다.

검증: `npm test`, `npm run check:architecture`, `tests/browser/realm-workflow.spec.js`와
기존 우주계·낚시·후반 콘텐츠 검사를 PC/모바일에서 실행했다. 어두운 테마와 밝은 테마, 상세
정보 열고 닫기, 실제 탐사 시작, 즉시 종료 후 중복 정산 방지를 확인한다. 실물 휴대폰 성능은
이 UI 검사의 검증 범위가 아니다.
