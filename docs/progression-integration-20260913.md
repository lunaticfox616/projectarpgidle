# 패시브·장비·지역 콘텐츠 통합 점검

목표: 최신화된 패시브 스킬 트리 노드와 레벨 및 능력치 요구조건, 지역별 레벨 할당에 따른
장비 아이템 개편 및 각 지도 지역별 콘텐츠 최적화.

## 이번에 수정한 연결 오류

`generateEquipmentDrop`은 전달받은 지역으로 아이템 레벨을 계산하지만, 내부 베이스·고유 선택은
현재 지역을 다시 읽었다. 원본 지역을 `chooseItemBase`와 `generateUniqueItem`까지 전달한다.
기존 호출은 현재 지역을 기본값으로 유지한다. 보물사냥·경계 완료 보상 및 보스의 별도 고유 드랍도
같은 원본 지역을 사용하며 플레이어 상태를 임시 변경하지 않는다.

수정 전 동작을 재현한 우주계 보상 400개는 현재 위치를 바꾸면 281개가 달랐다. 수정 후에는
차이가 없다. 회귀 검사는 액트·혼돈계·지하계·우주계에서 일반/고유 보상, 베이스/옵션 수치,
장착 요구조건과 아이템 레벨을 함께 비교한다. 검사 상태의 `game`과 `window.game` 참조도 맞춰
실제로 현재 지역이 바뀌는 조건을 검증한다.

검증: 전체 스모크 188/188, `npm run check:architecture`, 스크립트 연결 검사 통과.
새 저장 필드·전투 틱·타이머는 추가하지 않았고, 기존 저장의 옵션을 다시 굴리지 않는다.

## 계 전용 베이스 드랍과 패시브 경로 추가 점검

계 전용 일반 베이스 6종은 `reqTier`가 해당 지역의 드랍 상한보다 높아 후보에 들어가지 못했다.
`dropOnly.minTier`를 혼돈계·지하계 15, 우주계 20으로 분리하고 기존 베이스 선택기가 이를 사용한다.
베이스 자체의 T18/T20/T22 수치·장착 레벨·요구 능력치·희소 가중치는 유지한다.
우주계 베이스는 제5은하의 T20 드랍에서 등장하며, 다른 지역이나 한 단계 낮은 티어에서는 제외된다.
별도 고유 드랍 정책과 일반 장비 드랍률은 변경하지 않는다.

`smoke-loot-tier-progression`은 수정 전 첫 혼돈계 베이스의 도달 불가를 재현했고 수정 후 6종 모두
실제 장비 생성, 지역/하한 제외, 장착 요구조건 유지, 저장 정규화 후 옵션/제작 상한을 통과했다.

`scripts/audit-passive-requirements.js`는 실제 연결 경로와 활성화 함수를 사용한다.
장비·키스톤·별쐐기·기타 성장 없이 주 능력치 130 및 혼합 능력치 92씩을 확보한 예시 비용:

| 직업 | 주 능력치 130 | 혼합 조합 | 각각 92 |
| --- | ---: | --- | ---: |
| 전사 | 25P | 힘·민첩 | 33P |
| 궁수 | 26P | 민첩·지능 | 35P |
| 방랑자 | 24P | 민첩·힘 | 34P |
| 비술사 | 22P | 지능·민첩 | 40P |
| 연금술사 | 23P | 지능·힘 | 43P |
| 성직자 | 24P | 힘·지능 | 32P |

초반 혼합 25씩은 9~29P로 차이가 컸다. 다른 직업 영역으로 이동하는 공허 연결을 실제 사용하며,
이를 금지하면 일부 조합을 얻지 못하므로 공허를 제외한 이전 임시 결과는 판단에 사용하지 않는다.
탐욕적 경로 선택의 예시로 최소 비용을 보장하지 않으며, 공격·방어를 함께 챙기는 실전 빌드 결과도
아니다. 모든 조합이 실제 활성화되었지만 이 값만으로 요구조건을 일괄 낮추지는 않는다.
결과 및 선택 노드 ID: `artifacts/passive-requirement-paths.json`.

이번 베이스 수정 검증: 전체 스모크 188/188(13.7초), 구조·린트 검사 통과,
부트스트랩 스크립트 연결 152개 통과. UI 배치·렌더링·로드 순서는 변경하지 않았고
상태/드랍 스크립트의 캐시 식별자만 갱신했다. 새 저장 필드는 추가하지 않았다.

## 통합 검증 범위와 체감 검증의 한계

- 여섯 직업의 연결 가능한 단일·혼합 경로와 장비 보완 시 실제 착용을 확인했다. 아래 조건의
  반지를 자연 드랍/제작으로 확보하는 속도, 공격·방어를 겸한 실전 빌드 선택은 미검증이다.
- 각 지도 콘텐츠의 입장 시점, 구간별 레벨, 전투 밀도/패턴, 요구 DPS/EHP, 보상 상한은
  아래 수치 조사와 실제 진행 검사로 대조했다. 대표 지역 레벨만으로 난이도의 적절성을 증명하지 않는다.
- 벌집·대균열·운석·군락지·미궁·혼돈계·지하계·심해·우주계·경계 너머의 실제 진행/실패/재도전과
  보상 저장 복원 경계를 최신 장비 요구조건으로 검증했다.
- 플레이어 체감 및 장시간 난이도는 현재 자료가 없으므로 자동 검증과 구분한다.

구현과 회귀 검증은 마지막 완료 감사에 정리했다. 장시간 플레이어 체감은 별도 플레이테스트 대상이다.

## 완료 보상·재도전·초반 혼합 장비 추가 검증

- 벌집 여왕의 8% 추가 고유 보상이 귀환한 지역을 참조하던 오류를 수정했다. 초기화 전에 벌집
  지역 정보를 보존하고, 벌집의 드랍 후보 상한 및 여왕 레벨을 사용한다. 액트/우주계에서 출발한
  같은 벌집은 같은 난수에서 같은 고유·베이스·요구조건을 지급한다. 완료 함수의 재호출은 무효다.
  고유의 `hiddenTier`는 고유 자체의 정의 티어이며, 후보 상한 15로 일괄 바꾸지 않는다.
- 미궁의 자동 다음 층 이동이 화석 확률 및 30층 부적 재료 조건을 한 층 먼저 적용하던 오류를
  수정했다. `clearedFloor`로 보상을 판정해 29층 반복/진행의 지급 결과를 같은 난수로 비교했다.
- 벌집·군락지는 실제 입장 함수로 입장권 2개에서 시작해 중복 입장, 저장 복원, 패배, 재입장,
  다시 패배, 재료 부족 시 거부를 검증했다. 현재 요구조건을 만족한 장비의 소유·활성 상태와
  복원 후 양수 생명력이 유지되며, 완료된 패배 상태가 저장 로드로 되살아나지 않는다.
- 초반 혼합 갑옷은 여섯 직업 모두 Lv.21에 실제 장착 가능했다. 주 능력치 25는 연결 패시브
  5P(성직자 6P), 보조 능력치 28은 요구 능력치 없는 반지 두 개의 T1 최솟값 +14씩으로 준비했다.
  `equipItemById` 및 스탯 계산은 실제 구현을 사용한다. 남는 14~15P의 공격·방어 효율은 측정하지
  않았으며, 이 반지가 반드시 초반에 드랍된다는 의미도 아니다. 수치 조정 없이 현재 규칙을 유지한다.

재현: `scripts/smoke-event-context.js`, `scripts/audit-passive-requirements.js`.
전체 스모크 188/188, 구조·린트 검사, 부트스트랩 연결 검사 통과.
브라우저 `core-ui.spec.js`의 벌집 갈림길 선택/닫기/다음 갈림길 흐름은 PC·모바일 2건 통과,
두 화면 캡처를 확인했다. 렌더링 스타일은 이번 변경에 포함되지 않았다.

## 지역 수치 조사 확장

`scripts/audit-map-progression.js`와 `artifacts/map-progression-audit.json`에 지역 단계,
보스 레벨·생명력, 표시 권장 DPS/EHP, 동레벨 경험치, 드랍/옵션 상한을 기록한다.
15개 동적/일반 지역 유형 및 정의된 시련·시즌 보스 전부를 루프 1·50에서 조사한 172개 표본의
수치는 모두 양수·유한이다. 창공은 실제 해금 최고층을 설정하고, 지하계는 별도 난이도 전환 경계
299/300/301층을 포함했다. 우주계는 은하별 대표 전투 티어의 합성 탐사이며 모든 천체 표본은 아니다.
입장 해금 및 플레이어 장비는 이 수치 조사에서 제외되어 있으므로 실제 클리어 시간으로 읽지 않는다.

지하계는 기존 설계상 300층까지 지역 Lv.133을 유지하고 별도 배율로 강해진다. 301층부터
레벨도 상승한다. 혼돈 심화도 레벨 상한 후 별도 난이도 증가를 사용한다. 전용 재료/누적 보상이
있는 구조를 무시하고 몬스터 레벨만 일괄 올리면 전투·경험치가 함께 변하므로 이번에는 보존했다.

## 완료 정지와 특수 지역 저장 복원

- 혼돈계·창공·미궁·지하계는 층 보상 및 다음 층 해금을 처리한 뒤 `mapCompleteAction=stop`이면
  현재 위치에서 정지한다. 정지 시 운석 자동입장이 끼어들지 않는다. 공통 완료 후 이동 함수를
  사용하며 우주계·경계 너머 등의 탐사 도중 웨이브는 기존대로 이어진다.
- 실제 로컬 저장 로더는 적과 전투 계획이 비어 있으면 `combatHalted`를 무조건 해제했다.
  완료 후 중단 설정일 때는 저장된 정지를 유지한다. 다른 자동 진행 설정의 재개 동작은 유지한다.
- 저장의 문자열 지역 ID를 별도 허용 목록과 실제 지역 정의로 이중 검증하던 과정에서 심해,
  시간의 균열, 나무꾼의 잔상, 아스트라 및 일부 정점 보스가 시작 지역으로 바뀌었다.
  실제 지역 정의를 유일한 ID 검증 출처로 사용하고 반환 객체의 ID 일치까지 확인한다.
  `constructor`·`__proto__` 등 배열 속성 및 미등록 시련/보스 ID는 지역으로 허용하지 않는다.
  입장 해금·재료 차감 규칙과 별개인 저장 복원 수정이며 새 저장 필드는 추가하지 않았다.
- 심해 500m 저장 복원 후 가디언 완료 시 암초 조각 3개를 한 번 지급하고, 산소 고갈 귀환 후
  체크포인트·처치 기록·요구조건을 충족한 장비를 유지한 채 산소를 충전하여 재입장한다.
- 경계 너머 5전 완료 및 봉인 보상은 한 번만 지급한다. 재도전 실패 후 기존 보상과 장비를
  보존하고, 각 도전의 무형의 이슬 비용을 정확히 차감한다. 저장 시 장비에 부여되는 인스턴스
  ID를 먼저 정규화한 뒤 전체 보상 객체를 비교하여 수치·재화 손실과 중복을 검사한다.
- 우주계 5개 은하 125개 탐사 지점의 기존 진행 검사에 실제 장비를 추가했다. 각 은하의 탐사
  중 저장 복원 후 같은 무기가 유지되고 능력치 요구조건으로 비활성화되지 않음을 확인했다.

검증: `smoke-event-context`, `smoke-cosmos-route`, 전체 스모크 188/188(10.1초).
PC·모바일의 실제 설정 선택 → 층 완료 → 로컬 저장/불러오기 및 심해 가디언 복원 2건 통과,
양쪽 `ocean-restored.png` 화면을 확인했다. 구조·린트 검사와 부트스트랩 152개 연결 검사도 통과했다.
로컬 로더는 기본 상태 또는 이미 정규화한 저장만 받으므로 중복 배열 검사를 제거해 복잡도를
늘리지 않았다. 저장 입력의 배열 검증은 `mergeDefaults`에 유지한다.
전투·저장 스크립트 캐시 식별자 `content-resume=20260913-1`을 갱신했다.

## 제단·룬·최초 돌파 통합 검증

- 시간의 균열은 해금 루프 전 과거 입장 및 빈 제단의 미래 입장을 거부한다. 과거 완료,
