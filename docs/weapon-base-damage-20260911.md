# 무기 베이스 고정 피해 상향 — 2026-09-11

## 범위와 수치

- 모든 무기 베이스 37종의 `flatDmg`, `spellFlatDmg` 44줄을 상향한다.
- 원소·카오스 피해 증가율, 속도·치명타 등 다른 기본 옵션 및 추가 옵션은 유지한다.
- 실제 베이스의 `reqTier`를 기준으로 초반 +20%, T10 약 +58%, T20 이상 +140%가 되도록 데이터의 정수 수치를 직접 변경했다. 전투 계산에 배율을 추가하지 않는다.
- 데이터 산출식: `round(oldBase * (1.2 + 1.2 * ((min(20, reqTier) - 1) / 19)^1.5))`. 정수 반올림 때문에 초반 증가율은 20~25%다.
- 실제 옵션 범위는 기존 `floor(base * 0.8)` ~ `floor(base * 1.2)`를 유지한다. 드랍의 숨은 티어가 낮은 단계 무기의 기본 피해를 올리지는 않는다.

## 기존 장비와 의존성

`BASE_ITEM_DB`가 기존에 있는 `js/state.js`의 정의를 수정하고, `js/passives.js`의 기존 `normalizeItem` 경계에서 저장 장비를 환산한다. 로드 순서와 공개 전역은 바꾸지 않는다.

기존 `rollBaseStats`는 범위 계산(`getBaseStatRollRange`), 한 줄 생성(`rollBaseStat`), 벨트 슬롯을 포함한 장비 전체 생성(`rollBaseStats`)으로 분리했다. 정수·소수점 및 보호막 계산, 난수 소비 순서는 유지하며 새 버전 필드로 함수 복잡도가 늘어나지 않게 한다.

- 정의의 `legacyDamageBase`는 변경 전 값이다. 이전 저장 지원 기간 동안 보존한다.
- 각 기본 옵션의 `baseDamageBalanceVersion: 1`로 중복 환산을 막는다. 신규 드랍·베이스 업그레이드도 생성 시 표시한다.
- 옛 범위 안에서는 상대적인 뽑기 위치를 유지하고, 범위를 넘은 특출난 수치는 비례 환산한다. 정수 반올림 오차는 있을 수 있다.
- `originalVal`, 제련용 `baseRollMin/max`도 함께 갱신한다. 품질, 고유 효과, 고정 여부 및 추가 옵션은 보존한다.
- `baseId` 또는 알려진 `baseName`으로 대응되는 무기만 환산한다. 알 수 없는 베이스와 무기 이외 부위는 추측해 변경하지 않는다.

## 검증

`scripts/smoke-weapon-base-damage.js`에서 전체 무기 최소·최대 범위, 베이스와 드랍 티어 분리, 기존·신규 장비 중복 환산 방지, 특출난 고유 장비, 미확인 베이스, 다른 부위 보존을 검사한다.

- `npm test`: 184/184 통과. 저장 복원의 인벤토리·장착·임시 보관 및 재복원도 포함한다.
- `npm run check:architecture`: 구조·복잡도 검사 통과.
- `npx playwright test -c artifacts/crafting-flow/playwright.config.cjs weapon-base.spec.cjs`: PC·모바일 2/2 통과. 격리된 실제 게임에서 기본 피해 표시, 기존 최종 무기 환산, 축복의 오브 1개 차감 및 새 범위 재추첨, 저장 복원을 확인했다. 브라우저 오류는 없었다. 이 시연 검사는 로컬 artifacts에 있다.

후반 무기의 기본 피해 비중이 크게 증가한다. 전체 DPS 증가는 빌드마다 다르며, 적 난이도 조정이나 실제 플레이 밸런스 검증을 포함하지 않는다.
