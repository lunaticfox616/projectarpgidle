# 프로필·공허 패시브·장비 필터

- 공허 패시브 제작과 공개 프로필은 공통 UI 테마의 표면·구분선·문자색을 사용한다. 프로필 장비 이름은 가독성을 우선하고 등급 색은 테두리로 표시한다.
- 지혜의 도약은 투자된 속성 분기 노드가 기준이다. 기존 경로 판정과 동일하게 여러 분기가 투자되어 있으면 마지막으로 투자한 분기를 적용한다. 분기가 없으면 속성 효과를 적용하지 않는다. 투자 효과 요약에는 변경용 선택 상자를 제공하지 않는다.
- 저장된 과거 선택값은 전투 판정에 사용하지 않는다. 저장 복원과 런타임 상태 정규화에서도 투자 노드에 맞춰 보정한다. 기존 저장 형식과 노드 투자는 유지한다.
- 검색·등급·부위·분석 조건은 교집합으로 적용한다. 불일치 장비도 원래 칸에 회색으로 남고 클릭·장착할 수 있다. 일치 장비는 금색 테두리로 강조한다. 실제 장비 삭제나 이동은 수행하지 않는다.
- 전역 선택 변경 API를 제거했으며 스크립트 순서는 유지한다.

검증: 전체 스모크, 런타임 구조 검사, PC·모바일의 다크/라이트 공허 제작·프로필 전환 및 장비 필터·장착 흐름.
