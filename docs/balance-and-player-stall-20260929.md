## 검증된 전투 결함 수정

- **공격 시작 보너스 누락**: 워록 피의 계약은 최대 생명력 4%를 지불하고도 예약 타격에
  피해 1.5배가 전달되지 않았습니다. 공허 특이점과 광신의 새 스택 보정도 같은 경로에서
  사라졌습니다. 기존 공격 배율에 실어 예약 타격 및 시간 가속의 지속 피해까지 전달합니다.
  비용은 시전당 한 번, 생명력이 부족하면 비용·보너스 모두 없습니다.
- **연쇄 처치 보상 중복**: 사망자가 배열에 남아 있는 동안 시체 폭발이 다른 적을 죽이면
  원래 사망자를 재귀적으로 다시 정산했습니다. 2마리 처치가 3회로 기록되는 재현을 고쳤습니다.
  보상·연쇄 처리 전에 사망자를 제거해 경험치·재화·그루터기 함 성장의 중복을 막습니다.

신규 회귀 검사는 수정 전 실패하고 수정 후 통과했습니다. 이것은 결함 수정이며,
모든 직업의 피해량·생존력·클리어 시간이 균형 잡혔다는 뜻은 아닙니다.

## 가판대 행동

거래소 → **나의 가판대**. 기존 거래소 해금(루프 2 이후 장비 제련 해금)을 따릅니다.
장비를 선택하고 판매가를 입력하면 보관함에서 진열대로 이동합니다. 네 칸을 제공합니다.
가격 변경, 장비 회수, 판매 대금 수령, 최근 방문 기록이 실제 게임 상태와 저장에 연결됩니다.

손님은 외부 LLM 호출 없이 취향과 독립적인 구매 결정을 가진 NPC로 시뮬레이션합니다.
경비병·사냥꾼·학자·견습생의 선호 부위와 옵션이 다릅니다.
구매하지 않은 방문과 구매한 방문을 구분해 표시합니다.

| 조정 가능한 초기값 | 값 |
| --- | --- |
| 방문 간격 | 실제 시간 10~180초의 불규칙한 도착, 평균 약 1분 |
| 손님 몰림 | 충분한 가치·실제 손님 선호·큰 할인을 모두 충족한 경우에만 2~4명 동시 방문 |
| 최초 판매 가능 시점 | 진열·가격 변경 후 최소 1분 |
| 초기 관심도 | 할인가는 초반 구매 가능성이 높고, 정상가는 낮게 시작해 10분까지 상승 |
| 구매 방식 | 방문마다 독립적으로 구매, 공통 예산 적립 없음 |
| 오프라인 반영 | 한 번에 최대 12시간, 초과분 재사용 불가 |
| 판매 통화 | 마법의 새싹 / 형체 없는 이슬 / 황금률 중 선택 |
| 손님 최대 지불가 | 감정가 약 120%, 고유 장비 되팔기 상한 별도 |

가격은 자유롭게 올릴 수 있지만 지불 한도를 넘는 가격으로 즉시 구매되지는 않습니다.
가격 제안을 허용했다면 손님이 감정가에 맞는 더 낮은 금액을 제시할 수 있습니다.
싼 물건은 구매 확률이 높아지며, 같은 손님이 한 번에 한 물건만 삽니다.
전투 배속·재화 획득 보너스는 판매 속도와 판매 대금을 늘리지 않습니다.

## 거래 화면과 가격 제안 · 2026-09-30

사용자가 선택한 방향은 디아블로 2식 장비 진열과 POE식 상세 옵션·가격 표시의 혼합입니다.
현재 게임의 실제 장비 아트와 금색·어두운 재질을 유지하고, 암거래상은 진열 그리드와
선택 상세판으로 나눕니다. 옵션의 실제 범위와 비용을 본 뒤 구매하며, 갱신으로 다른 상품이
들어온 슬롯은 재선택 전까지 구매하지 못합니다. 가판대도 장비를 선택해 옵션을 확인하고
판매가를 정합니다. 복사한 게임 자산이나 외부 LLM은 사용하지 않습니다.

참고 자료: [D2R UI 개선](https://news.blizzard.com/en-gb/article/23695734/technical-alpha-learnings),
[PoE 2 비동기 거래 FAQ](https://www.pathofexile.com/forum/view-thread/3828185).
NPC 흥정은 본 게임에 추가한 규칙이며 위 게임들에 동일한 NPC 기능이 있다는 뜻은 아닙니다.

- 새 진열에서는 **가격 제안 받기**를 선택할 수 있고, 화면 기본값은 켜짐입니다.
  이전 저장의 진열품은 즉시 구매만 허용하던 행동을 유지하며, 개별적으로 켤 수 있습니다.
- 구매하지 않은 손님이 취향에 맞는 장비에 더 낮은 금액을 제안합니다. 금액은 감정가와
  손님 선호로 산정하며, 호가보다 낮고 감정 상한 이하여야 합니다. 호가 1에는 제안이 없습니다.
- 물건마다 한 제안을 **24시간** 보관합니다. 제안이 있어도 진열가 구매는 계속 가능합니다.
  먼저 완료된 거래가 장비를 판매하며, 수락·거절·만료나 다른 손님의 구매 이후 낡은 제안은 무효입니다.
- 제안 생성·취소 뒤 가판대 전체에 최소 **30분** 제안 대기 시간을 둡니다.
  회수 후 재등록하거나 제안 허용을 껐다 켜도 대기 시간과 저장 난수를 초기화하지 않습니다.
- 가격 변경·제안 끄기·회수는 진행 중인 제안을 취소합니다. 보관함 부족으로 회수가 실패하면
  물건과 제안을 그대로 보존합니다. 판매 대금은 기존 수령 버튼으로 받습니다.

`playerStall.version=2`는 `offerSequence`, `nextOfferAt`을 추가합니다. 각 진열품의
`negotiate`와 `offer={id,amount,customerId,createdAt,expiresAt}`도 저장합니다.
제안 ID는 진열 ID와 별개이며, 수락·거절은 두 ID를 함께 검사해 낡은 버튼의 오작동을 막습니다.
초기 버전은 `budgetMs`로 공통 구매 예산을 적립·예약했습니다. v5에서 이 규칙을 제거했습니다.
현재 제안은 물건을 보류하지 않으며 같은 물건의 진열가 구매도 계속 가능합니다.
손상된 제안만 취소하고 물건은 보존합니다. 오프라인 12시간 제한 이후에도 실제 복귀 시각을
기준으로 기한을 검사합니다. 전투 시뮬레이션 중에는 거래하지 않습니다.

전용 검사: `node scripts/smoke-player-stall-offers.js`, `node scripts/smoke-player-stall-ui.js`,
`node scripts/smoke-market-purchase-state.js`. 기존 가판대·경제 검사도 유지합니다.
체험: `http://127.0.0.1:4227/artifacts/player-stall-review/index.html`의 **NPC 제안 체험 준비**는
별도 예시 저장에 장비를 진열하고 실제 구매 규칙으로 2시간을 진행합니다.
이 거래 화면 단계의 전체 스모크 **231/231**, 구조 검사, CSS 검사, 웹 빌드가 통과했습니다. 실제 브라우저에서
암거래상 선택·교환, 제안 생성·수락·거절·대금 수령과 390px 모바일 배치를 확인했습니다.
200개 시드의 기존 가격 감사와 104개 상점 고유 장비의 되팔기 검사도 통과했습니다.
장기 플레이에 따른 적정 대기 시간의 체감은 추가 플레이 테스트로 조정할 수 있습니다.

## 감정 방식과 한계

`data/player-stall.js`의 `PLAYER_STALL_APPRAISAL`이 옵션별 가중치와 베이스 계열을 소유하고,
`js/item-appraisal.js`가 베이스·옵션·조합·희소성의 이슬 기여도를 계산합니다.

- 옵션은 능력치별 가중치, 실제 T1~T20 등급, 해당 롤 범위 안의 품질, 실제 수치 크기를 반영합니다.
  이 게임의 T20은 T1보다 높은 등급입니다. 복합 옵션(`extraStats`)의 축소된 수치도 그대로 평가합니다.
- 베이스는 요구 단계만 보지 않고 실제 고정 속성과 부위, 공격·주문·사역·방어 계열을 구분합니다.
  옵션끼리 같은 계열을 이루거나 베이스와 맞으면 제한된 조합 보너스를 줍니다.
- 동일 능력치는 가장 강한 기여분만 계산하며, 나열 순서를 바꾸거나 같은 줄을 복제해도 가격이 늘지 않습니다.
  요구 가격과 현재 플레이어 빌드는 감정가를 바꾸지 않습니다.
- 합계는 내부 점수이며, 아래의 고가 구간 곡선으로 재화 가치를 계산합니다. 희소성·최대 감정가·상점 되팔기 상한도 적용합니다.
  가장 싼 암거래 구매가 기준으로 고유와 일반 베이스의 되팔기 차익을 막습니다.

옵션 가중치·롤 품질·베이스 차이는 내부 연속 가치에 반영됩니다. 정수 재화의 최소 거래 단위보다
가치가 낮으면 같은 가격표가 붙더라도 실제 구매 빈도는 다릅니다.
위 상세 수치는 개발자용 감정 규칙과 감사 자료입니다. 사용자 요청(2026-09-30)에 따라 플레이어
화면에서는 감정 근거 펼침, 항목별 가격 기여도·가중치, 수치 품질·조합 적합도 점수를 제거했습니다.
감정 계산과 거래 규칙은 유지하며, 감정가와 거래 조건, 장비 자체의 옵션은 계속 표시합니다.

현재 산식은 **NPC 중고 판매가**입니다. 모든 특수 효과·주입·인챈트의 전투 가치를
정밀하게 가격으로 환산한 모델은 아닙니다. 그러한 특수 제작비를 전액 보상하지 않습니다.
새로운 상점 할인·교환 비율을 추가할 때 되팔기 검사를 다시 실행해야 합니다.
서버 시계가 없는 로컬 게임이므로 기기 시계와 저장 파일 자체의 조작까지 막지는 않습니다.

## 직접 진열 · 2026-09-30

나의 가판대는 네 개의 고정된 진열칸을 제공합니다. 보관 중인 장비를 빈칸으로 끌면 해당 칸에
미리 보이고, 가격을 정한 뒤 **진열 확정**을 눌러야 보관함에서 실제로 이동합니다.
취소하면 장비는 그대로 보관함에 있습니다. 터치·키보드는 **장비 선택 → 빈칸 선택**으로 같은 흐름을 씁니다.
진열품은 다른 빈칸으로 옮길 수 있으며, 판매가·진열 시각·NPC 제안은 유지됩니다.

진열품에 `slot: 0..3`을 추가했습니다. 기존 `list`의 다섯 번째 boolean 인수는 유지하며,
명시적 위치를 지정할 때 `{negotiate, slot}`을 받습니다. 지정하지 않으면 첫 빈칸을 사용합니다.
`moveListing`은 위치만 변경합니다. 이미 점유된 칸, 잘못된 위치, 사라진 장비는 부분 변경 없이 거절합니다.
판매·회수 후 다른 물건을 앞으로 당기지 않습니다. 저장 복구는 유효한 위치를 우선 보존하고,
이전 저장·중복·잘못된 위치만 빈칸에 배치합니다. 네 칸을 넘는 손상 저장의 실제 장비는 보관함으로 돌려줍니다.

새 전역이나 스크립트 순서 변경은 없습니다. 가격 정의 → 감정/가판대 도메인 → UI 순서이며,
드래그·임시 배치는 `js/player-stall-ui.js`, 소유권·위치·판매는 `js/player-stall.js`가 담당합니다.
별도 검사 `smoke-item-appraisal`, `smoke-player-stall-placement`, `smoke-player-stall-ui`는
가격 세분화, 저장 복구, 실패 시 원자성, 드래그 취소, 제안을 보존한 이동, 진열 확정을 검증합니다.
최종 전체 스모크 **233/233**, 구조 검사, CSS 검사, 웹 빌드가 통과했습니다. 실제 브라우저에서
장비를 4번 칸에 끌어 놓고 가격 확정 후 3번 칸으로 이동하는 흐름,
390px 화면에서 선택·빈칸 배치·취소·확정을 확인했습니다. 드래그 중 지연된 제안 갱신은
취소 직후 반영되며, 임시 배치 칸에 기존 진열품을 옮기면 미리보기를 해제합니다.
브라우저 초기 로드 로그에는 소스 URL이 없는 `MutationObserver.observe` 대상 오류 한 건이
관찰됐습니다. 위 거래 흐름은 작동했으며, 이 초기화 오류의 발생 주체는 이번 검수에서 확정하지 못했습니다.

## 저가 재화와 상위 가치 구간 · 2026-09-30

사용자가 저가품의 하위 재화 거래와 드문 1이슬 거래를 모두 요청했습니다. 진열·가격 변경에서
**마법의 새싹 / 형체 없는 이슬 / 황금률**을 선택할 수 있습니다. 저가품은 새싹을 기본 제안하며,
이슬을 선택해도 등록할 수 있지만 가치가 낮으면 구매는 매우 드뭅니다. 장비 전당·해체 보상은 바꾸지 않았습니다.
저가 거래는 해체보다 불리할 수 있으므로 게임 안내에서 해체 재료와의 비교를 권합니다.

아래는 개발자용 조정값이며 플레이어에게 점수·가중치·기여도·확률은 표시하지 않습니다.

- `PLAYER_STALL_APPRAISAL.marketCurve`: 내부 점수 24까지 `0.02 + 0.98 × (점수/24)^3` 이슬 가치,
  초과분을 x라 할 때 `1 + 0.6x + 0.3x²`로 상승합니다. 점수 42를 넘는 부분에는
  `(점수-42)³`을 더하며 전체 곡선에 1.12배를 적용합니다. 최대 5,000이슬 상당과
  기존 상점 되팔기 상한을 적용합니다.
- 실제 생성기의 희귀 장비 15,000개를 T1/10/15/18/20에 나누어 비교했습니다. 분기점은 일반 드랍의
  상위 꼬리보다 높고, 좋은 베이스에 우수한 옵션이 여러 개 붙은 장비가 진입하는 수준입니다.
  이것은 고정 티어·희귀 등급 조건부 표본이며 전체 지역 드랍률이나 시간당 획득량을 뜻하지 않습니다.
- 초기 조정에서 T20 멸세 대검 최고 롤의 동일 공격 옵션 묶음 3/4/6줄은 4/39/100이슬이었습니다.
  아래의 시너지·황금률 조정에서 조합 보너스와 상한을 확대했습니다. 아이템 티어만 높은 평범한
  옵션 조합에 최고급 프리미엄을 주지는 않습니다.
- `quote(item, currency)`는 해당 통화의 정수 `fair/ceiling`과 내부 `marketValue/demand`를 반환합니다.
  `marketValue`는 소수 이슬 가치, `demand = min(1, (가치/재화 단위 가치)^4)`이며 직판 확률에 반영합니다.
  해당 재화 한 개보다 가치가 낮은 물건에는 새 가격 제안을 만들지 않아 고가 호가를 이용한 우회를 막습니다.
- 기준 교환은 기존 8새싹→1이슬입니다. 지불 상한은 현재 가장 유리한 할인 교환인
  5새싹→1이슬을 적용해 보수적으로 계산합니다. 황금률은 표준 구매 단위인 100이슬 상당으로
  계산합니다. 재화만 바꿔 기존 상점 되팔기 상한을 우회하지 못하게 하는 거래당 제한이며,
  시간당 적립하거나 가판대 전체가 나누어 쓰는 예산은 아닙니다.

저장은 `playerStall.version=6`: `proceeds`는 기존 이슬, `budProceeds`는 새싹,
`goldProceeds`는 황금률의 정수 대금입니다. `PLAYER_STALL_RULES.proceedsKeys`가 통화별 대금 필드를 지정합니다.
진열품과 판매 기록의 `currency`가 가격 단위를 지정하며 제안액은 그 진열품의 재화를 따릅니다.
기존 저장의 누락 통화는 이슬로 복원합니다. 잘못된 진열 통화는 원물을 반환합니다.
이전 제안이 새 지불 상한을 넘으면 제안만 취소하고 물건·판매 대금은 보존합니다. 상한 이내인 기존
1이슬 제안은 수요가 낮아졌다는 이유만으로 취소하지 않습니다.

모든 재화의 대금 수령은 각 잔액의 정수 범위를 먼저 검사한 후 한 번에 지급합니다. 하나라도
넘치면 부분 지급하지 않습니다. 루프 차단도 모든 대금을 검사합니다. `advance/collect`의 숫자 반환은
기존 호출자의 갱신 신호를 위해 기준 이슬 환산값을 사용합니다(새싹1 판매는 0.125 반환).
이 소수는 실제 재화 잔액에 저장되지 않습니다.
가격·재화 선택은 미리보기이고 **진열 확정 / 가격 변경**에서만 실제 상태에 반영됩니다.

## 계열 시너지와 황금률 거래 · 2026-09-30 후속

사용자는 평균 가격의 소폭 상승과 같은 계열 옵션 조합의 가치 상승을 요청했고,
이번 범위는 **황금률 여러 개까지**로 확정했습니다. 요정의 고리 등은 거래 재화에 추가하지 않았습니다.
여기서 시너지는 기존 옵션의 상호 활용도를 가격 평가에 반영하는 규칙이며, 전투 수치나 드랍률을
변경하는 별도 세트 효과가 아닙니다.

  각 계열의 핵심 옵션이 있어야 해당 조합으로 인정하며 주문 젬과 소환 젬처럼 서로 다른 빌드의

  8/16/25/35/45%를 더하고 베이스 계열 일치 시 8%p를 더하며, 최종 시너지율은 50% 이내입니다.

  동일 희귀 표본 15,000개의 연속 가치 평균은 T1~T20에서 12.8~14.7% 상승했습니다.

  다른 티어와 재화 단위의 표시 가격 상승률은 이 값과 다릅니다.
- 이전 조정에서 실제 T20 멸세 대검 최고 수치 표본의 공격 계열 옵션 3/4/6개는 7이슬 / 60이슬 / 3황금률이었습니다.

## 독립 손님 전환 · 2026-10-01 최초 조정 이력

사용자는 적정가라면 빨리 팔려야 하며 고액 판매를 위해 공통 예산을 적립하는 방식은 원하지
않았습니다. 시간당 회복량과 공통 지갑을 제거했습니다. 거래당 감정·지불 상한은 유지합니다.
아래 방문 간격·최소 시간·제안 보류 규칙과 측정은 최초 조정 이력입니다. 현재 규칙은 마지막의
**1분 구매와 저가 흥정**으로 갱신됐습니다.

- 6분마다 방문, 진열·가격 변경 후 최소 12분부터 구매합니다. 비싼 장비도 같은 규칙입니다.
  구매 여부는 호가/참고가 비율, 손님의 옵션·부위 선호, 해당 통화의 수요로 결정합니다.
  싸게 올릴수록 판매 확률이 높고 감정 상한 초과 가격에서는 직판하지 않습니다.
- 한 방문에 한 물건만 구매합니다. 진열품은 최대 4개이며 실제 보유 장비를 소비합니다.
  전투 배속·획득 보너스와 독립적이고 오프라인 방문은 한 번에 최대 12시간 반영합니다.
- 적정가 이하에서는 새 흥정 제안을 만들지 않고 바로 구매를 시도합니다. 제안 허용을 켜 두어도
  적정가 판매가 응답 대기 때문에 멈추지 않습니다. 참고가보다 높은 호가에는 가격 제안을 보낼 수 있습니다.
  가격 제안은 감정 상한 이하이고 호가보다 낮으며, 기존 30분 생성 대기와 24시간 기한을 유지합니다.
  해당 물건만 보류하므로 다른 진열품의 직판·제안을 막지 않습니다. 수락 시에만 실제 대금을 지급합니다.
- 저장 v5는 기존 `budgetMs`를 제거합니다. NPC 내부 구매 자금이므로 플레이어에게 환급하지 않습니다.
  실제 장비, 통화별 미수령 대금, 유효한 제안, 방문 시각·난수는 보존하며 다시 복원해도 중복 지급하지 않습니다.
  이전 공통 예산이 0이거나 커도 동일한 판매 시간과 대금으로 복원됩니다.
- `maxPaymentDew=5000`, `paymentDew`는 거래당 보수적 지불 상한의 단위입니다.
  통화별 할인 환금성 검사와 기존 암거래상 되팔기 제한을 유지합니다. 시간당 수익 제한은 아닙니다.

새 가판대에 완벽한 T20 공격 6옵션 장비 **1개**를 **27황금률**에 진열한 100개 시드에서

## 1분 구매와 저가 흥정 · 2026-10-01

사용자 요청에 따라 최초 구매 가능 시간을 **진열·가격 변경 1분 후**로 줄이고, 손님 방문을

관심도가 점차 상승합니다. 할인가는 초반에도 구매 가능성이 더 높습니다. 이는 확률이며
1분 또는 10분에 반드시 판매된다는 보장은 없습니다. 통화보다 가치가 낮은 장비의 드문 거래와
기존 감정·지불 상한, 한 손님당 한 물건, 오프라인 12시간 제한은 유지합니다.

  않도록 제안 빈도를 낮췄으며, 가격 제안 허용을 꺼 두면 제안 없이 진열가 구매만 가능합니다.
  제안액은 선택한 재화의 정수 단위이고 항상 호가보다 낮습니다. 1개 호가에는 더 낮은 제안이 없습니다.

  무효이며 다른 진열품을 삭제하지 않습니다. 24시간 기한과 가판대 전체 30분 제안 대기는 유지합니다.

## 정가 대비 헐값 제안 · 2026-10-01 정정

사용자는 단순히 싼 진열가보다 조금 더 낮은 가격이 아니라, **정가보다 훨씬 낮은 금액을 부르는
손님도 있을 확률**을 요청했습니다. 제안 발생 빈도와 구매 시점은 유지하고 제안 금액의 분포를 변경합니다.
제안 중 15%는 `min(호가, 참고가)`의 약 20~45%를 부르며, 나머지는 기존의 일반 흥정 범위를 따릅니다.
예컨대 정가 27황금률로 진열한 장비에 6황금률을 제안하는 손님이 있을 수 있습니다.
정수 재화의 최소 단위와 반올림이 아닌 내림 계산을 적용하므로 작은 금액에서는 비율이 거칠어집니다.
