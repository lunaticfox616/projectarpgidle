# 도트 UI 통일 + 디아블로 2 향 (2026-09-29)

전장(한 칸 16도트)은 도트인데 UI는 매끈한 벡터 틀·명조 글꼴이라 따로 놀던 것을 도트 결로 맞췄다.
디아블로 2 느낌은 "살짝"만: 돌판 재질, 청동 테와 금빛 징, 금빛 제목, 생명 구슬, 물약 허리띠.

## 무엇이 바뀌었나

| 부분 | 전 | 후 |

도트 글꼴은 제 크기(물마루 12·갈무리 15·DOS새물 16과 그 배수)에서만 또렷하다. 8~11px로 줄어 있던 글자는 12px로 올렸고,
한글은 단어 중간이 아니라 띄어쓰기에서 끊는다(`word-break: keep-all`).

## 파일

| 파일 | 하는 일 |
|---|---|
| `css/themes/pixel.css` | 글꼴·모서리·도트 판(창·대화 상자·툴팁·기록·레일·시작 화면)·버튼·입력·작은 글자 |
| `css/themes/pixel-hud.css` | 전투 화면: 생명 구슬 HUD, 물약 허리띠, 젬 칸, 대상 적 체력바, 미니맵, 지역 줄 |
| `css/themes/pixel-mobile.css` | 휴대폰: 지역 줄·귀환/목표 버튼·전투 기록 막대·하단 메뉴·메뉴 서랍·목표 서랍 |
| `css/themes/pixel-menu.css` | 메뉴: PC 하단 HUD에 담긴 메뉴(둥근 소켓·이름표·기타 목록), 휴대폰 하단 메뉴 띠(HUD와 한 판)·서랍 아이콘 |
| `scripts/build-pixel-ui.cjs` | 테(무거운·가벼운·오목)·둥근 테(구슬·미니맵·메뉴 소켓, 1px 도트)와 구멍 가면·물약 병/액체·메뉴 아이콘 줄·도트 로고를 코드로 찍어 `assets/ui/pixel/`에 쓴다 |
| `scripts/pixel-menu-icons.cjs` | 메뉴 아이콘 21개(13×13 도트 글자 그림). 순서가 CSS `--px-icon` 번호 |
| `scripts/build-pixel-icons.cjs` | 원화 아이콘을 도트 사본으로 `assets/px/`에, 목록을 `data/pixel-icons.js`에 쓴다(Playwright Chromium 사용) |
| `js/utils.js` `pixelIconPath` | 사본이 있으면 도트 경로로. 장비·인벤토리·젬·재화 아이콘 해석 함수가 이를 거친다 |
| `js/icon-art-ui.js` | 설정 "아이콘 그림"(도트/원화) |

네 CSS는 `@layer overrides`의 맨 끝(css/main.css 마지막 import)이라 스킨(rift 등) 위에 얹힌다.
구슬은 기존 막대와 같은 `--gauge-fill`(js/ui.js `setUiImageGaugePercent`)을 세로 `clip-path`로 읽으므로 스크립트는 그대로다.

## 다시 만들기

```bash
node scripts/build-pixel-ui.cjs       # 테·구슬·물약·로고 그림을 바꿨을 때
node scripts/build-pixel-icons.cjs    # 원화 아이콘을 추가·교체했을 때(사본과 data/pixel-icons.js 갱신)
```

`npm test`의 `smoke-pixel-icons`가 사본 누락·크기·도트/원화 전환을 검사한다(원화를 새로 넣고 사본을 안 만들면 실패).

## 알림 자리 (2026-09-29 추가)

- **새 콘텐츠 카드**(`#tutorial-overlay`): PC는 플레이어 HUD(생명 구슬·정보 판) 바로 위 가운데

  창을 덮지 않도록 왼쪽 빈 전장으로 비켜선다(자리가 없으면 HUD 위 그대로). 휴대폰은 하단 메뉴 위 시트 그대로이고
  확인 · 화면 열기를 한 줄에 놓아 높이를 줄였다(세로로 쌓으면 화면 아래 1/3을 덮었다). 안내가 떠 있는 동안 전투는
  기본값으로 멈춘다(`settings.pauseGameOnOverlay`).
- **DPS 변화**: 공용 알림(PC 오른쪽 위 = 미니맵·창 닫기 단추 위, 휴대폰 아래 = 생명 구슬 위) 대신 생명 구슬 바로 위의 작은
  도트 칩(`.build-dps-chip`, `js/build-feedback-ui.js`). 휴대폰에서 구슬 위에 전투 로그 줄이 있으면 그 위, 구슬이 안 보이는
  화면(장비 탭 등)에서는 하단 메뉴 위 가운데, 새 콘텐츠 카드와 겹치면 카드 위에 뜬다.
- **공용 알림**(`#game-toast-region`, 2026-09-30 손질): 자리는 그대로(PC 오른쪽 위, 휴대폰 아래)이고 모양만 바꿨다.
  도트 돌판을 반투명하게(뒤 전장·미니맵이 비친다), 왼쪽 띠와 표시 색이 종류(정보 금 · 성공 초록 · 경고 호박 · 위험 빨강),
  폭 330px로 좁게. **누르면 바로(0.09초) 사라진다.** 휴대폰 전투 로그 알림(`#mobile-toast-root`, `showNextMobileToast`)도
  같은 모양이고 누르면 바로 다음 알림으로 넘어간다. 휴대폰에서는 두 알림이 겹치지 않게 공용 알림을 로그 알림 위로 쌓고
  가장 최근 두 개만 보인다. 안내 카드가 떠 있는 동안 휴대폰 로그 알림은 기다렸다가 카드가 닫히면 나온다(카드 단추를 덮었다).

## 안내 카드 (2026-09-29 추가)

`js/tutorial-ui.js` · 스타일 `css/ui-game-overhaul.css`(카드는 components, 메뉴 단추 깜빡임은 overrides).

- **머리말로 종류를 가른다**(`tutorialNoticeKind`): 처음 하는 조작은 `시작 안내`(이끼색), 새로 열린 콘텐츠는
  `새 콘텐츠`(금색), 루프 도달은 `새 루프`(보라). 예전에는 전부 "새 콘텐츠"였다. 이야기 장면은 그대로.
- **본문**(`tutorialBodyHtml`): 첫 줄은 무슨 일이 생겼는지, 나머지 줄은 할 일 목록(도트 점). 따옴표로 시작하는 줄이
  있으면 목록 대신 문단으로 둔다. 문구를 쓸 때는 줄마다 한 가지만 말한다.
- **단추 이름**: 조작 안내가 있으면 `따라 해보기`, 없으면 `○○ 열기`(`TUTORIAL_TAB_NAMES`, 메뉴 이름과 같게).
- **다음 안내 N**: 뒤에 기다리는 카드 수를 카드 오른쪽 위에 적는다(이야기 장면에서는 숨김).
- **메뉴 단추 깜빡임**(`setTutorialCallout`): 카드가 가리키는 화면의 메뉴 단추에 금빛 테. 단추가 기타(PC)·전체(휴대폰)
  메뉴 안에 있으면 여는 단추와 메뉴 속 단추 둘 다. `확인`으로 닫아도 6초 동안 남는다. 움직임 줄이기 설정이면 깜빡이지
  않고 테만 둔다.
- **액트 제목과 겹치지 않는다**: 이야기 장면이 아닌 카드는 액트 제목(`actTitleCard.busy()`)이 떠 있거나 뜰 차례면
  기다린다. 제목은 전장 시계로 흐르므로 전장이 실제로 그리고 있을 때만 기다린다(전장이 안 보이면 막지 않는다).
- **새 캐릭터의 첫 조작**(`queueStarterGuides`, 루프 1만): 탭이 처음부터 열려 있어 예전 "스킬트리 개방"·"장비/제작 개방"
  카드가 뜨지 않으면서 그 카드에 달린 따라 해보기도 사라져 있었다. 레벨 2에서 `첫 패시브 포인트`, 첫 장비를 주우면
  `첫 장비` 카드를 띄우고 예전 안내를 이어 붙인다. 예전 카드를 본 세이브는 다시 띄우지 않는다.
- 시작 순서: 프롤로그 → 액트 1 이야기 → 액트 제목 → `첫 여정` → `첫 스킬 젬 장착` → (레벨 2) `첫 패시브 포인트`
  → (첫 장비) `첫 장비`.
- **글 색**(2026-09-30): 본문의 `‘메뉴·단추’`는 카드 종류 색(어디로 갈지), `[이름]`은 하늘색(무엇인지)으로 칠한다
  (`tutorialMarkup`). 카드 위 테 아래에 종류 색 가는 줄. 문구를 쓸 때 메뉴·경로는 ‘…’, 아이템·젬 이름은 […]로 감싼다.
- **액트 제목**(2026-09-30): "액트 N"과 액트 이름만. 한 줄 부제는 목표 창과 같은 말이었고 PC에서는 목표 창, 휴대폰에서는
  미니맵 밑으로 들어갔다. 부제는 액트 클리어 보상 창에는 그대로 남아 있다.

## 새 콘텐츠 카드 (2026-09-30)

콘텐츠 대부분이 해금 창에서 사서 열리게 바뀐 뒤로, 사도 "○○ 해금" 알림 한 줄뿐이었다. 예전 해금 카드는 사기 전에
떠서, 아직 열 수 없는 창을 가리킨다는 이유로 보이지도 않고 사라졌다(대기열이 넣는 순간 '본 것'으로 적는다).

- **콘텐츠마다 카드 한 장**(`contentUnlockUi.announceContent`, `js/content-progression-ui.js`): 제목은 콘텐츠 이름,
  첫 줄은 해금 목록의 설명(`CONTENT_UNLOCK_CATALOG.description`), 둘째 줄은 `‘장비 → 거래소’에 있습니다`
  (`CONTENT_ROUTE_PATHS`, 메뉴 이름 그대로). 단추 `○○ 열기`는 하위 탭·탐험 목록까지 정확히 연다(`openTutorialTarget`).
  - 산 콘텐츠: 사는 순간. 같이 열리는 무료 콘텐츠(장비 제련 → 거래소·장비 전당)도 한 장씩.
  - 무료 콘텐츠: 루프·조건에 닿아 처음 열린 순간(`checkUnlocks`의 `syncOpened`). 불러온 저장에서 이미 열려 있던 것은 알리지 않는다.
  - 자기 카드가 따로 있는 콘텐츠(`CONTENT_CARD_DEDICATED`: 그루터기 함·생장판·시간의 균열·코어 큐브·혼돈계·창공·지하계·
    우주계·심해·낚시·경계 너머·운석 낙하 지점)와 루프 1 기본 콘텐츠는 카드를 따로 만들지 않는다.
- **사기 전에 뜨는 안내**(`queueContentNotice`, `js/state.js`): 봉인된 카드 발견·재능 개화·전문가 조우·첫 고유 장비·첫 나이테·
  주얼·직업전직처럼 해금에서 사야 하는 콘텐츠의 안내는, 아직 사지 않았으면 "‘해금’에서 ○○을 열면 …"이라 쓰고 해금 창을
  가리킨다. 이미 샀으면 그 화면을 가리킨다.
- 남은 카드 문구 35개도 같은 형식으로 고쳤다. 틀린 곳도 바로잡았다: 대균열 단추는 `대균열 입장`, 생장판 카드는 플라스크 창이
  아니라 `보조장비 → 생장판`, 버려진 날붙이 결투는 `지도 → 탐험 → 강대한 적`, 직업 탭 이름은 `직업전직`.
- 검사: `scripts/smoke-content-unlock-cards.js`.

## 하단 HUD (2026-09-30)

디아블로 계열 하단 바처럼 **왼쪽 생명 구슬 · 가운데 미니맵 · 오른쪽 경험치 구슬**, 그리고 PC는 **메뉴도 이 바 안에** 있다.
둥근 셋이 낮은 돌판 위로 솟는다. 테는 사용자 HUD 그림의 쇠 · 청동 매듭 테다(뿔·기둥 같은 장식은 넣지 않는다).
스타일: `css/themes/pixel-hud.css` 끝 부분(HUD) · `css/themes/pixel-menu.css`(메뉴). 그림: 판 · 테두리는 `scripts/build-pixel-ui.cjs`,
구슬 · 미니맵 테 · 메뉴 단추 틀은 `scripts/build-hud-kit.cjs`.

- **구슬 · 미니맵 테 · 메뉴 단추 틀은 사용자 HUD 그림에서 잘라 쓴다**(2026-10-01, 사용자 결정 "지금 적용"). 원본 네 조각
  (`tools/hud-kit/source/`: 생명 구슬 · 경험치 구슬 · 미니맵 · 인벤토리 단추)을 `scripts/build-hud-kit.cjs`가 도트 그대로 층으로 나눈다.
  구슬은 윗층(테 + 유리 위 반짝임) · 빈 유리 · 액체 세 장이고, CSS가 액체를 `--gauge-fill`만큼 아래에서 잘라 겹친 뒤 맨 위 두 도트에
  원본 그림의 수면 색을 긋는다. 원본 생명 구슬은 반쯤 찬 그림이라 수면 위 액체는 수면 아래를 뒤집어 채우고, 빈 유리는 그 액체를
  어둡게 뺀 색이다. 미니맵 테는 창을 136도트에 맞추려고 반지름 방향으로 3도트 밀었고, 캔버스는 창보다 4도트 안쪽까지만 그려
  그 틈에 탐험 비율 호가 돈다. 메뉴 단추는 인벤토리 단추를 9칸으로 잘라 이은 40도트 틀(`hud-key`, 열린 창은 청동을 금빛으로
  올린 `hud-key-on`). 예전에 코드로 찍던 둥근 테(`orb-ring` · `map-ring` · `key-socket`)는 지웠다.
- **크기**: 한 도트 = `--px-hud-dot` CSS px. PC는 1(uiDisplay가 1 CSS px = 1 기기 픽셀로 맞추므로 원본 도트 그대로), 휴대폰은 .5
  (구슬 유리 50px · 지도 창 68px — 예전 휴대폰과 같은 유리 크기). 구슬 상자 = 원본의 유리 원(100도트)이고 테는 상자 밖으로 걸친다.

## HUD 재질로 전체 통일 (2026-10-01)

HUD 그림의 재질(먹선 · 청동 빗면 · 숯빛 판)을 창 · 단추 · 판 · 오버레이 전부에 입혔다. 그림은 `scripts/build-hud-kit.cjs`가 같은
원본에서 만든다: 창 테 `hud-window.png`(모서리 매듭 26도트), 단추 `hud-btn(-hot · -on · -down).png`, 움푹한 칸 `hud-inset.png`,
판 결 `hud-panel(-dark).png`. 색은 `css/themes/pixel.css` 머리의 `--px-*` 변수 하나로 모았다(먹 #080508 · 밝은 청동 #c59862 ·
청동 #845f42 · 어두운 청동 #483239 · 판 #1e1c22). 단추는 1px 먹선 + `--px-bevel`(밝은 청동 · 청동 · 먹 세 겹 빗면), 주 동작은
`--px-gold-rim`, 눌린 상태(열린 탭 · 고른 분류)는 `--px-bevel-pressed`.

- **창**: 제목 띠 아래 청동 · 먹 두 줄, 창 안 제목(h2)은 금빛 + 청동 밑줄(예전 ui-luxe의 남색 밑줄). 휴대폰 창의 소제목(h3)이
  base.css의 주황으로 남던 것은 `@layer components` + `:where()`(우선순위 0)로 글빛만 바꿔, 영역별 색 규칙은 그대로 이긴다.
- **판**: 진행 판(`.progression-section` 등) · 트리 요약 · 재능 개화 · 젬 공방(성장 · 각인) · 대전 · 패시브 트리 서랍 · 커뮤니티 도크 ·
  입력칸(남색 그라데이션 `background-image`까지 걷어 냄)이 모두 같은 숯빛 판. 원소 꼬리표(냉기 · 주문 · 혼돈)의 색은 의미라 남겼다.
- **런타임에 넣는 `<style>`**(social · ghost-pvp · cloud-tools)은 `@layer components` 안에 넣는다. 레이어 밖 CSS는 모든 레이어 규칙을
  이겨서 스킨이 덮지 못했다(커뮤니티 안내판이 남색으로 남던 원인).
- **오버레이**: 직업 선택 · 루프 정산/결정 · 액트 보상 · 사망 기록 · 패치 노트 카드가 창과 같은 매듭 테. 휴대폰에서 고르는 오버레이는
  하단 메뉴 띠(z 13100)보다 위(13200)이고 카드는 화면 안에서 스크롤한다 — 직업 카드 아래 줄이 메뉴에 가려 눌리지 않았다.
  사망 기록의 분류 탭은 고른 쪽이 눌린 판 + 금 밑줄(모든 단추에 입힌 빗면이 예전 활성 표시를 덮었다).
- **시작 · 불러오기**: 로그인 판은 가벼운 판, 입력은 움푹한 칸, 불러오기 막대는 먹 테 안 금빛 칸. 불러오기 문구에서 "에셋"과 영어
  부제(Loading Battle Assets 등 12개)를 뺐다. 이 기기에 저장이 있으면 게스트 단추가 **이 기기 저장으로 이어하기**.
- **글자**: 도트 글꼴은 소수 크기(em · rem 배율의 9.5 · 11.18 · 11.9px 등)에서 번져 자주 쓰는 자리를 정수로 맞췄다(단추 · 수치 · 서랍 ·
  도감 카드 · 기록 · 해금 단계 · 클라우드 판 · 젬 공방 7~10px 글씨 → 12px). 영어 대문자 머리글 16곳은 한국어로 바꾸고 넓은 자간을 풀었다
  (예: SANCTUARY HALL → 성소의 기록, ATTACK GEMS → 주 스킬, Death Log → 사망 기록). 창 제목 앞 컬러 이모지는 뺐다.
- **자리**: 휴대폰 지역 이름은 진행 막대가 숨은 지역에서 그 칸까지 써서 잘리지 않는다. 지도 창의 "현재 위치" 중복 줄은 사냥 권역
  머리판이 있을 때 숨긴다. 전리품 연출의 "연출 건너뛰기"는 PC에서 경험치 구슬 뒤에 가려졌다 — 미니맵 테 바로 위 가운데로.
  잠긴 루프 패시브는 넓은 창 위쪽 한 줄 대신 가운데 안내 판.
- **겹침 정리**: PC 알림은 귀환 단추 아래(위 50px)에서 두 개까지. 휴대폰 전투 탭의 알림 · 따라 하기 카드는 HUD 판 위(기록 막대 위)로,
  안내 카드가 떠 있으면 전투 기록 알림은 카드 뒤(z 13200 — 알림 판의 인라인 z-index 22000을 `!important`로 덮는 유일한 자리).
  PC 채팅 판은 전투 기록처럼 관리 창 아래(z 1100). 대상 적의 특성 꼬리표는 체력 숫자 위가 아니라 막대 아래. PC "기타" 목록은 바깥을
  누르거나 Esc로 닫힌다. PC 패시브 트리는 창 높이에 맞춰 줄어(최소 280px) 프리셋 단추가 잘리지 않는다.
- **휴대폰 가로**: 높이 600px 이하 가로 화면은 테를 반 굵기로, HUD 돌판은 상자 안에 맞춘다. 주소창이 보이는 좁은 가로(높이 339px 이하,
  터치 기기)는 배치가 들어가지 않아 "세로 화면으로 돌려 주세요" 가림막만 띄운다.
- **검사 도구(로컬)**: 창마다 남색 · 보라 판, 소수 글자 크기, 영어 문구를 세는 Playwright 스크립트로 확인했다(데스크톱 1440×900 · Pixel 5).

## 출시 전 검토 2차 반영 (2026-10-01)

엄격한 출시 직전 기준 검토(65점)에서 나온 항목을 고쳤다. 화면만이 아니라 초반 경험을 망치던 흐름도 포함한다.

- **초반 사망 반복**: 새 캐릭터가 같은 무리에 거듭 쓰러지며 탐험 전리품을 잃었다. 원인은 앞 전투에서 깎인 생명으로 다음 무리를 맞는
  소모전(측정). 스토리 액트에서 살아 있는 적이 없을 때 초당 최대 생명의 `ACT_REST_RECOVERY_PCT_PER_SEC`(6%)를 회복하고, 자동 진행
  (다음 지역) 중 쓰러지면 한 액트 물러나 `ACT_RETREAT_LEVELS`(2)만큼 레벨이 오른 뒤 다시 도전한다(`game.actRetreat`, 저장 유지 ·
  잘못된 값은 불러올 때 버림). 반복 설정이나 직접 고른 지역은 건드리지 않는다. 20분 측정(6직업 × 2시드): 사망 175 → 33회.
- **사망 기록**: 잃은 탐험 전리품(아이템 N개 · 재화 N종)과 물러난 액트를 적는다. 읽을거리라 열려 있어도 방치 진행을 멈추지 않는다.
- **장비**: 탐험 보상으로 받은 장비가 조용히 가방에 들어가던 것을 장비 배지로 알린다. 정산은 여전히 빌드를 바꾸지 않고, 장비 창
  정리 막대의 **빈 칸 채우기 N** 한 번으로 빈 칸만 티어 · 등급 높은 것부터 채운다(찬 칸 · 요구 레벨 미달은 그대로).
- **기호 · 글자**: 루프 패시브 노드의 기호 글꼴 문자(⌈ ∞ ✺ …)를 한 글자(경 · 피 · 생 · 치 …)로, 장비 가방 칸의 6~7px 배지를
  12px 두 글자(잠금 · 세팅 · 특수)와 색으로 나눈 +N%(주황 공격 · 초록 생존)로 바꿨다. 사망 원인 · 재능 · 숙련 · 전직 잠금 문구의
  이모지를 뺐다. 오프라인 결과에는 계산식(최대 N시간을 N% 속도로)을 적는다.
- **성능**: 스킬 이펙트 스프라이트의 색 필터를 프레임마다 `ctx.filter`로 걸던 것을 작은 캔버스에 한 번 구워 재사용한다
  (`js/canvas-fx-remake.js` filteredFrame). CPU 4배 감속에서 이펙트가 몰린 장면 26.5 → 58 fps.
- **휴대폰 누름 자리**: 목표(38×25) · 귀환(48×32)은 모양은 그대로 두고 보이지 않는 자리를 44px 넘게 넓혔다(버튼 공통 overflow:hidden을
  풀어서 — 목표 단추의 절대 위치는 원래 규칙 그대로). 젬 칸은 누르는 칸(주 공격 44 · 이동 스킬 40px)이 윗줄, 소환 젬(누르면 스킬 젬
  창)은 24px 알로 아랫줄 — 다섯 칸이 세 줄로 쌓여 HUD가 늘어나던 것을 두 줄로. 젬 칸이 88px를 늘 갖도록 이름 칸이 양보한다.
- **세로 고정**: 안드로이드 활동을 `screenOrientation="portrait"`로 고정했다(웹은 좁은 가로에서 "세로로 돌려 주세요" 가림막).
- **안내 카드**: 오프라인 결과를 계산하거나 보여 주는 동안에는 따라 하기 카드를 미루고, 창 배치가 바뀌면 카드 자리를 다시 잡는다.
- **시작 화면**: 이 기기에 저장이 없으면 요약 칸을 숨기고 제목을 "새 모험"으로.
- **따라 하기**: 첫 스킬 젬 안내는 젬 상세가 열리면 표시를 그 '장착' 단추로 옮긴다(가이드 selector는 우선순위 배열, 보이는 첫 요소).
  휴대폰에서 직업 카드를 눌러 고르면 카드 툴팁이 전투 HUD 위에 남던 것을 닫는다.
- **스킬트리 첫 화면**: 새 캐릭터는 기본 직업(궁수)의 "닿는 노드"가 남아 트리를 처음 열면 트리 절반을 담는 최소 배율(0.14)로
  물러나 시작점이 화면 밖에 있었다 → 직업을 고르거나 바꾸면(반환할 패시브가 없어도) 닿는 노드를 다시 세고, 카메라를 맞추기 전에도
  한 번 더 센다. 아직 투자하지 않았으면 시작점이 가운데보다 높이 10% 넘게 아래로 가지 않게 카메라만 옮긴다(배율은 그대로).
  시작점을 누르면 "연결된 노드가 아니라…" 대신 시작점 안내를 알림으로, 휴대폰 상세의 "0포인트 사용"은 "시작점 · 이미 열림".
  휴대폰에서 노드는 화면 반지름 22px 안이면 잡힌다(예전엔 그린 반지름 + 8월드 ≈ 5px).
- **태블릿 · 좁은 PC 창(1080px 이하, 높이 600px 넘는 가로)**: 가로 전용 규칙이 600px 이하 가로 휴대폰 몫이라 1024×768에서는 HUD가
  지역 줄을 덮은 채 위로 올라가 있었다 → 세로 쌓기 배치를 그대로 쓴다. 쌓는 배치의 HUD 돌판 · 메뉴 띠는 반 굵기 테(26px 테가 솟아
  "전투 로그" 글씨를 덮었다), 이름 칸은 생명 구슬 테에서 4px 띄운다("미전직"이 "기전직"으로 보였다).
- **남은 옛 모양**: 둥근 모서리(장비 검색칸 · 스킬트리 틀 · PC 전장 틀)와 번짐 광택(스킬트리 필터 · 첫 젬 안내 · 적 체력 막대)을 전 창에서
  찾아 정리, "황금률 획득!" 띠는 HUD 판. 전체 메뉴 서랍이 열리면 DPS 칩을 숨기고, 서랍의 "다음 지역"은 "완료 후 다음 지역"으로.
- **고해상도 PC(Retina · 200%)**: 디스플레이 배율 전체를 되돌려 1 CSS px = 1 기기 픽셀로 그렸더니 2배 화면에서 UI가 절반 크기였다.
  배율의 정수 부분은 살리고 소수 부분만 되돌린다(2 → ×2, 1.25 → ×1, 2.5 → ×2) — 도트는 늘 기기 픽셀의 정수 배(js/ui-display.js).
- **UI 스킨 하나로**: 예전 스킨(검은 성유물함 · 녹청 성당 · 핏빛 참회)은 옛 세로 칸 배치라 도트 HUD를 담지 못했다(PC에서 생명 구슬이
  화면 밖). 균열 등불 하나만 남기고, 저장에 예전 스킨이 있어도 균열 등불로 읽는다(설정의 고르는 줄은 숨김).
- **안전 영역**: 휴대폰 세로 배치가 body 여백을 0으로 두어 노치 · 상태 표시줄 아래로 지역 줄이 들어갔다 → 위쪽 안전 영역만 비운다.
- **알림 자리(PC)**: 오른쪽 위는 창 제목 줄(닫기 · 최대화)과 겹쳐 왼쪽 위 몬스터 수 줄 아래로.
- **따라 하기 카드가 다른 화면에 있을 때**: 전투 화면으로 돌아오면 제목 · 단추만 한 줄(휴대폰)로 줄여 전장을 덜 가린다.
- **가벼운 판 불투명**: 툴팁 · 안내 카드 · 목표 판의 `--px-panel`이 96%라 아래 창의 밝은 글씨가 비쳐 보였다 → 불투명.
- **사망 기록**: 본문이 여섯 줄이 되며 108px 칸에서 마지막 줄이 잘려 176px로. "(으)로" 대신 받침에 맞춘 조사
  (`withDirectionParticle`: 성소로 · 숲으로 · 길로). 방치 결과 창 제목은 "방치 전투 결과"(백그라운드 → 방치).

## 그대로 둔 것

- 이야기 삽화(프롤로그·저널), 시작 화면 배경 그림, 패시브 트리 노드 그림, 상태 이상 아이콘 묶음은 원화 그대로.
- 구글·카카오 로그인 버튼은 각 사 표기 규정대로 원래 글꼴.
- Windows 데스크톱은 글자에 서브픽셀 안티앨리어싱이 걸려 확대하면 글자 가장자리에 색 번짐이 보인다(1배에서는 티 나지 않음).
