## 2026-09-11 — 재화 선택과 자동 사용

- 재화 이름을 카드의 주 표기로 올리고 효과를 보조 설명으로 옮겼다. 재화/홀씨를 고른 뒤 목표를 정한다.
- `getAvailableMods`로 현재 베이스, 부위, 잠금, 중복을 반영한다. 추가형 홀씨는 실제 홀씨 후보로 좁히고,
  전체 재련은 일반 줄에서 나올 수 있는 옵션도 남긴다. 남는 줄이 보장 옵션 하나뿐인 경우도 반영한다.
- 실제 제작과 시안이 같은 `SPORE_CRAFT_MOD_IDS`와 `equipmentCrafting.filterSporeMods`를 사용한다.
  기존 홀씨 후보/확률은 바꾸지 않고 중첩 함수의 기존 표를 공용 데이터로 옮겼다.
- 황금률 목표는 현재 수치가 변할 수 있는 옵션과 기존 티어 이내로 제한한다. 옵션/티어를 새로 뽑는 자동 사용에는 황금률을 제외한다.
- 자동 사용은 기본 20회, 1~100회 범위에서 사용자가 정한 상한을 적용한다. 400ms 간격으로 실제 사용을 한 번씩 실행한다.
- 목표 달성, 재료/제작 조건 불충족, 상한 도달, 직접 중지, 재화/장비/목표 변경, 화면 이탈 시 중지한다.
  매 사용 전후 조건을 확인하며, 취소된 실행의 타이머가 다시 재료를 쓰지 않도록 실행 번호를 검증한다.
- 기존 목표가 새 재화/장비에서 불가능하면 지우고 다시 선택하게 한다. 목표 티어를 몰래 낮춰 자동 사용하지 않는다.
- 확률 변경·자동 재료 보충·세이브 반영은 없다. 기존 실제 저장과의 분리를 유지한다.
- 검증: PC/모바일 10개 검사 통과(목표/횟수/재화/홀씨 제한 정지, 수동 취소, 재화 변경과 화면 이탈,
  출현 불가 후보 제거, 황금률 티어 범위, 저장 분리). 전체 스모크 183/183 및 구조 검사도 통과했다.

  이름/효과 검색, 보유 재화 필터, 0개 표시를 제공한다. 구형 주얼 핵은 보유한 경우만 표시한다.

- 홀씨는 전체 재련의 함께 사용 설정으로 연결한다. 나머지 재화는 현재 체험에서 용도 확인만 제공한다.
  새로운 재화 사용 효과나 제작 확률은 만들지 않는다. 세이브 격리/자동 사용 정지 계약을 유지한다.
- 검증 중 기존 전투 스모크의 무작위 장비 드랍 경로에서 제작 모듈 로드 누락을 발견했다.
  실제 index.html과 같이 equipment-crafting.js를 로드하도록 테스트 런타임만 수정했다.
- 전체 스모크 183개와 구조 검사 통과. PC/모바일 재화 검색·화석 사용/부위 제한·복원·표시 검사 추가.

  선택한 재화는 테두리와 `선택 중` 문구, 제작실의 선택 재화 영역으로 구분한다.
- `목표 옵션` 제목은 요청한 문구의 커스텀 툴팁을 제공한다. 마우스 호버/키보드 포커스/모바일 탭으로
  열리고, 모바일에서 포커스를 옮기면 닫힌다. 터치 기기의 잔류 hover는 적용하지 않는다.

  주 재화 설정의 저장 복원을 함께 적용해야 한다. 운영 세이브 형식은 이번 단계에서 변경하지 않았다.

  실제 보유하거나 획득 기록이 있어도 제외한다. 기본 제련 분류를 `기본 재화`로 변경했다.
- 방패/쐐기/오래된/균열 화석 이름의 이모지를 ORB_DB와 FOSSIL_DB 양쪽에서 제거했다.
  원본 자산 아이콘을 사용하는 기본 재화의 그림은 유지한다.
- 화석 설명은 `…옵션 하나를 확정하여 희귀 아이템의 옵션을 다시 굴립니다.`로 통일했다.
  균열 화석은 실제 표식+증폭 두 효과를 설명하고, 방패 화석은 실제 최대 화염/냉기/번개 저항과 방어구 범위를 표시한다.
- 카탈로그와 선택 재화 설명은 ORB_DB의 동일한 문구를 사용한다. 텍스트를 먼저 이스케이프한 뒤
  매직/희귀/물리/근접/생명/방어/속도/치명/저항/원소/카오스/흡혈/재생 등의 키워드에만 색상을 적용한다.
- 목록 UI는 체험 페이지 변경이다. 이름/설명은 기존 공용 게임 데이터에도 반영하고 캐시 키를 갱신했다.
  옵션 풀, 제작 조건, 보장 수치, 결제, 저장 구조는 변경하지 않는다.

## 2026-09-11 — 짧은 목록과 선택 상세

- 재화 카드에는 짧은 핵심 효과만 표시하고, 선택하면 목록 아래에 공용 ORB_DB의 전체 설명을 표시한다.

  `제작실에서 선택` 또는 `정제·복원 열기`를 누르기 전에는 제작 설정과 보유량을 바꾸지 않는다.
  주 재화 편집은 기존의 슬롯 지정 흐름을 유지한다.

- `기타 재화`에서는 미궁/원시/원시 고대 화석과 속성 홀씨를 목록·검색에서 제외하며 빈 홀씨 분류도 숨긴다.
  독립 `재화 인벤토리` 및 정제·복원/홀씨 함께 사용 경로는 유지한다. 두 진입점 간 전환 시 분류 표시를 복원한다.

## 2026-09-11 — 선택 용도와 장비 조건 가시성

- 기타 재화로 열면 `제작 재화 선택`, 독립 보관함에서는 `재화 인벤토리`를 표시한다.
  카드마다 반복하던 `상세 보기`를 제거하고 선택/주 재화/사용 제한만 표시한다.
- 체험에 연결된 제작 재화는 현재 대상 장비의 실제 제작 조건을 읽어서 불가 상태를 표시한다.
  사용할 수 없어도 설명은 볼 수 있으며, 선택 적용 버튼만 비활성화한다. 방패 화석의 무기 적용은
  `방어구 전용`으로 표시하고, 방어구로 바꿔 다시 열면 사용 가능 상태를 다시 계산한다.
- 조건 확인에는 기존 장비/화석 제작 검사를 재사용한다. 목록 검색/선택만으로 장비·재화·홀씨 설정을
  바꾸지 않는지 검사한다. 체험에서 아직 제작 동작을 연결하지 않은 재화는 기존 용도 확인 상태를 유지한다.
- 직접 클릭 점검에서 상세 영역이 펼쳐지며 목록 아래의 선택 카드가 가려지는 문제를 확인했다.
  선택 후 카드가 목록 안에 보이도록 가장 가까운 위치로 스크롤한다.
- 검증 흐름: 재화 검색→조건 확인→닫기, 불가 장비→가능 장비 전환→화석 실제 사용,
  카드/상세/버튼의 PC·모바일 가림, 주 재화 변경, 자동 사용 정지와 목표 보호.
- 장비 전환 검사에서 체험 조건이 방패 화석의 일반 방어구 예외를 누락한 것을 발견했다.
