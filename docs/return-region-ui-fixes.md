# 정산·지역 메뉴 수정

- 정산 진행을 0.1% 단위로 표시하고 폭 전환 애니메이션의 지연을 제거한다. 처음과 완료 화면은
  브라우저가 그릴 기회를 받은 뒤 계산/결과로 넘어간다. 완료 100%는 정산 작업 완료를 뜻하며,
  실제 반영 시간과 포기 시간, 보상 계산식은 바꾸지 않는다.
- 결과창 외곽과 제목/버튼 영역, 보상 요약의 경계를 공통 테마 토큰으로 구분한다.
- 지도 지역 버튼은 자신이 여는 지하계·심해·낚시 패널을 즉시 그린다. 주기적 전투 갱신이나
  테스트의 수동 `updateStaticUI()` 호출에 의존하지 않는다. 접근 조건은 기존 검사에서 유지한다.
- PC 기본 레일은 고정된 개수 제한 없이 현재 높이에 들어가는 탭을 표시한다. 가지치기도 같은
  순서·공간 기준을 사용하며, 공간이 부족할 때만 넘치는 탭이 기타로 이동한다. 창을 키우면
  자동으로 복귀하고 저장된 탭 순서는 바뀌지 않는다. 사용자가 지정한 기타 배치와 모바일 분류는 유지한다.
- 로그인 선로딩과 배경 지연 로딩은 `login-loading-resources.md`, `battle-asset-loading.md` 참조.

검증: `npm test`, `npm run check:architecture`. Playwright의 `realm-workflow`,
`runtime-settlement`, `equipment-loot-filter`, `core-ui` 관련 시나리오에서 PC/모바일 실제 진입,
진행률의 그려진 폭·완료 프레임, 즉시 종료/저장 실패 재시도, 장비 툴팁, 로그인 캐시 재사용,
데이터 절약 모드, 배경의 필요 시 단일 요청을 확인한다. `settings-layout`에서는 창 높이에 따른
기타 이동·복귀, 넘친 탭 열기와 기존 메뉴 설정 보존을 확인한다. 저장 shape와 스크립트 순서는 유지한다.
