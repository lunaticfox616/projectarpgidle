## 1. 결론

- 접두 3, 접미 3은 지금 굴림 코드에 작게 들어간다. 메모리 안 원형(A2안)은 5파일 +93/-66줄, 스모크 294개 통과, 구조 검사 래칫
  통과, 굴림 시간 차이 3% 안.
- 지금 희귀의 33%가 한도를 넘는다(수액 봉오리로 6줄을 채운 장비는 55~100%). 기존 장비는 그대로 두고 넘은 종류에 더 붙이는 것만
  막으면 되므로 저장 형태는 바뀌지 않는다.
- 3/3을 못 채우는 부위는 신발 하나다. 이동 속도를 접두로 옮기면 모든 부위가 채워진다.
- 힘 변화는 작다. 부위마다 12개 중 최선을 고르면 DPS -4%~+5%, EHP -3.5%~+2%. 무작위 T20 희귀 한 벌로 맞추면 EHP -6~-7%
  (저항 줄이 11% 줄어서).

## 4. 단계

### A. 3/3 굴림, 제작, 툴팁(약 350줄)

- data/items.js에 `EXPLICIT_AFFIX_RULES` { magic 1/1, rare 3/3 }. 흩어진 상한 6과 4~5줄도 여기로 모은다.
- MOD_DB 22줄의 type(A2안): 접두로 젬 레벨 9줄, 보조 젬 한도, 이동 속도, 주문 내장 피해 증가%. 접미로 타겟 3줄, 투사체 추가 발사,
  소환수 최대 한도, 최대 저항 5줄.
- equipmentCrafting에 affixKind, storedAffixKind, affixCounts, affixRoom, fitsRoom. 화석 전용 줄, 균열 표식, 심해 고정 옵션은
  종류로 세지 않는다.
- 굴림: pickRandomMods(mods, count, room)는 고를 때마다 자리가 남은 종류에서만 고른다(지도석과 같은 방식). rerollExplicitMods는
  혼돈 주입을 먼저, 홀씨 보장 줄을 먼저 넣고 남은 자리를 채운다.
- 추가 제작(수액 봉오리, 독벌침, 주입)은 자리가 있는 종류에서만, 없으면 결제 전에 막는다. 바꾸기 제작(바다의 선물, 변환, 메아리,
  심해의 파편, 잿불가지 다시 굴림)은 바뀌는 줄을 빼고 센다. 잿불가지 addMod만 한도를 넘는다(지도석 타락과 같다).
- 저장 형태는 그대로. 한도를 넘은 예전 장비는 줄을 지우지 않고 넘은 종류는 자리 0으로 본다.
- 툴팁 "추가 옵션 5/6 (접두 2/3, 접미 3/3)". 공개 프로필은 snapStatMarks에 kind(예전 프로필은 표기만 없음).
- 검사: 새 smoke-affix-kinds.js, smoke-social-format.js 머리 문구, 끝에 tests/browser/crafting-workspace.spec.js.

원형 결과(A2): 초과 0, 평균 줄 수 그대로(희귀 4.50, 마법 1.50). 대표 분포 무기 3P2S 31%, 투구 2P3S 48%, 신발 2P3S 46%.
혼돈 뒤 수액 봉오리로 채우면 모든 부위가 6줄 3P3S에 닿는다. 예전 5P1S 무기는 6줄 그대로, 남은 자리 {접두 0, 접미 2}.
생성 3.01s → 3.01s, 재굴림 2.88s → 2.87s(10k번 중앙값).
