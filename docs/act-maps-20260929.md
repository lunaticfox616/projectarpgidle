# 액트 탐험 맵 그림 — 예전 디오라마 스타일 (2026-09-29)

탐험 맵(위에서 본 16도트 칸)의 그림을 예전 전투 디오라마(`assets/background/act1~10.png`, 8×8 마름모 판)의
**스타일만** 가져와 다시 찍었다. 시점·칸 크기·걷는 칸·관문 위치·게임 코드는 그대로이고 그림 파일만 바뀐다.

## 무엇을 가져왔나

| 액트 | 디오라마에서 가져온 것 | 맵에서의 모양 |
|---|---|---|
| 1 뿌리끝 성소 | 칙칙한 올리브 흙, 굵은 뿌리, 창백한 버섯·촛불, 낙엽, 이끼 웅덩이 | 무너진 판석 + 방 가운데서 굽이쳐 뻗는 뿌리, 흙벽과 뿌리 엮임 |
| 2 가지치기의 중정 | 푸른 회녹색 판석, 금 상감, 고딕 아치와 난간, 늘어진 뿌리 | 칸 맞춤 판석, 북쪽 벽은 아치 줄 |
| 3 허공뿌리 현수림 | 바랜 뼈색 판석과 뿌리, 아래는 허공 | 창백한 판석 발판, 널다리, 가장자리를 감은 바랜 뿌리 |
| 4 갈림뿌리 미궁 | 적갈색 서재 겸 연금실, 아치 문·선반·물약·방패·등, X자 뿌리 | 방마다 X자 뿌리, 북쪽 벽은 나무 벽에 문·물약 선반·방패·벽등 |
| 5 지주근의 침묵 성소 | 갈색 석조, 새긴 원, 난간과 아치 문, 검은 물 | 판석, 난간 벽과 아치 문, 무덤돌·촛불 |
| 6 무너진 중정 | 어두운 갈색 판석, 무너진 난간, 부러진 흰 자작나무 | 네잎 새김 판석(테두리 없음), 난간 벽 앞에 선 흰 자작나무 줄기 |
| 7 말라가는 큰 줄기 | 해살처럼 퍼진 널빤지, 줄기 벽, 선반 버섯, 등 | 방마다 방사형 널, 나이테 벽에 선반 버섯·매단 등 |
| 8 끝없는 장막의 줄기 | 보랏빛 판석, 널빤지 고리, 등나무꽃 | 판석을 두른 널 고리, 등나무꽃 장막 벽, 허공에 늘어진 꽃줄기 |
| 9 비탄의 교차 | 자줏빛 돌바닥의 호 무늬, 뿌리 난간, 분홍 꽃 | 판석, 뿌리 난간 벽, 자줏빛 수관과 분홍 꽃 |
| 10 합일의 차륜 | 흑요석 판석, 금빛 동심원, 별 박힌 허공, 첨탑 | 판석(금빛 고리는 표지물 한두 곳), 흑요석 벽의 금선과 첨탑, 별 허공 |

색은 디오라마에서 뽑아 단계표로 만들었다(`scripts/act-maps/palettes.cjs`). 어둡고 채도 낮은 바탕에 액트마다 강조색 하나.
건축물 액트(2·4·5·6·10)는 칸 경계를 그대로 써서 벽이 곧고, 나머지는 예전처럼 둥글고 삐뚤다.

## 색 맞춤 (같은 날 2차)

첫 판에서 외곽선과 금빛 선이 너무 튄다는 의견을 받아 색을 주변에 맞추고 장식을 조금 덜었다. 배치는 그대로다.

- **외곽선**: 벽·뿌리·바닥의 새까만 선을 맞닿은 재질 가운데 가장 어두운 색의 두 단계 아래로 바꾼다
  (`softenOutlines`, `dress.cjs`). 뿌리는 짙은 갈색, 판석 가장자리는 짙은 회녹색 선이 된다. 소품은 이 뒤에 그려서
  제 외곽선을 그대로 가진다(작아서 선이 있어야 읽힌다).
- **금빛 선**: 금 상감을 한 단계 낮추고(`warm` 2→1) 아래 그늘도 한 단계만. 액트 2의 이중 호는 한 줄로,
  동심원(액트 5·10)의 바큇살 눈금은 뺐다. 액트 2 기둥의 금 박음, 액트 10 흑요석 벽의 이중 금선도 한 단계씩 낮췄다.
- **방 바닥 선 무늬 제거(2026-09-30)**: 전투·정예·선택 방마다 그리던 사각 테두리+호(액트 2·9)와 동심원(액트 5·10)은
  농구 코트처럼 보이고 너무 자주 나와 뺐다(`themes.cjs`의 `ornament: null`). 액트 6은 네잎 새김만 남기고 방 둘레 사각
  테두리를 뺐다(`look.frame: false`). 이 무늬들은 난수를 쓰지 않아 다른 배치는 한 도트도 바뀌지 않았다
  (다시 그린 그림은 액트 2·5·6·9·10 지도뿐, 관문 그림과 다른 액트는 그대로).
- **장식 덜기**: 바닥 티끌 셋에 하나, 벽 위 이끼·버섯 점과 늘어진 줄기 넷에 하나, 바닥 뿌리·웅덩이·흩뿌린 소품
  다섯에 하나를 뺀다. 뺄 것도 **그려서 버리는 캔버스**(`ghost`, `paint.cjs`)에 그려 난수를 똑같이 소비하므로
  남은 소품 자리·뿌리 모양·방 꾸미기가 첫 판과 같다. 뺀 등불은 빛도 내지 않는다.

## 다시 만들기

```bash
node scripts/build-act-maps.cjs            # 미리보기 → artifacts/act-maps/
node scripts/build-act-maps.cjs --act 4    # 한 액트만
node scripts/build-act-maps.cjs --write    # assets/exploration/actN-map.png · actN-gate.png 교체
```

걷는 칸은 게임의 맵 데이터(`ACT_EXPLORATION_MAPS`, `actExplorationMap.layout`)에서 직접 읽으므로 맵 모양을 바꾸면
다시 돌리기만 하면 된다. 관문 그림의 크기·기준점은 예전과 같아서 `ACT_EXPLORATION_BACKDROPS.gateOffset`은 그대로 맞는다
(다르면 실행 결과에 표시된다). 같은 씨앗이면 같은 그림이 나온다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `scripts/build-act-maps.cjs` | 순서: 바닥 → 포장 → 바닥 무늬 → 뿌리·웅덩이 → 벽 앞면·윗면 → 외곽선 다듬기 → 방 꾸미기·소품 → 빛 → 관문 |
| `scripts/act-maps/themes.cjs` | 액트별 모양 표(포장·무늬·벽·소품·빛) |
| `scripts/act-maps/palettes.cjs` | 액트별 색표 |
| `scripts/act-maps/floor.cjs`, `ornaments.cjs` | 흙·판석·널, 금 상감·새김·방사형 뿌리/널 무늬 |
| `scripts/act-maps/faces.cjs`, `faces2.cjs` | 벽 앞면(흙벽·아치·난간·서재·줄기·등나무꽃·뿌리 난간·흑요석)과 벽 앞에 서는 자작나무·첨탑 |
| `scripts/act-maps/tops.cjs` | 벽 윗면(뿌리 엮임·석축·나이테·허공·수관) |
| `scripts/act-maps/props.cjs`, `dress.cjs` | 소품 도트 그림, 방 역할별 꾸미기, 흩뿌리기, 빛 |
| `scripts/act-maps/terrain.cjs`, `raster.cjs`, `paint.cjs`, `gate.cjs` | 지형 계산, 노이즈·거리 변환·PNG, 캔버스·관·덩어리, 관문 |

예전 판을 그린 `rignin-ui/art-pipeline/tiles/build_map.py`(파이썬)를 Node로 옮긴 것이다. 이 PC에는 파이썬이 없어
같은 방식으로 다시 찍을 수 있게 옮겼고, 모양 표를 디오라마 쪽으로 바꿨다. 게임은 이 스크립트를 불러오지 않는다.
