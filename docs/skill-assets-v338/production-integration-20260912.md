# 신규 젬 본편 통합 · 2026-09-12

신규 10종을 체험장 전용에서 실제 획득·장착·전투·저장 가능한 젬으로 연결했다.
기존 43종 아트 교체와 장비·제작·레벨·지도·드랍·저널·팝업 누적 변경도 같은 PR에 포함한다.

## 소유 경계

- `data/skills.js`: 젬 정의, 승인한 1차 계수와 성장, 아이콘, 사거리 문구. 기존 획득 풀을 사용한다.
- `js/skill-gem-casts.js`: 전투 스냅샷을 받아 예약 타격·이동 명령을 만든다. DOM과 피해 계산을 호출하지 않는다.
- `js/combat.js`: 기존 공격 시작 훅을 실행하고 명령을 실제 피해·흡수·상태 이상 경로에 적용한다.
  적중 반복이 공격 시작 비용·패시브를 중복 실행하지 않도록 시전 문맥을 전달한다.
- `js/canvas-world-tree-native.js`: 제공된 원본의 크롭·회전·모션으로 생성한 표현 코드다. 피해를 만들지 않는다.
  일반 타격 큐에서는 신규 전용 이펙트를 다시 만들지 않는다. 공통 프레임당 48장 예산을 유지한다.
- 임시 시전은 전투 런타임에만 두고, 방치 재생의 캡처/복원에 포함한다. 이동·죽음·중단 시 정리한다.
  영구 저장에 새 시전 데이터를 넣지 않으며 기존 저장에 무료 젬을 지급하지 않는다.
- `index.html`은 그리드 → 예약 젬 → 전투 → 렌더러 순서다. 테스트 호스트는 본편에 로드되지 않는다.

## 유지한 동작과 수정

- 암살: 전신 면적 뒤 빈 칸으로 순간이동, 접촉 1회, 별도 단검 없음. 점유되면 이동·피해 취소.
- 플라스크: 합의한 빠른 비행, 2×2 적 중심 조준. 과냉각은 직접 착지 타격 후 세 고리.
- 빈 플라스크: 기본 파편 1~4개, 기본 파편마다 확률 추가, 추가분 40% 피해, 총 파편 11개 상한.
  비교 DPS의 확률·상한도 반영한다. 탄성 플라스크는 네 접촉의 기대 계수를 반영한다.
- 시간 가속: 플레이어를 따라가는 지속 영역 하나, 초당 1회/5회. 신성한 안개: 인접 8칸과 4초 화염 취약.
- 파문심판: 십자에 적을 담을 수 있는 위치로 접근한 뒤 시전. 빈 십자를 영원히 반복하지 않는다.
- 인과: 주 공격 슬롯 집중 유지, 양수 피해 5회마다 폭발. 0 피해는 제외하고 집중 중단 시 누적 초기화.
- 고유 플라스크 궤적은 범용 발사 방식 각인으로 바꾸지 못한다. 호환 검사에서 거절하고 기존 저장의
  방식 각인도 피해 배율만 잘못 적용하지 않는다. 일반 피해/속성 보조와 빈 플라스크 추가 투사체는 유지한다.

## 재현 검사

- `node scripts/smoke-native-skill-gems.js`: 10종 실제 보스 피해, 중복 타격 방지, 확률 투자/상한,
  공격 시작 훅, 순간이동 장애물, 집중 취소, 방치 재생 격리, 구/신 저장과 연구 획득 풀.
- `node scripts/test-production-gems.cjs`: 4216 체험 서버, 본편 전투 PC/모바일 10종 피해·아트 좌표·오류.
- `node scripts/test-new-skill-lab.cjs`: 원본 체험 호스트와 승인된 모션·투자·위치 회귀 비교.
- `npx playwright test tests/browser/native-skill-gems.spec.js`: 본편 `/`에서 실제 연구 비용·중복 획득 방지,
  10종 보스 피해/모션, 명시적 장착, 저장 소유/레벨을 PC·모바일로 검증한다. CI에도 포함한다.
- 전체 스모크, 구조 검사 및 PC/모바일 브라우저 최종 결과는 PR 본문에 기록한다.

체험장은 `node scripts/build-new-skill-lab.cjs`로 만든다. `/artifacts/new-skill-gems/index.html`은 본편
코드를 사용하고 `?reference=1`은 비교용 이전 호스트다. 둘 다 저장을 분리한다.

## 검증 한계

일반 DPS 표시는 고정된 공격 기대값이다. 적 이동·빗나감·여러 고리 접촉, 지속 영역의 실제 체류율,
인과 피격 빈도와 같은 조건부 성능을 장시간 실전 DPS로 보장하지 않는다. 전체 빌드의 재미·난이도와
안드로이드 실기 발열은 이번 자동 검사로 확정하지 않는다. 이식 제작의 실제 콘텐츠 추가도 범위 밖이다.

## 통합 브라우저 검사에서 정리한 회귀

- 팝업 공통 CSS가 늘면서 단일 대화창을 클래스만으로 찾던 검사가 여러 창을 동시에 선택했다.
  실제 대화창 ID로 범위를 제한했다. 새 팝업이 위에 표시되는 동작은 별도 팝업 검사로 유지한다.
- 배경의 옛 파일명·연속 베기의 옛 개별 sweep 값을 기대하던 검사를 실제 아틀라스와 두 접촉 기준으로 변경했다.
- 장비 요구조건 도입 후 초보에게 중간 베이스를 장착시키던 테스트를 착용 가능한 초반 베이스로 변경했다.
  무작위 드랍 목록에 갑옷이 있다고 가정하던 선택 검사에는 명시적인 갑옷을 준비했다.
- 후반 진행도를 직접 부여하는 테스트는 해금 검사와 알림 큐를 먼저 처리하고 대상 조작을 시작한다.
  알림이 사용자의 입력을 막는 정상 동작을 우회하는 강제 클릭은 사용하지 않는다.
- 후반 UI 보관함 검사는 이미 읽은 지도 알림을 저장 상태에 기록한다. 늦게 갱신되는 창공 해금도
  처음 보는 알림으로 재등장하지 않게 하며, 본편 알림 동작은 변경하지 않는다.
- 필터 검사에서 만든 옵션에는 현재 밸런스 버전을 지정한다. 구버전 마이그레이션으로 시험 수치가
  바뀌는 것을 방지하고 목표 보호·미습득·자동 해체를 동일한 수치 기준으로 검증한다.

최종 검증: 스모크 187개 및 구조 검사 통과. 브라우저 전체 480개 최초 실행은 416개 통과,
35개 기기 전용 건너뜀, 29개 실패였으며 실패한 경로를 수정해 재검증했다. 마지막 묶음은
27개 통과·1개 건너뜀. 추가한 본편 신규 젬 검사 2개도 PC/모바일 통과했다.
