# 스킬 아트 v3.38 인수인계

기존 공격 스킬 43종과 신규 10종의 아이콘·원본 모션을 실제 게임에 연결했다. 소환 젬 8종은 이번
압축에 아이콘이 없어 기존 것을 유지한다. 신규 10종도 일반 획득 풀·장착·전투·저장에 포함한다.
현재 구현·검증 경계는 [본편 통합 기록](production-integration-20260912.md)을 따른다.
이 문서의 아래 작업 기록은 체험장에서 합의한 모션 변경의 이력이다.

체험장: `/artifacts/new-skill-gems/index.html`. 상단에서 10종을 골라 장착하거나 실제 게임의 젬 창에서
변경할 수 있다. 인과는 후속 사용자 요청에 따라 주 공격 슬롯의 **집중 유지** 젬으로 변경했다.
집중 중 유효한 피격 5회마다 폭발하며 기존 집중 이동 제한을 사용한다. 이동·군중 제어·장착 변경·
사망·전투 중단 시 집중과 누적을 초기화한다. 별도 장착 슬롯은 없다. 원본 자료의 반응형 분류와
동시 공격 허용 규칙은 이 체험에서는 사용자 지시로 대체하며 원문 파일은 보존한다.
`node scripts/build-new-skill-lab.cjs`로 생성한다. 원본을 `artifacts/imports/pixellab-v3.38/`에 먼저
풀어 놓아야 한다. `node scripts/test-new-skill-lab.cjs`는 `?reference=1`의 PC/모바일 원본 체험 모션을 검사한다.
기본 체험장은 본편 전투를 실행하며 `node scripts/test-production-gems.cjs`로 별도 검사한다.
호스트 소스는 `scripts/skill-gem-lab/`이며 정식 게임에는 로드되지 않는다.

시험 수치는 [1차 젬 밸런스](balance-v1.md)를 따른다. 일반 젬의 별도 재사용 제한을 제거하고
젬별 피해·공격 속도 성장으로 바꿨다. 시간 가속은 5초 장판 하나만 유지하며,
인과는 집중 중 5회 피격마다 폭발한다. 이 수치는 최종 밸런스가 아니다.
일반 타격은 기존 피해 계산·방어·보호막·흡수 경로를 사용하고, 시간 가속은 회당 주문 기반 피해를
기존 지속 피해 배율·적 저항·적 자원 차감으로 처리한다. 지속 피해에 치명타·흡수·적중 상태 이상은 적용하지 않는다.
원본 컨트롤러의 시점·거리·궤적은 보존한다. 전체 지원 젬/키스톤 상호작용, 방치 정산,
밸런스·진행 해금은 이 체험으로 검증 완료한 것이 아니다.

실제 전투 추가 시 확인할 사항: 공격/주문/반응형 분류, 원본의 거리 정의, 취소와 사망, 이동 대상,
추가 투사체 확률, 상태 이상 중첩, 방치 재생, 저장·드랍·해금. 원본 콜백은 HP를 감소시키는 함수가
아니므로 현재 게임의 단일 피해 경로에 연결해야 한다. 시각 타이머가 별도 피해를 만들면 안 된다.

### 체험 화면의 모션 시간 보정 (2026-09-12)

`scripts/skill-gem-lab/drawing.js`는 100ms 전투 틱 사이의 이동·회전을 화면 시간으로
최대 100ms까지 보간한다. 탄성 플라스크는 실제 착지 확인 전까지 병을 남기고, 착지와
피해 콜백은 원본 컨트롤러가 계속 담당한다. 일시정지에는 화면 시간도 정지한다.
원화·공격 속도·피해량·타격 수·저장 구조는 변경하지 않았다. 신규 젬 체험 화면에만 적용된다.

동일한 브라우저 재생 2초 동안 기존 틱 시각의 포즈 변경 21회, 보정 시각은 91회였다
(rAF 95회, 개발 환경 측정이며 모든 기기에서 해당 프레임률을 보장하는 값은 아니다).
`node scripts/test-new-skill-lab.cjs`에서 PC·모바일의 틱 사이 7개 포즈, 정지, 착지 대기,
추가 피해 없음, 취소·시계 재시작을 검증한다. 타겟 제한 수치는 이번에 변경하지 않았다.

### 큰 적 조준 위치 (2026-09-12)

대상 지정 투사체와 직접 피격 이펙트는 기존 `getGridUnitCenter`로 2×2 적의 중앙을 사용한다.
실제 게임의 연쇄 출발점도 중앙을 사용하며, 관통 직선·부메랑 경로·장판 점유 칸은 보존한다.
신규 젬 체험에서는 원본 컨트롤러의 정수 좌표·타격 시점을 유지하고, 대상 지정 이펙트 이벤트만
중앙 좌표로 바꾼다. 탄성 플라스크가 2×2 적에게 총 4회 타격하며 점유 칸별 중복 피해가 없음을
PC·모바일에서 확인했다. 상단의 ‘일반 적 / 2×2 보스’ 선택으로 비교할 수 있다.

### 신규 젬 위치 연결 수정 (2026-09-12)

체험 전용 `targeting.js`는 `runtime.js` 이후, `combat.js` 이전에 로드한다.
암살은 현재 플레이어 방향으로 적이 돌아보는 전투를 기준으로 매 시전 후방을 재평가하고,
2×2 점유 영역 바깥에 착지한다. 원본 1칸 전용 `behind` 계산에 한정해 빌더가 호스트 목적지
콜백을 연결한다. 원본 압축·규격·참조 파일은 수정하지 않는다. 착지 직전에도 전체 점유 칸을
검사하여 뒤쪽이 막히면 이동과 피해를 취소한다.

파문심판의 자동 교전은 실제 전방 2칸 십자 범위를 사용한다. 대각선에서 타격할 수 없으면
기존 이동 주기로 정렬한 뒤 공격한다. 과냉각 혼합물은 적 너머를 우선해 첫 고리에 적을 넣고,
보드 가장자리에서는 사거리 안 대체 지점을 고른다. 발밑과 대상 점유 칸에는 투척하지 않는다.
십자·냉기 고리는 보스의 모든 점유 칸을 고려하되 한 타격 단계당 같은 적을 중복 타격하지 않는다.
계수와 원본 포즈·시전 시간은 유지한다. 보스가 여러 고리에 걸치면 각 고리에서 적중할 수 있다.

`scripts/lib/new-skill-position-checks.cjs`에서 4방향 후방·연속 암살·착지 직전 장애물,
대각선 교전·가장자리 투척·2×2 보스·실제 `coreLoop` 12초의 반복 타격을 PC·모바일에서 검사한다.

### 순간이동·플라스크 속도·향로 수정 (2026-09-12, 후속 요청)

- 암살 착지는 `playerMobility.instant` 이벤트를 보내며, 공통 캐릭터 렌더러는 해당 이동에
  걷기 보간을 적용하지 않는다. 일반 이동 보간은 유지한다.
- 신규 플라스크 4종과 빈 플라스크 파편은 비행 시간만 1/1.8로 단축한다. 빌더가 원본의
  `flightMs`/`shardMs` 반환식을 AST로 변환하므로 이펙트 착지와 실제 타격 시점이 함께 당겨진다.
  공격 주기, 폭발·냉기 고리 간격은 유지한다. 기존 게임의 원소 포션 투척에도 같은 비행 배율을 적용한다.
- 사용자 선택에 따라 **앞 절의 과냉각 지면 조준 규칙을 대체**한다. 적 중앙으로 직접 투척하며
  2×2 중심의 반칸 좌표도 허용한다. 착지 시 중심 피해를 첫 고리와 한 묶음으로 처리해
  같은 적의 중복 피해를 막는다. 이후 고리는 중심에 반복 피해를 주지 않는다.
- 신성한 안개는 체험용 아틀라스 설정의 추가 사슬을 40→8px, 4→1개로 줄인다.
  작은 안개 스프라이트 1개가 향로 끝을 따라가고 기존 지면 안개·인접 8칸 판정은 유지한다.
  향로 재생 시 스프라이트 수는 기존 5개에서 3개다. 원본 이미지 파일은 수정하지 않는다.

`new-skill-motion-checks.cjs`와 기존 위치·브라우저 검사에 비행 시간, 폭발·고리 간격 보존,
향로 끝의 안개 위치, 실제 암살 착지 첫 프레임, 일반 적 착지 1회 타격 검사를 추가했다.

### 암살 사라짐·후방 타격 연결 (2026-09-12)

- 앞 절의 매 시전 방향 재계산을 대체한다. 적 방향은 실제 `enemyAttack` 때 플레이어를 향해
  갱신하며, 암살 자체가 적을 돌려세우지 않는다. 이미 뒤라면 같은 자리에서 재등장·타격한다.
  체험 화면의 적 스프라이트도 이 방향을 사용한다. 뒤가 막히면 기존처럼 시전이 실패한다.
- 체험용 빌더에서 암살 동작만 출발 후 100ms에 순간이동, 240ms에 타격, 후속 베기 120ms로
  줄였다. 재사용 간격·피해 계수·상태 이상 확률은 유지한다. 원본 압축과 참조 파일은 보존한다.
- `assassination.js`는 `drawing.js` 뒤에 로드되는 체험 전용 표현 어댑터다. 원본 `actorPose`를
  재사용해 100ms 사라짐·70ms 재등장을 캐릭터와 그림자에 적용하고, 출발지 잔상은 최대
  80ms 동안 한 번 더 그린다. 도착 후 걷기 대신 작은 상체 기울임을 사용한다.
- 피해는 기존 컨트롤러가 한 번만 확정한다. 렌더링은 피해를 생성하지 않으며, 시전 실패·취소·
  스킬 변경·사망 시 투명 상태를 남기지 않는다. 저장 형식·본편 로드 순서는 변경하지 않는다.
- `test-new-skill-lab.cjs`: PC·모바일에서 연속 후방 공격, 실제 적 방향 전환, 착지 장애물,
  사라짐/재등장과 실제 캔버스 알파, 접촉 피해 1회·취소 복구를 검사한다.

후속 요청: 별도 단검 이미지(`dagger` 단계)는 체험 호스트의 이펙트 전달 단계에서 제외한다.
기존 접촉 잔상(`slash`)과 사라짐·재등장은 유지한다. 무기 그림을 새로 만들거나
타격 수·피해·순간이동 시점을 바꾸지 않는다. 단검 미출력과 기존 접촉 이펙트 출력을 검사한다.
