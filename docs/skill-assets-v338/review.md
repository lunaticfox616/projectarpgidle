# 누적 변경 리뷰 — 2026-09-12

이 문서는 신규 젬 본편 통합 이전의 리뷰 이력이다. 후속 반영과 현재 범위는
[본편 통합 기록](production-integration-20260912.md)을 따른다.

현재 개발본 `pr-repo`의 미반영 변경을 대상으로 검토했다. 제작·장비 옵션·착용 요구사항·저장 복원,
저널·드랍 연출·팝업, 지도·벌집·균열·운석, 적 시전 표시, v3.38 스킬 아트를 함께 확인했다.

별도 캐시 변경은 하지 않았고, 요구 능력치가 20 → 30 → 20으로 즉시 복원되는 행동을 검사한다.

## 유지한 계약

- 새 10종은 자료만 준비했다. 원문·아이콘·모션·참조 컨트롤러를 보존하고 게임 DB에는 넣지 않았다.
- 43종 원본 모션의 크롭, 회전, 반전, 원본 알파에 게임의 85% 투명도를 곱한다.
- 원본 갤러리의 보드 밖 시각 잘림은 적용하지 않는다. 게임 판정 범위는 변경하지 않는다.
- 투사체 접촉 시점은 확정된 전투 스케줄을 읽는다. 빗나감·연쇄·관통·시전 취소를 유지한다.
- 아틀라스는 lossless WebP 한 장(113,572바이트), 디코딩 RGBA 약 7.5MiB다.
  출력은 프레임당 48장, 잔여 시각 이벤트는 최대 128개다. 프레임마다 새 이미지/입자를 생성하지 않는다.
- 기존 저장의 옵션 수치/출처/벌꿀 고정/장착 유예를 보존한다. 계승 장비의 능력치 부족 시 비활성은 의도한 정책이다.
- 일반전에는 적 시전 바를 표시하지 않으며 특수 공격/보스 패턴은 이름 없이 둥근 게이지를 사용한다.

## 검증

- `npm test`: **186/186 통과**, 최종 9.7초.
- `npm run check:architecture`: 통과. 규칙·baseline 완화 없음.
- 원본 VM 렌더링과 **215개 이벤트, 1,935개 시점**의 위치·부분 크롭·스케일·알파·회전 일치.
- 실제 43종 전투 브리지와 투사체의 적중·취소·빈 대상·잔여 모션 종료 회귀 검사 통과.
- PC/모바일 관련 브라우저 **42개 고유 검사 통과**: story-fx 14, 요구사항 2, 지면 드랍 4,
  팝업 6, core-ui의 제작·저널·지도·특수 전투 16. 실패한 옛 저널 검사는 수정 후 재실행했다.
- 실제 브라우저에서 연속 베기 전투, 저널 읽기, 신규 아트 미리보기 화면 확인.
- `node scripts/audit-level-progression.js`: 고정 난수로 액트를 각 한 번 순회한 합성 계산에서
  루프 1/10/50의 액트 10 종료 레벨은 19/23/30, 혼돈 1 종료는 29/33/39. 일반 드랍 배율 100%.
  장비 XP 보너스·사망·소요 시간은 포함하지 않는다.
- 공개 배포/PR 생성은 이번 작업에서 수행하지 않았다.

휴대폰 실기 발열·장시간 파밍 밸런스·새 스킬의 재미는 위 검사로 검증됐다고 볼 수 없다.
이식의 실제 소비/전투 기능과 고유 융합 정책 변경도 이번 아트 준비에 추가하지 않았다.
기존 융합은 고유 전체 복제 후 희귀 옵션 추가 방식이므로, 고유 옵션만 이전하려는 의도와의 차이는
`docs/equipment-crafting-direction-20260910.md`의 후속 설계 항목으로 남아 있다.
