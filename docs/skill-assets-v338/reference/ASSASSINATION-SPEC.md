# 암살 — 후방 순간이동과 단검 베기 v3.32.0

## 확정 요청과 기본안

사용자는 ‘암살’이라는 새 스킬을 요청했다. 적의 뒤로 순간이동하고 단검으로 물리 피해를 주며 중독 또는 출혈 확률을 부여한다. 기존 4번 ‘암살자의 일격’과 40번 ‘그림자 점멸’은 변경하지 않는다. 전체 60번째 젬·이펙트 52번으로 추가한다.

| 항목 | 적용 내용 | 상태 |
|---|---|---|
| 이름 | 암살 | 사용자 요청 |
| 분류·피해 | 단검을 사용하는 물리 공격 | 사용자 요청 |
| 이동 | 적이 바라보는 방향의 반대쪽 인접 1칸 | 사용자 요청의 구현 |

질문에 대한 선택이 없는 상태에서는 ‘무작위 하나’ 방식이 기본안이다. API는 각각 독립 판정 및 지정 상태 하나 판정도 지원하고, 미리보기에서 기본안과 비교할 수 있다. 30%는 선택된 상태가 적용될 확률이므로 기본안에서 중독 15%·출혈 15%·미발동 70%다. ‘중독’ 때문에 단검의 직접 피해 속성을 카오스로 변경하지 않는다.

## 이동과 적중

1. 선택한 생존 적과 사거리·뒤쪽 착지 칸을 검사한다. 적 방향은 MZ의 2/4/6/8을 사용한다. 방향 정보가 없으면 적이 현재 시전자를 바라보는 방향을 4방향으로 추정한다. 실제 게임에서는 `getTargetFacing` 연결을 권장한다.
2. 기본 시전 후 200ms에 다시 적 위치·방향·현재 플레이어 위치·점유를 검사한다. `onTeleport`는 호스트에서 칸을 원자적으로 확인하고 플레이어를 이동시킨 뒤 정확히 `true`를 반환해야 한다.
3. 340ms에 대상이 착지 때의 칸에 있고 플레이어도 착지 칸에 있으면 해당 적에게 물리 공격 1회를 전달한다. 대상 사망·이동, 플레이어 이동, 거부된 순간이동에는 피해를 전달하지 않는다.
4. 호스트의 적중 처리 후 살아 있는 적에게 확률 판정을 수행하고 성공 시 `onAilment`를 호출한다. 호스트가 적중이나 상태 적용을 `false`로 거절하면 후속 상태 확인 연출을 생략한다.

시각 속도 배율은 0.5~2.5 범위의 제안값이다. 순간이동·베기 시간이 함께 변한다. 시전 중단은 이동 전이면 원래 자리를 유지하고 이동 후이면 뒤쪽 착지 위치를 유지한다. 이미 적용된 피해나 상태 이상을 되돌리지 않는다. 재호출·시간 역행·시각 출력 예외로 동일 타격이 중복되지 않는다.

## 픽셀 연출 [제안]

은회색 단검 핵을 목질 씨껍질이 비대칭으로 감싼 네이티브 32px 젬이다. 효과는 작은 회색 소멸 연기 → 뒤쪽 출현 → 실제 단검의 짧은 스윙 → 대상 몸체의 은색 칼선이다. 중독은 녹색 방울, 출혈은 붉은 방울로 구분한다. 표식의 700ms 표시는 성공 확인 연출이며 실제 상태 지속시간이나 지속 피해를 의미하지 않는다.

PixelLab 32px 연기·단검·칼선과 16px 표식을 64px 슬롯 1개에 배치했다. 14색 공통 팔레트, 디더링 없음, 원본 이진 알파 복구, 정수 위치와 최근접 샘플링을 사용한다. 화면 전체 섬광·색 반전·반복 점멸·대형 파티클을 추가하지 않는다. 젬과 최종 조형은 제안이다.

## 런타임 연결

`WT_ASSASSINATION` 또는 `WorldTreePixelLabFX.assassination`을 사용한다. `createCast`에 `source`, `targetId`, `getEnemies`, `onTeleport`, `onHit`가 필요하다. `getSourceCell`, `getTargetFacing`, `isWalkable`, `getOccupiedCells`, `onAilment`, `emit`은 호스트 기능과 연결한다. `update(now)`에 단조 증가하는 전투 시간을 전달하며, `cancel(now)`로 중단한다. `emit`에는 `layer.fx.emit`을 연결한다.

`onHit`는 `category: attack`, `element: phys`, `weapon: dagger`, `damage: null`, 단일 `targetId`를 전달한다. 피해량은 호스트가 채운다. `onAilment`에는 `type: poison|bleed`, 성공 시각과 대상 ID를 전달한다. 실제 게임의 중독·출혈 저항·면역·중첩·지속 피해 규칙은 호스트에서 처리해야 한다. 맵 이벤트와 전투 데이터베이스를 자동으로 바꾸는 연결은 포함하지 않는다.

## 검수·성능

13개 이동·타격·확률·취소 검증 그룹, 방향별 Canvas 재생, 실제 MZ 타이밍과 이동, 미리보기 조작을 검수한다. 기존 51종의 전체 시퀀스 102개·Canvas 표본 204개·MZ 표본 102개와 기존 아틀라스 465슬롯을 보존했다. 기존 59개 젬을 포함한 이전 이미지 110파일을 해시로 비교했다.

전체 이펙트 52종·466슬롯, Canvas 아틀라스 1024×1920·7.5MiB를 유지한다. MZ는 1024×1856 기본 텍스처와 128×64 확장 텍스처, 합계 7,634,944바이트를 사용한다. 확장 폭을 64px에서 128px로 늘려 기존 51번의 픽셀 샘플링을 보존했다. 증가량 16KiB, 텍스처 수 2개·48Sprite 풀·128시각 이벤트 상한 유지. 기본 암살 장면 최대 4Sprite, 독립 상태 판정에서는 최대 5Sprite다. 전체 게임의 실제 기기 부하는 별도 검증 항목이다.
