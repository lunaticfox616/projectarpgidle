# 폭발 혼합물 — 포션 투사체 투척 스킬 v3.20

## 요청과 적용 기본안

사용자는 **폭발 혼합물이 든 포션을 던지는 투사체 투척 스킬**을 요청했다. 기존 원소 포션 투척(38번, 원소 웅덩이 3틱)과 탄성 플라스크(44번, 4회 튕김)를 보존하고 새 스킬을 추가한다.

- `[최신 사용자 요청]` 폭발 혼합물 포션을 투사체로 던지는 스킬 제작.
- `[WORKING: 적용 기본안]` 이름 **폭발 혼합물**, 공격 젬·화염 피해·최대 4칸 투척·착지 칸과 인접 8칸의 3×3 범위·포션 1병·착지 시 한 번의 범위 타격. 선택 질문 후 진행 기본안으로 안내한 값이며, 명시적인 사용자 확정으로 기록하지 않는다.
- `[WORKING: 제작 번호]` 전체 젬 55번째, 이펙트 카탈로그 47번. RPG Maker MZ 전투 데이터베이스 ID와 구분한다.
- `[제안: 조형]` 적주황 핵을 목질 씨방이 감싼 32px 씨앗, 코르크로 봉한 짧은 유리 포션, 밝은 점화 섬광과 굵은 화염 덩어리의 폭발. 새 물질의 제조법·세계관 능력·클래스 전용 설정은 추가하지 않는다.
- `[OPEN]` 피해량·계수·쿨다운·소모량·젬 성장·실제 전투 DB 연결, 기본안의 최종 선택과 조형 채택.

## 동작과 판정

| 항목 | 적용 기본안 |
|---|---|
| 분류 | 공격 / 투사체 / 범위 |
| 속성 | 화염 |
| 시전 거리 | 시전자 칸 중심에서 유클리드 거리 4칸 이내 |
| 사거리 밖 조준 | 사거리 안의 가장 가까운 유효 칸으로 제한 |
| 착지 지점 | 시전 시작 때 지정한 칸에 고정 |
| 비행 | 포션 1개가 시전자에서 착지 칸으로 포물선 이동 |
| 폭발 범위 | 착지 칸과 인접 8칸, 보드 밖 칸은 제외 |
| 피해 | 착지 시 한 번, 범위 안 살아 있는 모든 적 |
| 잔향 | 폭발 뒤 잔불 소멸, 추가 피해와 지속 장판 없음 |

착지 때 현재 적 목록을 검사한다. 죽은 적·범위 밖으로 이동한 적은 제외하고, 새로 들어온 적은 포함한다. 같은 ID의 중복 입력은 한 번으로 정리한다. 포션은 이동하는 적을 자동 추적하지 않으며, 시전 후 시전자가 움직여도 이미 던진 포션의 시작점과 착지점은 바뀌지 않는다.

`WT_EXPLOSIVE_MIXTURE.createCast()`의 `onImpact`는 대상 전체를 한 번에 전달하는 전투 연결 콜백이다. 피해 계산은 수행하지 않으며 `damage:null`을 유지한다. 시각 이벤트는 비행과 폭발 두 개로 묶고, 출력 제한이 실제 피해 대상 수를 줄이지 않게 한다. 취소 시 컨트롤러와 해당 렌더링 채널을 함께 취소한다. 착지 전에 취소하면 피해 콜백이 없고, 착지 뒤 다시 갱신해도 피해가 반복되지 않는다.

## 픽셀 아트와 자원

PixelLab으로 네이티브 32px 포션과 씨앗, 64px 폭발 성분을 생성한다. 포션은 원본 배율, 폭발은 정수 2배 배율로 표시한다. 회전 각도와 화면 좌표를 양자화하고 최근접 샘플링을 유지한다. 생성 프롬프트·원본·미채택 후보·팔레트·측정 기록은 번들 `pixellab/explosive-mixture-v320/`에 보존한다.

씨앗은 최종 13색·이진 알파·2px 이상 여백·1,070바이트다. 기존 54개 씨앗과 46개 번들 아이콘은 해시로 보존한다. 포션 원화 job은 `64fb756f-241a-49ff-b0ba-37fc575bb9b7`, 점화 섬광은 Pro `5bf2b85e-f2c1-4646-bac8-81e2f05de581` 후보 14다. 최초 폭발 애니메이션 `343dea5c-6708-4005-92c1-1cf321e26995`는 독립 육안 검토에서 꽃잎 같은 대칭 분리가 지적되어 미채택 이력으로 보존했다. 수정 원화 `1c066b11-05aa-41e5-9a4e-c1ee2ecd57bf`와 애니메이션 `9a92db48-ed8b-4191-9281-7dd9e537d280`의 불규칙 화염 분해를 사용한다. 실제 선택 순서와 공통 감색 job은 `selected-sources.json` 및 `records.json`에서 확인한다.

포션 1슬롯과 폭발 9슬롯을 기존 444슬롯 뒤에 추가한다. 아틀라스는 **454슬롯·1024×1856·7.25MiB·텍스처 1개**, 증가량은 **0.25MiB**다. Sprite 풀 48개·시각 이벤트 상한 128개를 유지한다. 프레임마다 새 원화·파티클·무작위 경로를 생성하지 않는다. 젬은 `assets/gems/active/explosive-mixture-seed-32-v1.png`, 번들에서는 `icons/47.png`다.

미리보기는 `explosive-mixture.html` 및 `index.html?version=3.20&skill=47`, 전체 투명 모션은 `motions/47.webp`·`animations/47.webp`, 성분 시트는 `sheets/47.png`다. 주요 장면·전장 포함 모션·검사 결과는 `qa/explosive-mixture/`에 기록한다. 시연 속도는 연출 확인용이며 확정된 공격 속도·재사용 시간이 아니다.

## 검증과 재출력

`verify-explosive-mechanics.cjs`는 거리·범위·현재 적 목록·중복·취소·정확히 한 번인 피해 콜백·시각 제한과 대상 수 분리를 검사한다. `verify-explosive-mixture.cjs`는 기존 46종의 동작·444개 사용 슬롯·아이콘·과거 QA 보존과 신규 방향·착지·네이티브 MZ 출력·풀 제한을 확인한다. 구체 결과는 `qa/explosive-mixture/explosive-mixture-verification.json`을 따른다.

최종 기술 검사 통과: 기존 46종 메타데이터·444개 사용 슬롯·46개 아이콘·과거 파일 1,676개가 보존됐다. 전체 46개 시퀀스·Canvas 92표본·동일 텍스처 할당 높이 기준 MZ 92표본이 일치한다. 신규 메커닉스 42항목, 네 방향 36시점, 병과 폭발 정렬 각 16표본, 접촉 위치 16표본을 확인했다. 네이티브 MZ 65프레임에서 기본 시연 최대 6스프라이트를 관측했고, 부하 검사는 128이벤트·48스프라이트 한도를 유지했다. 이 6개는 모든 배치의 최대값이 아니며, 9개 타격 칸에는 중앙 폭발과 접촉 섬광을 합해 최대 10개를 사용한다. 실제 MZ 설치에서 기존 DB 25개를 보존했다.

독립 육안 검토는 정지 시퀀스와 원화·소멸 코드 확인 범위이며 `qa/explosive-mixture/visual-review.json`에 기록했다. 네 꽃잎처럼 보이던 초기안을 교체한 뒤 비행·착지·파열이 명확해졌음을 확인했다. 후반 다섯 잔불이 일부 정돈된 배열로 보이는 경미한 한계와 최종 사용자 채택 OPEN 상태를 남긴다. 마지막 24% 구간의 알파 감소로 잔불이 사라지며, 그 구간에 추가 피해는 없다. 전체 모션은 1.56초, 기본 착지는 600ms다.

재출력은 `prepare-explosive-mixture.cjs <팔레트 job>` → `build-atlas.cjs` → `build-preview.cjs` → `build-explosive-page.cjs` → `export-explosive-mixture.cjs`다. 검수·현재 MZ 설치 이후 `finalize-explosive-mixture.cjs --check` → `finalize-explosive-mixture.cjs` → `package-explosive-mixture.ps1`로 납품한다. 과거 버전의 QA와 최종화 도구는 해당 버전의 이력으로 보존한다.

## 정사 기준·충돌·미확정

참조 파일은 `docs/world/00_CANON_INDEX.md`, `01_WORLD_PREMISE.md`, `02_PLAYER_AND_TIME_LOOP.md`, `05_PLAYER_CLASSES.md`, `06_VISUAL_REFERENCE_MANIFEST.md`이며, 관련 규격은 `docs/items/01_SKILL_GEM_ART_SPEC.md`, `02_SKILL_PIXEL_EFFECT_SPEC.md`, `03_BOUNCING_FLASK_SKILL_SPEC.md`다. 큰 형태·정돈된 픽셀·48px 논리 셀·목질 씨앗 방향을 따른다.

새 정사 충돌과 LOCKED 세계관 변경은 없다. 화염색을 황금빛 수액의 서사 의미와 동일시하지 않는다. 기본안의 분류·속성·거리·범위와 최종 조형 채택, 전투 수치·실전 연결·기기별 전체 게임 성능은 `[OPEN]`이다.
