## 동작과 판정

포션 한 병이 시전자에서 지정한 칸으로 포물선을 그리며 날아간다. 시작점과 착지점은 시전 시 고정하며, 이동하는 적을 자동 추적하지 않는다. 착지 뒤 서리 고리가 1칸, 2칸, 3칸 순서로 넓어지고 사라진다. 고리의 중앙은 비우며 별도의 중앙 폭발·지속 장판·감속 효과를 추가하지 않는다.

| 항목 | 적용 기본안 |
|---|---|
| 분류 / 속성 | 공격 · 투사체 · 범위 / 냉기 |
| 투척 거리 | 시전자 칸 중심 기준 유클리드 4칸 |
| 사거리 밖 조준 | 보드 안, 사거리 안의 가장 가까운 유효 칸 |
| 1차 고리 | 착지점과 거리 0.5칸 초과, 1.5칸 이하 |
| 2차 고리 | 거리 1.5칸 초과, 2.5칸 이하 |
| 3차 고리 | 거리 2.5칸 초과, 3.5칸 이하 |
| 타격 | 각 시점의 새 고리 안 살아 있는 모든 적, 각 고리 1회 |
| 중앙 / 지난 영역 | 해당 단계에서 타격하지 않음 |
| 비행 시간 | 기본안 420ms + 이동 거리 × 50ms |
| 고리 간격 | 기본안 260ms, 세 번째 이후 340ms 잔향 |

논리 칸은 48px다. 범위는 **칸 중심**으로 계산하고, 보드 밖 칸은 제외한다. 고리 세 개의 판정은 서로 겹치지 않아 정지한 적은 한 번만 맞는다. 같은 적이 다음 바깥 고리로 이동하면 다음 타격도 받을 수 있다. 각 타격 시점에 살아 있는 적을 다시 조회하며, 사망·잘못된 좌표·중복 ID를 제외한다. 얼음 결정 실루엣의 들쭉날쭉한 외곽은 장식이고 정확한 판정은 위 칸 중심 규칙을 따른다.

`WT_SUPERCOOLED_MIXTURE.createCast({source, aim, getEnemies, emit, onRing, onCancel, startAt, speed, channelId})`를 제공한다. `onRing`은 0부터 시작하는 index, ringNumber 1~3, 예정 시각 at, 반경, targets, targetIds, 타격 칸 cells를 일괄 전달한다. damage는 null이며 실제 피해량 계산은 호스트가 맡는다. 이 API 자체가 MZ DB에 스킬을 등록하거나 HP를 깎지는 않는다.

`update(now)`는 최대 세 개의 예정 시점을 처리한다. 지연 시 `getEnemies(at)`가 각 예정 시각의 스냅샷을 제공해야 하며 과거 위치를 임의로 복원하지 않는다. 렌더링 실패·Sprite 한도는 피해 대상 수를 줄이지 않는다. 재진입과 중복 update는 이미 처리한 고리를 반복하지 않는다. `cancel()`은 이후 판정과 시각 이벤트를 함께 중단한다. 실제 게임 연결 시 시전별 고유 channelId를 사용하고, 레이어의 `fx.cancel(channelId, at)`를 onCancel에 연결한다.

## 참고와 픽셀 연출

디아블로 2 서릿발의 **바깥으로 퍼지는 냉기 고리**를 동작 참고로 삼았다. 공식 설명: [Blizzard — Sorceress Cold Spells, Frost Nova](https://classic.battle.net/diablo2exp/skills/sorceress-cold.shtml). 원작 이미지를 복제하지 않고 PixelLab에서 새 도트를 만들었다. 포션과 세 단계 판정은 이번 사용자 요청을 따른다.

처음에는 돌 테두리처럼 보이는 후보를 검수 후 제외했다. 최종 고리는 바깥을 향한 날카로운 얼음 결로 구성한다. 한 고리가 단계마다 짧게 머무른 뒤 확장해 3단계를 구분하며, 여러 밝은 고리를 겹쳐 점멸시키지 않는다. 최대 불투명도 0.82, 한 번의 도입과 소멸, 화면 흔들림 없음. 몬스터 아래 바닥 레이어에 배치한다. 미리보기는 처음 정지하며 사용자가 한 번씩 재생한다.

32px 젬 10색, 32px 포션 8색, 128px 서리 원화 4색이다. PixelLab 팔레트 변환 뒤 원본 투명도를 복원하고 이진 알파를 사용한다. 축소 원화를 다시 그리지 않는다. 포션은 정수 패딩, 고리는 네 개의 64px 타일로 무손실 분할한다. 최근접 샘플링과 1/32 단위 배율을 사용하여 타일 접합부와 좌표가 정수 픽셀에 놓이게 한다. 고리 확대 과정에서 도트 크기가 단계적으로 변하는 것은 현재 연출의 특성이다.

원본과 미채택 후보, 최종 job, 팔레트, 처리 기록은 `pixellab/supercooled-mixture-v327/records.json` 및 같은 폴더에 보존한다. 새 원화는 프레임마다 생성하지 않는다.
