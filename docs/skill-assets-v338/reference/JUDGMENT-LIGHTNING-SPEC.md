# 파문심판 — 은색 향로와 십자 낙뢰 v3.37

## 사용자 요청과 적용

- [최신 사용자 요청] 파문심판의 향로도 은색으로 변경하고 번개 피해를 주는 형태는 낙뢰가 떨어지는 모습으로 바란다.
- [적용] 이펙트 51번·젬 59번의 향로와 사슬은 은색이다. 전방 2칸을 내려찍은 지점과 상하좌우 네 칸에 위에서 아래로 낙뢰가 내려온다.
- 기존 **공격·번개·전방 2칸·상하좌우 4방향·십자 5칸·적마다 1회 타격** 기본안을 보존한다. 대각선 적을 추가로 타격하지 않는다. 전체 젬 60개·이펙트 52종이다.
- 문서 25의 청동 향로와 바닥을 따라 뻗는 가로·세로 전류 조형은 이 요청으로 대체한다. 신규 속성·상태 이상·종교·클래스 설정을 추가하지 않는다.

## 움직임과 판정

향로를 들어 올려 앞으로 넘긴 다음 마지막 구간에서 착지점 바로 위에서 수직으로 내려찍는 기존 동작을 유지한다. 향로와 손의 사슬 연결, 마지막 바닥 끝의 착지점, 상단 가장자리 높이 보정도 그대로다.

기본 속도에서 착지 120ms 전인 **360ms부터** 낙뢰 원화의 위쪽을 드러내고 아래로 진행시킨다. **480ms**에 향로가 닿을 때 다섯 낙뢰의 끝점도 각 십자 칸의 중심에 닿는다. 그 시각에 기존 공격 배치를 1회 처리한다. 사전 낙뢰 진행은 시각 효과이며 사전 피해나 추가 피해가 아니다.

착지 이후 기존 420ms 동안 번개 줄기가 잔광으로 남았다가 부드럽게 사라진다. 최대 알파 0.78, 말기 72% 구간에서 점차 감소한다. 바닥에는 기존 중앙 전류 원화를 각 착지 칸에 최대 알파 0.45로 재사용한다. 번개를 여러 번 켰다 끄지 않으며 화면 전체 섬광·가산 합성·흔들림을 추가하지 않는다.

낙뢰의 격자 배치는 착지점 중심 십자이며, 줄기 자체의 진행 방향은 모든 칸에서 수직 아래다. 상단 가장자리는 보드 경계에서 자연스럽게 잘리며 시전자나 다른 방향으로 비틀어 떨어뜨리지 않는다. 전방 2칸이 보드 밖이면 시전하지 않고 십자 팔만 보드 밖인 경우 해당 팔을 제외한다.

속도는 기존 0.5~2.5배를 지원한다. 낙뢰 도달 시점도 향로의 속도에 맞추되 기존 적중 시각 공식 `round(480/speed)`를 유지한다. 시전 취소는 사슬·향로·사전 낙뢰·잔광을 함께 종료하고, 이미 처리한 피해를 되돌리지 않는다. API의 비교용 `crossRadius:2`에서도 각 유효 칸에 낙뢰를 배치한다. 기본 반경은 1이다.

## PixelLab 원화

은색 금속은 기존 향로·사슬 배치를 편집한 64×32px 원본, 실제 사용색 7색이다. 향로와 사슬의 기본 크기·배치·연결점을 유지하며 원본 정수 배율 1배로 사용한다.

낙뢰는 투명 32×32px 원본의 가느다란 불규칙 줄기와 짧은 가지다. 실제 사용색 3색, 불투명 픽셀 112개, 경계 x9~21/y1~30. 3배 정수 배율로 사용한다. 첫 생성본은 지나치게 굵고 주황색이 강해 채택하지 않고 더 가늘고 옅은 금색으로 편집했다. 회색·금색 색면과 명확한 실루엣을 우선하며 미세 점·그물망·무의미한 입자 반복을 피한다.

- 은색 편집: `e1068aaa-012d-49b3-84be-51d4d1f772e0`; 팔레트: `6dcc5569-87fc-4e7c-b71b-466c2142bc41`.
- 낙뢰 편집: `8c24dc58-e40d-4539-9ca9-7b229b03ee1c`; 팔레트: `13ee80fb-6790-4df4-a0c9-cd64bb3228e4`.
- 생성·편집 원본과 기록: `pixellab/judgment-lightning-v337/`.
- 기존 64×64px 슬롯의 위쪽 64×32 금속과 아래 왼쪽 32px 번개 영역을 교체한다. 아래 오른쪽의 바닥 전류와 젬은 보존한다. 전체 466슬롯·다른 465슬롯은 유지한다.

## 성능과 검수

MZ는 기존 1024×1856 Base와 128×64 Extra 텍스처 두 개를 사용한다. Base 전체와 Extra의 52번 영역은 보존하고 Extra의 51번 영역만 변경한다. RGBA 7,634,944바이트로 **추가 텍스처 메모리 0바이트**다. 미리 할당한 48개 Sprite 풀과 128개 이벤트 제한을 유지한다. 사전 낙뢰에 사용할 셀과 잘라내기 정보는 이벤트 시작 때 준비해 프레임마다 새 이미지·난수를 만들지 않는다.

기본 십자 5칸의 4방향·보드 위치·속도 검수 최대는 15Sprite이며 비교용 반경 2에서는 최대 23Sprite다. MZ 검수 시나리오 최대는 22Sprite다. 이는 해당 검수 장면의 측정이며 전체 게임이나 저사양 장치의 프레임 성능을 보장하는 값은 아니다.

- 9개 위치×4방향×3속도×2반경: 유효 시전 144조건·무효 시전 72조건.
- 낙뢰 4,275개 시점 검사: 위→아래 진행, 고정된 시작점, 정확한 480ms 기준 도달, 십자 범위, 취소·종료 처리 통과.
- 전체 104개 피해 시퀀스 동일. 다른 51종의 Canvas 204개·MZ 102개 장면 동일. 이전 신성한 안개 은색 향로도 유지한다.
- MZ 1.10.0 / PIXI 5.3.12: 공유 텍스처·정수 좌표·풀 재사용·스트레스 제한·정리 통과.
- 전용 페이지 13개 검사와 6개 모션 시점, 네이티브 MZ 화면을 확인했다. 전체 내보내기 1,080ms.
- 검수 기록 `qa/judgment-lightning/`; 미리보기 `ripple-judgment.html?version=3.37`.
