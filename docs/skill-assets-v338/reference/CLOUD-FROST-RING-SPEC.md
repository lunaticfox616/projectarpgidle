# 과냉각 혼합물 — 냉기 구름 고리 v3.34

## 최신 사용자 요청

서리 고리를 자연스럽고 구름 같은 형태로 바꾼다. 앞선 옅은 고리 방향과 3단 확장을 유지하며, 단단한 얼음 테두리를 냉기 구름의 실루엣으로 대체한다. 새 게임플레이 규칙은 추가하지 않는다.

## 시각 제안

크기가 다른 둥근 구름 덩어리가 겹쳐 이어지는 고리다. 중앙은 투명하고 가장자리는 불규칙한 둥근 굴곡과 옅은 냉기로 마무리한다. 작은 점무늬와 반복되는 벽돌 조각 대신 넓고 정돈된 도트 색면을 사용한다. 최대 불투명도는 0.52이며 몬스터 아래 바닥 레이어에서 한 번 나타나 확장하고 사라진다. 화면 흔들림·반복 섬광·새 입자를 추가하지 않는다.

투척 포션·젬·비행 모션·3단 범위·타격 시점·취소 동작은 기존 22번 규격을 유지한다. 고리의 구름 굴곡은 장식이며 피해 판정은 칸 중심 거리로 계산한다. 기존 전투 모듈은 수정하지 않는다.

## 원화와 자원

PixelLab Pro로 128px 원화를 편집하고 최대 4색으로 정리했다. 투명 배경을 제외한 최종 도트는 청회색 3색이다. 원화의 투명도를 복원하여 이진 알파로 보존하고, 네 개의 64px 타일로 무손실 분할한다. 중앙의 투명 반경은 최소 약 22.9px, 바깥 실루엣은 최대 약 55.1px다. 생성 작업 ID·프롬프트·미채택 후보·후처리는 `pixellab/cloud-frost-v334/records.json`과 같은 폴더에 기록한다. 프레임마다 이미지를 생성하거나 입자를 할당하지 않는다.

기존 고리 4슬롯을 재사용한다. Canvas 아틀라스는 466슬롯·1024×1920, MZ는 1024×1856 기본 텍스처와 128×64 확장 텍스처를 유지한다. MZ RGBA 7,634,944바이트·추가 메모리 0바이트·텍스처 2개·48Sprite 풀이다. 고리는 최대 4Sprite, 시각 이벤트는 비행과 확장 2개다. 전체 젬 60개·이펙트 52종을 유지한다.

## 검수와 결과물

`qa/cloud-frost/`에 원화 비교·전체 모션·6장 주요 장면·실제 MZ/PIXI 화면·1회 재생 UI 검수를 저장한다. 게임플레이 소스와 104개 시퀀스, 다른 51종의 Canvas 204표본·MZ 102표본, 요청 외 아틀라스 픽셀을 비교한다. Canvas 비교에는 읽기용 소프트웨어 컨텍스트를 사용하여 GPU의 회전 가장자리 샘플링 편차를 배제한다.

- 미리보기: `supercooled-mixture.html?version=3.34`.
- 원화: `pixellab/cloud-frost-v334/ring-ready.png`.
- 납품: `sheets/48.png`, `motions/48.webp`, `animations/48.webp`.
- 수정 전후: `qa/cloud-frost/48-before.webp`, `48-after.webp`.
- 재출력: `prepare-cloud-frost.cjs <원화 job> <팔레트 job>` → `build-atlas.cjs` → `build-preview.cjs` → `export-cloud-frost.cjs`.
- 검수: `verify-cloud-frost.cjs`, `verify-cloud-frost-page.cjs`. 설치 후 `finalize-cloud-frost.cjs`, `package-cloud-frost.ps1`.

## 정사 기준·충돌·미확정

`docs/world/00_CANON_INDEX.md`, `01_WORLD_PREMISE.md`, `06_VISUAL_REFERENCE_MANIFEST.md`와 아이템 규격 00·02·22·28을 참조한다. 최신 사용자 요청에 따라 이전 얼음 띠 조형을 구름으로 대체하며, 기존 조형은 이력으로 남긴다. LOCKED 변경·정사 충돌은 없다. 최종 조형 채택과 기존 전투 수치·실전 DB 연결은 OPEN이다.
