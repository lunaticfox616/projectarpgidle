# 인과 — 피격 반응형 물리 폭발 젬 v3.38

## 확정된 사용자 요청

- 새 이름 **인과**, 전체 61번째 젬·이펙트 53번.
- **5회 피격하면** 캐릭터 주위 **4타일**에 물리 폭발을 일으키며 누적을 **0으로 초기화**한다.
- 인과 자체는 직접 시전할 수 없다. **다른 공격의 사용은 제한하지 않는다.**
- 폭발 시 바닥에 **켈트 트리플 매듭 마법진**을 표시한다.
- 기존 60개 젬과 52종 이펙트를 보존한다. 이펙트 목록은 소환 8종을 포함하지 않아 젬 번호와 다르다.

## 구현 기본안과 범위

[적용 기본안·OPEN] 피격은 방어 계산을 마친 실제 양수 피해의 직접 적중으로 센다. 회피·빗나감·차단·지속 피해·자해·반사 피해·인과에서 유래한 피해는 세지 않는다. 사망하거나 장착을 해제하면 누적을 초기화하며, 치명타의 별도 누적 배수는 없다. 죽음을 일으킨 피격에는 폭발하지 않는다. 이 피격 세부 규칙은 사용자가 지정한 5회·물리·인과만 직접 시전 불가와 구분한다.

범위 기본안은 타일 중심 사이의 원형 거리다. 9×8 전장·48px 셀에서 `dx² + dy² <= 16`을 만족하는 살아 있는 모든 적을 각각 1회 처리한다. 일직선 4칸, 대각 2·3칸 거리는 포함하고 대각 3·3칸은 제외한다. 보드 밖은 제외한다. 5번째 피격 시각의 플레이어 위치와 적 목록을 읽고 폭발 위치를 고정한다. 적이 없어도 5번째 피격에 폭발과 초기화는 발생한다.

피해량·배율·재사용 시간·소모량은 지정하지 않았으며 `null`로 남긴다. 직접 시전 슬롯이나 자동 공격 예약에 인과를 넣지 않는다. 분류 `reaction`은 피격 반응을 구별하기 위한 구현 표기이며 공격/주문 증폭의 적용을 임의 확정하지 않는다.

## PixelLab 원화와 움직임

32×32 투명 씨앗 젬은 세 갈래 목질 껍질과 은회색 매듭 핵이다. 최종 12색·371개 불투명 픽셀, 경계 x5~26/y5~25로 바깥 여백을 둔다. 처음의 보라색 핵은 최신 물리 피해 응답에 따라 은회색으로 바꿨다. 게임용 파일은 `assets/gems/active/causality-seed-32-v1.png`, 번들 `icons/53.png`이다.

128×128 마법진 원화는 세 개의 뾰족한 고리가 교차하고 가는 외곽 원이 감싼다. 3색을 사용하며 캐릭터 아래 바닥에 고정 3배 크기로 나타난다. 최대 알파 0.56, 100ms 도입 후 1,000ms 안에 사라진다. 함께 생성되는 별도 128×128 회색 충격파는 중앙이 투명한 압력 고리로, 580ms 동안 밖으로 한 번 퍼진다. 최대 알파 0.5이며 마지막 210ms에 감쇠한다. 이 두 시각 이벤트는 피해를 두 번 적용하지 않는다.

마법진과 충격파는 모두 캐릭터 아래에 배치한다. 반복 명멸·화면 전체 섬광·가산 합성·카메라 흔들림을 추가하지 않았다. 위협 범위의 가독성은 큰 매듭과 한 번의 확장으로 확보한다. 개별 몬스터 수만큼 장식 입자를 추가하지 않는다. 평가는 해당 연출의 구현 특성이며 광과민성 안전을 보증하는 판단이 아니다.

## MZ 연결 계약

`WorldTreePixelLabFX.causality`는 `WT_CAUSALITY`와 같은 피격 반응 API를 제공한다. 캐릭터마다 `createReactor({ ownerId, getSource, getEnemies, emit, onExplosion })`를 만들고 장비·생존 변화는 `setEquipped(bool)`, `setAlive(bool)`로 전달한다.

전투 담당 코드가 방어 처리를 마친 뒤 `receiveHit({ sequence, at, targetId, sourceId, kind: 'hit', damageTaken, targetAliveAfter })`를 호출한다. `at`은 렌더러와 같은 밀리초 시간축, `sequence`는 캐릭터별로 증가하는 안전한 정수이며 시간도 감소하면 안 된다. 동일·과거 번호를 거절하므로 중복 통지로 누적되지 않는다. 누적 리셋은 이 번호를 되돌리지 않는다. 새 전투의 번호를 처음부터 쓰려면 새 반응기를 만든다.

`getSource(at)`는 현재 `{gx, gy}`, `getEnemies(at)`는 `{id, gx, gy, hp}` 배열을 돌려준다. 좌표는 전장의 정수 셀이다. 유효하지 않은 위치는 누적하지 않는다. 스냅샷 조회가 예외를 내면 호출자에게 전파되고 해당 입력 번호는 재사용할 수 없으므로 호스트가 유효한 스냅샷을 보장해야 한다.

`emit(event)`는 두 바닥 시각 이벤트를 해당 FX 레이어에 전달한다. `onExplosion(batch)`의 물리 피해 배치는 5회마다 한 번 발생한다. 이 배치에는 대상 ID·위치·시각·1회 적중 정보가 있으며, 실제 HP 감소는 호스트가 확정된 피해 공식으로 처리한다. 렌더링 실패나 스프라이트 제한은 피해 대상을 줄이지 않는다. 콜백 전에 누적을 소모하여 재진입이나 예외로 폭발이 중복되지 않으며, 피해 콜백 예외의 복구는 호스트 책임이다.

`canCast()`는 항상 false, `cast()`는 실패 사유를 반환한다. 다른 공격에 대한 후킹이나 차단은 없다. 수동 호출 기능은 전용 페이지의 **피격 시뮬레이션**에만 쓰인다. 현재 플러그인·텍스처 설치는 전투 DB 등록이나 자동 HP 연결을 뜻하지 않는다.

## 성능과 검수

마법진 4칸·충격파 4칸의 64px 타일을 사용해 8슬롯을 추가한다. 기존 466슬롯은 그대로고 전체 474슬롯이다. Canvas/export master는 기존 1024×1920을 유지한다. MZ의 Base 1024×1856, Extra 128×64는 바이트 단위로 보존하며 새 `WorldTreePixelLabFXCausality.png` 128×256에 8타일을 담는다.

추가 RGBA 텍스처는 **131,072바이트(128KiB)**, 전체 세 텍스처는 **7,766,016바이트**다. 이미지/엔진의 다른 메모리는 이 숫자에 포함하지 않는다. nearest 필터·mipmap 비활성·48개 Sprite 풀·128개 시각 이벤트 상한을 유지한다. 일반 검수 최대 8Sprite, 동시 폭발 부하에서도 표시 제한과 피해 콜백은 독립이다.

- 피격 상태·5회 임계·초기화·수동 금지·중복·사망·장착·범위·재진입·표시 실패·장기 입력 등 14그룹 통과.
- 6,000회 피격에 폭발 1,200회. 한 시각 1,000회 피격은 폭발 200회, 표시 이벤트 128개·Sprite 48개 제한.
- 기존 52종의 피해 시퀀스 104개, Canvas 표본 208개, 네이티브 MZ 표본 104개 동일. 기존 산출물 2,461개 보존 검사 통과.
- 중앙과 네 모서리의 범위·배치·배우보다 아래 렌더링·종료 정리 통과.
- MZ 1.10.0 / PIXI 5.3.12, 공유 텍스처·8Sprite·풀 재사용 확인.
- 전용 페이지 12개 검사와 실제 화면, 6개 모션 시점 육안 확인. 미리보기는 자동 반복하지 않는다.
- `motions/53.webp`, `animations/53.webp`: 432×384 투명·40ms 간격 85개 표본=3,400ms. 동일 프레임을 병합한 실제 WebP는 26프레임이며 대기·잔상 시간은 유지한다. `sheets/53.png`: 256×128.
- 검수 `qa/causality/`, 미리보기 `causality.html?version=3.38`.
