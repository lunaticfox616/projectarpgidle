# 신성한 안개 — 은색 향로와 넓은 휘두르기 v3.36

## 사용자 요청과 적용

- [최신 사용자 요청] 향로를 기존 범위보다 넓어 보이도록 휘두르고 향로의 금속은 은색으로 한다.
- [적용] 젬 58번·이펙트 50번의 향로와 사슬을 은색으로 바꾸고 사슬을 40px 늘려 큰 회전 궤적을 만든다. 기존 문서 24의 짧은 청동 사슬 제안은 이 요청으로 대체한다.
- 실제 피해와 디버프는 **플레이어 주위 1칸**에 유지한다. 대각선 포함 인접 8칸, 모서리 3칸, 자신의 칸 제외. 향로가 시각적으로 지나가는 바깥 칸에 추가 피해를 주지 않는다.
- 주문·화염 분류, 0.33초 타격, 0.52초 휘두르기, 0.7초 안개와 받는 화염 피해 증가 20%·4초 기본안은 유지한다. 신규 젬을 추가하지 않으며 전체 60개 젬·52종 이펙트다.

## 도트와 움직임

PixelLab으로 기존 32×32 향로의 금속만 은색으로 편집했다. 어두운 강철 회색, 중간 은회색, 제한된 밝은 면으로 금속을 구분한다. 불투명 픽셀 248개, 실제 사용색 7색, 외곽과 투명 구멍은 원본과 동일하다. 큰 색면을 유지하고 발광·깜빡임·입자를 추가하지 않는다. 젬, 따뜻한 잿빛 안개와 불꽃 표식은 그대로다.

손 위치를 축으로 기존 회전 각도와 속도 곡선을 유지한다. 기존 사슬 고리의 4×6px 영역을 네 번 재사용해 2배 정수 배율, 간격 10px의 사슬을 연결한다. 향로 자체도 2배 정수 배율이며 사슬과 같은 각도로 움직인다. 원본의 결합점을 손에서 40px 더 떨어뜨린다. 중앙 검수 장면에서 향로 끝 궤적의 최대 반경은 약 104px이다. 실제 주변 1칸 판정은 그대로이므로 가로·세로 경계 72px보다 바깥으로 보이는 연출이다.

회전은 기존 π/32 단위, 위치는 정수 픽셀을 사용한다. 사슬과 향로의 투명도·시작·종료·취소는 함께 움직인다. 사슬이 늘어나도 피해 시점, 시전 위치 갱신, 안개·표식의 레이어는 변하지 않는다.

## 원본과 성능

- PixelLab 편집 작업: `3c1a852b-038e-44a3-833a-9a1fabeb552f`; 팔레트 작업: `e41dae8f-6ac3-4ce2-9fa1-685d69df0de8`.
- 원본과 프롬프트: `pixellab/silver-censer-v336/records.json`; 준비 프레임 `ready/0.png`, `ready/1.png`.
- 기존 50번 첫 64px 슬롯의 왼쪽 위 32px 향로 영역만 변경한다. 다른 영역과 465개 슬롯은 동일하다. 전체 466슬롯을 유지하며 사슬은 같은 영역을 잘라 재사용한다.
- 휘두르기 Sprite는 향로 1개+연결 사슬 4개다. 인접 8적 검수 장면의 전체 최대는 기존 10개에서 14개로 바뀌며, 미리 할당된 48개 풀과 128개 이벤트 제한을 유지한다.
- MZ 텍스처 2개·RGBA 7,634,944바이트 유지, 추가 텍스처 메모리 0바이트. 보간과 밉맵을 사용하지 않는다.
