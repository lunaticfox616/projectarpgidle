# 빈 플라스크 — 유리 파편 포물선 v3.35

## 최신 사용자 요청

빈 플라스크가 깨지며 생성되는 파편도 포물선을 그리며 날아가도록 수정한다. 이펙트 49번의 파편 비행과 착탄 방향만 변경한다. 병·파편·파손·젬의 PixelLab 원화는 그대로 사용한다.

## 적용한 모션

깨진 지점에서 나온 파편이 위로 솟은 뒤 조준한 몬스터에게 내려간다. 날카로운 끝은 곡선의 진행 방향을 따르며, 도착하면 같은 방향을 유지한 채 짧게 사라진다. 같은 칸의 적에게 재적중할 때는 위로 튀었다가 그 칸으로 돌아온다.

파편의 진행률을 `t`로 두고 시작점과 목표점의 선형 보간에 `-4 × 높이 × t × (1-t)`의 수직 높이를 더한다. 시작점과 도착점은 고정하고 비행 시간·발사 간격·피해 시점은 유지한다. 높이는 거리와 파편 순번에 따라 약간 다르며 최대 68px다. 보드 위쪽에서는 높이를 낮춘다. 각도는 5.625도 단위, 위치는 정수 픽셀로 맞춘다. 목표점을 떠난 적은 여전히 빗나가며 자동 추적으로 바꾸지 않는다.

기본 1~4개·각 기본 파편별 추가 발사 확률·최대 8개·다른 몬스터 우선·부족하면 재적중·피해 콜백은 기존 23번 규격을 유지한다. 변경은 `atlas-renderer.js`의 49번 시각 분기에 한정한다. `empty-flask.js`는 바꾸지 않는다.

## 성능과 검수

각 파편의 이동 차이·높이·착탄 각도는 시각 이벤트 생성 때 계산하여 보관한다. 프레임마다 새 파편이나 원화를 생성하지 않는다. 전체 아틀라스 466슬롯과 모든 원화 PNG는 이전 버전과 동일하다. MZ 텍스처 2개·RGBA 7,634,944바이트·48Sprite 풀·이벤트 상한 128개를 유지한다. 추가 텍스처 메모리 0바이트, 최대 파편 구성의 MZ 검수 장면은 8Sprite였다.

방향·보드 모서리·같은 칸을 포함한 51가지 경로 구성에서 357개 위치의 파편 끝과 접선 방향을 확인했다. 정확한 착탄 좌표·착탄 방향 연속성·취소·대상 없음·재적중·공격 속도를 검수했다. 104개 피해 시퀀스와 다른 51종의 Canvas 204표본·실제 MZ/PIXI 102표본이 이전 버전과 일치한다. 미리보기의 개수·확률·대상 선택 및 1회 재생 10개 항목을 확인했다.

- 미리보기: `empty-flask.html?version=3.35`.
- 전체 투명 모션: `motions/49.webp`, `animations/49.webp`.
- 검수: `qa/empty-arcs/`의 수정 전후 모션·주요 장면·MZ 화면·검사 기록.
- 원화: `pixellab/empty-flask-v328/ready/`와 `sheets/49.png`를 그대로 사용.
- 재출력: `build-atlas.cjs` → `build-preview.cjs` → `export-empty-arcs.cjs`. 검사 `verify-empty-arcs.cjs`, `verify-empty-arcs-page.cjs`. 설치 후 `finalize-empty-arcs.cjs`, `package-empty-arcs.ps1`.

## 정사 기준·충돌·미확정

`docs/world/00_CANON_INDEX.md`, `01_WORLD_PREMISE.md`, `06_VISUAL_REFERENCE_MANIFEST.md`와 아이템 규격 02·23을 참조했다. LOCKED 변경과 정사 충돌은 없다. 포물선 이동은 사용자 요청이며 높이·각도 등 세부 연출은 제안이다. 기존 전투 수치·추가 발사 스탯 및 DB 연결은 OPEN을 유지한다.
