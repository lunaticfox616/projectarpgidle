# 탄성 플라스크 — 스킬 젬과 픽셀 이펙트

## 사용자 확정 요구 — 2026-09-09

- 이름: **탄성 플라스크**. 기존 51종에 추가하는 52번째 32×32px 씨앗 젬이다. 비소환 이펙트 갤러리에서는 44번이며, RPG Maker MZ 데이터베이스 ID를 의미하지 않는다.
- 피해 속성: **카오스**. 독성 플라스크가 기본 **총 4번 착지·적중**한다. 최초 투척의 적중도 포함하며 최초 1회 + 추가 4회가 아니다.
- 최초 대상은 유효한 살아 있는 적 중 무작위로 선택한다. 이후는 직전 대상 이외의 살아 있는 적 중 무작위로 선택하고, 다른 적이 없으면 같은 적에게 다시 적용한다. 이전에 맞았던 다른 적도 다시 후보가 될 수 있다.
- 살아 있는 적이 전혀 없으면 종료한다. 죽은 적에게 새 피해를 적용하지 않는다.
- Slay the Spire의 탄성 플라스크를 연출 참고로 사용한다. 원작 카드 수치를 가져오지 않으며 사용자의 기본 4회 규칙이 우선한다.

## 시각 제안 및 제작물

- `[제안]` 갈고리처럼 말린 목질 줄기와 상아색 껍질이 보라색 액체 핵을 감싼 비대칭 씨앗. 짙은 보라색 외곽, 밝은 보라색 반사, 소량의 독성 녹색을 사용한다. 별도 클래스 전용 설정이나 세계관 능력을 추가하지 않는다.
- PixelLab Pixen으로 네이티브 32px 씨앗·플라스크·착지 원화를 생성하고 착지 후속 4장을 생성했다. 세 자산의 7장을 공통 12색 이내, 디더링 없이 정리했다. 젬 실제 사용색 10색, 투명도 0/255.
- `[제안]` 포물선 상승 → 공중 한 바퀴 회전 → 착지 때 눌림 → 재도약. 340~520ms 비행·80ms 착지 압축·280ms 액체 잔류는 검토용 연출 시간이며 공격 속도/재사용 시간 확정값이 아니다.
- 생성 원본은 `output/skill-effects-43-v3-pixellab-mz/pixellab/bouncing-flask/`에 보존한다. 64px 첫 착지 후보는 구형 덩어리로 읽혀 채택하지 않았다. 32px 단순 액체 후보를 사용한다.
- 젬: `assets/gems/active/bouncing-flask-seed-32-v1.png`. 기존 51장은 보존한다.
- 미리보기: 기존 갤러리 `?version=3.4&skill=44`. 적 3명/1명 전환, 다시 시전 시 다른 난수 경로, 속도 조절과 중단을 지원한다.
- `bouncing-flask-showcase.gif`: 3명 분산/1명 재적중 전체 궤적 비교. `sheets/44.png`·`animations/44.webp`는 착지 액체 5프레임이며, 비행 경로는 실시간 좌표를 따라 계산한다.

## 성능과 연결

- 기존 424칸 뒤 빈 칸 6개에 플라스크 1장·착지 5장을 넣었다. 합계 430프레임, 1024×1728px, RGBA 6.75MiB로 **텍스처 크기 증가 없음**. 이미지 1장·기본 스프라이트 풀 48개·시각 이벤트 128개 상한 유지.
- 한 시전 검사에서 동시 출력 최대 2개. 무작위 선택은 도약 시작 시에만 수행하며 렌더링 중 난수·파티클 생성은 없다.
- `WT_BOUNCING_FLASK.createCast()`는 도약마다 현재 적 목록을 다시 확인한다. `onImpact`는 전투 코드에 전달하는 알림이며 피해 계산이 아니다. 적의 이동·충돌 판정과 피해 적용은 연결하는 게임 코드가 결정한다. 취소 때 컨트롤러 `cancel()`과 레이어의 해당 채널 취소를 함께 호출한다.
- MZ 시연 명령 44번, 다른 적 우선 1,000회, 단독 적 4회, 적 목록 변경 후 재적중, 대상 없음, 중단, 정확히 한 번씩 4회 알림, 43종 기존 화면 172표본 SHA-256 일치, 이전 424프레임 보존을 확인했다. `qa/flask-verification.json` 참조.
- 실제 MZ 1.10.0·PIXI 5.3.12의 Sprite/Bitmap에서 풀 48개 재사용·128개 이벤트 상한을 확인했다. 이 PC의 헤드리스 Edge에서 측정한 CPU 제출 시간은 전체 게임 또는 모바일 FPS 보장이 아니다.
