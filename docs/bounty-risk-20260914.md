# 보물사냥 표시 및 위험도

- 준비된 HUD 버튼은 `보물사냥`만 표시한다. 최저 보스 티어 기준은 툴팁과 선택창에 유지한다.
- 공통 대화상자를 사용해 이름·특성·위험도·보상을 구분한다. 재화 이름은 기존 `getStyledOrbName`, 장비는 `getRarityColor`를 사용한다. 아이콘과 `공통 추가 보물` 안내는 제거한다. 추가 보물 지급 자체는 유지한다.
- 위험도는 표적 데이터가 소유한다. 철갑 수집가·뿌리 밀렵꾼은 낮음, 폭풍 밀매상·거울 갑주 도주자는 보통, 유리칼 처형자·혼돈 중개상은 높음이다.

| 위험도 | 표적 특성 적용 후 생명력 | 공격 피해 | 표적 일반 보상 기대량 | 희귀 보물 확률 |
| --- | ---: | ---: | ---: | ---: |
| 낮음 | ×1 | ×1 | ×1 | ×1 |
| 보통 | ×1.10 | ×1.05 | ×1.10 | ×1.15 |
| 높음 | ×1.20 | ×1.10 | ×1.20 | ×1.30 |

일반 보상은 기존 장비·재화에 기대량 배율을 적용하고 소수 부분을 확률로 1개 추가한다. 희귀 보물은 황금률·요정의 고리·고유 장비 이벤트다. 이미 추첨한 희귀 보물은 보존하고, 일반 보물만 수락 시 1회 승급 추첨한다. 기본 희귀 확률을 r이라고 하면 승급 추첨의 확률 배율은 `(위험도 추가 배율)/(1-r)`다. 따라서 일반 보물에서 승급되는 양까지 합쳐 목표 희귀 확률이 된다.

다음 지역 등장, 최저 보스 티어, 실패 후 다시 보스 10회 조건은 유지한다. 해금 전 재화 제한·고유 전용 드랍 제한도 유지한다. 이전에 얻은 보상은 다시 굴리지 않는다. 신규 저장 필드는 없고, 신규 난수 계산은 선택·처치 시에만 발생한다.

검증: 실제 표적 능력치·희귀 승급·보상 추가·중복 방지·저장 복원 검사, 전체 스모크 194개, PC·모바일 보물사냥 선택·다음 지역 예약·보물 수령 검사 4개 통과. 장기간 플레이 밸런스는 추가 관찰이 필요하다.

전체 구조 검사에서 `getStyledOrbName`의 암묵 참조 1건이 검출됐다. 기존 UI가 공개한 `window.getStyledOrbName`으로 명시하고 변경 파일의 미정의 변수·미사용 변수·빈 블록·복잡도·깊이·길이·매개변수 검사를 재실행해 통과했다. 이 참조 수정 후 전체 구조 검사를 다시 실행하지는 않았다.
