## 2. 드랍이 굴러가는 방식

1. 처치마다 `rollLootForEnemy`(js/combat.js)가 젬, 재화, 장비, 영역 보스 고유(3%), 야생 부적, 주얼을 따로 굴린다.
2. 처치당 장비 기대 개수는 일반 0.765%, 정예 3.4%, 보스 13.2%에 배율을 곱한 값이다. 장비가 160 크레딧 동안 안 나오면 희귀
   이상을 보장한다(data/items.js, js/loot.js).
3. `generateEquipmentDrop`(js/passives.js): 아이템 레벨로 콘텐츠 상한(액트 9, 혼돈 15, 우주와 아틀라스 20) → 상한 아래 2~4티어
   폭에서 드랍 티어 → 부위를 고르게 고른 뒤 `chooseItemBase` → 희귀도 → 고유면 `generateUniqueItem`, 아니면
   `createItemFromBase`와 `rerollExplicitMods` → 특출 베이스(줄마다 1%), 소켓 달린 장신구, 화석 전용 옵션, 혼돈계 잠식 →
   복제, 묶음, 타락 변형(js/loot.js).
4. 줍기는 필터와 자동 해체를 거친다. 바닥 더미의 큰 소리는 황금률, 고유, 목표 일치일 때만 난다.

### 좁고 반복되는 지점

- **베이스에 하한이 없다.** 상한만 거르고 낡은 베이스도 같은 가중치다. 아틀라스 16등급 일반 몬스터 드랍 중 드랍 티어 2단계 안쪽
  베이스는 15%, 4단계 안쪽은 28%다. 체인 최상위는 가중치 0.04라 0.03~0.05%만 나온다.
- **베이스가 적은 장신구가 반복된다.** 부위를 먼저 고르기 때문에 목걸이 베이스 하나가 전체 드랍의 약 2%다. 혼돈 30층과 아틀라스
  8, 16등급 여섯 경우 모두 가장 흔한 베이스 3개가 목걸이였다. 장신구 일반 베이스는 T14~T15에서 끝나고 대부분 티어당 1개다.
- **방어구 베이스는 생성된 묶음이다.** gen__ 베이스 62개가 이름 어간 21개를 나눠 쓴다. 방어구 부위당 기본 옵션 조합은 18~21종.
- **무기 옵션 풀이 하나다.** 소환 무기를 뺀 모든 무기가 같은 43줄을 쓴다. 대검에도 투사체 3줄과 주문 4줄이 붙는다.
- **방어구 풀이 작다.** 방어 형태가 하나인 베이스 기준 투구 14줄, 신발 13줄(접두 3~4).
- **접두와 접미는 데이터에만 있고 굴림에서는 쓰지 않는다.** 희귀의 약 33%가 접두 4개 이상이거나 접미 4개 이상이다. 102줄 중
  88줄이 가중치 1이다.
- **최고 티어가 드물다.** 티어 감쇠 0.2라 상한 20에서 T20은 약 2.5%. 아틀라스 16등급 희귀 중 상한 2티어 안쪽 줄이 둘 이상인 것은
  4.5~5.8%.
- **영역 도감 고유 70종이 능력치 묶음 3~4개를 돌려 쓴다.** 부위도 순번으로 정한다.
- **얇은 부위의 고유가 적다.** T15 이하 일반 고유는 목걸이 6, 허리띠 6, 반지 8, 방패 8뿐이다.
- **아틀라스 지도는 수량과 희귀도만 바꾼다.** 지도 전용 장비가 없다.
- **고유 추적은 확률을 바꾸지 않는다.** 강조하고 보호만 한다.

## 4. 확장 로드맵

콘텐츠를 늘리기 전에 단계마다 목록과 개수를 먼저 확정하고 진행한다.

### 1단계: 데이터 위주 (1~2주)

| 할 일 | 예시 | 고칠 곳 | 늘어나는 것 |
|---|---|---|---|
| 베이스 드랍 창 | 드랍 티어보다 4단계 넘게 낮은 베이스는 가중치 0.15, 체인 최상위는 0.25 | data/items.js 상수, js/passives.js chooseItemBase | 메모리 안 실험: 아틀라스 16등급 4단계 안쪽 28% → 68%, 최상위 0.05% → 0.87%, 혼돈 30층 52% → 87% |
| 장신구 베이스 14개 | 목걸이: 호박, 비취, 청금, 나이테, 송진(T16), 세계수 잎(T20). 허리띠: 가죽 매듭띠, 덩굴 사슬띠, 뿌리 매듭띠, 옹이 장식띠(T18). 반지: 홍옥, 황옥, 쌍석, 금강석(T18) | js/state.js BASE_ITEM_DB, data/items.js baseAssets | 장신구 일반 베이스 27 → 41, T16~T20 단계가 생김 |

- 그림: 새로 그리지 않는다. 같은 부위 그림에 색조만 입히고, 아이콘이 없으면 부위 그림으로 대체된다.
- 위험: 고유는 부위와 이름이 도감 키라 기존 고유의 이름과 부위는 바꾸지 않는다. 베이스 승급 체인과 최상위 승급 비용을 다시 본다.
  젬 레벨 줄은 기존 특수 줄처럼 가중치 0.15~0.3. 새 무기 베이스는 대분류 표에 반드시 넣는다.

### 2단계: 시스템 (2~4주)

- **접두 3, 접미 3과 태그**: `rerollExplicitMods`, `pickRandomMods`에 종류 한도. MOD_DB에 태그(공격, 주문, 원소, 방어, 생명, 소환,
  속도)와 계열별 최소 아이템 레벨. 홀씨와 화석의 하드코딩 목록을 태그 질의로. 얻는 것: 읽기 쉬운 희귀, 접두 봉인 같은 결정적
  제작, 필터 규칙. 위험: 희귀 화력 분포가 바뀌어 루프 난이도를 다시 잰다.
- **세계수 기운(영향력 대응)**: 아틀라스 지역 다섯의 지도에서 떨어진 장비가 낮은 확률로 기운을 띤다. 뿌리의(카오스 저항, 중독
  확률), 줄기의(막기), 가지의(번개 젬 레벨, 투사체), 정원의(점화, 화염 젬 레벨), 성소의(동결, 최대 냉기 저항). 지역당 6~8줄의
  새 표, 테두리 색은 지역 색 재사용. 지역 5 × 부위 9 × 약 5줄로 약 200가지. 순수 화력보다 조건부 옆길 성능으로.
- **잠식 일반화(베일)**: 혼돈계 전용 확률을 공허 균열 방과 리그 보스로 넓히고 전용 혼합 줄을 둔다. 고르기 화면을 UI 계층으로 옮긴다.
- **기억의 잎(점술 카드 대응)**: 콘텐츠, 지역, 보스별로만 떨어지는 묶음 수집품. 예: 뿌리 파수꾼의 잎 5장 → 정해진 고유,
  금고지기의 잎 8장 → 황금률 3, 벌집 여왕의 잎 6장 → 벌집 여왕의 명령. 목표 경로 30~40개, 그림 1장에 색조.
- **아틀라스 드랍 편향**: 지도석 접미 옵션(장비가 무기일 확률 +30%, 대신 몬스터 강화), 장신구 각인, 고유 각인. 원하는 아이템을
  보고 지도를 고르게 된다.
- **타락 확장**: 잿불가지 결과에 타락 전용 줄(목걸이 젬 레벨 +1, 신발 이동 속도 +8% 등 부위당 3~5줄)과 고유 전용 결과(고유 효과
  수치 ±20%). 고유 219종이 다시 쫓을 대상이 된다.

### 3단계: 콘텐츠 (장기)

- 지역 한정 베이스 10개, 고유 15개(예: 깊은 뿌리의 뿌리 감긴 반지, 하늘 가지의 번개 맞은 장궁, 잊힌 정원의 잿불 정원 향로).
- 정점과 리그 보스 9명의 전리품을 보스당 1개에서 3~4개로(+27).
- 영역 도감 고유 70종의 능력치를 효과에 맞게 따로 정한다(이름과 부위는 유지).
- 루프 기운 순환: 루프마다 바뀌는 8줄 풀 6조. 리그처럼 시간에 따라 바뀌는 다양성.
- 특수 베이스: 쌍색 장화(저항 두 줄), 공허 박힌 갑옷(공허 소켓 기본), 메아리 장갑(연속 타격).
- 그림: 상징적인 고유만 새로 그리고(무기는 16×48 도트) 나머지는 색조를 재사용한다.

## 5. 휴대폰에서 시끄럽지 않게

- 소리 규칙은 그대로(희귀 무음, 큰 소리는 황금률, 고유, 목표 일치). 새로 큰 소리를 줄 것은 체이스 고유, 잎 묶음 완성, 상한 티어 줄이
  둘 이상인 기운 장비뿐.
- 더미는 처치당 하나, 이름은 중요도 순. 기운과 대분류는 글자 대신 테두리 색으로.
- 필터를 넓힌다: 낡은 베이스 자동 해체, 무기 대분류 허용 목록, 기운, 최상위 베이스. 휴대폰에는 성장, 후반, 수집 세 프리셋만.
- 장비 판정(js/equipment-triage.js의 화력, 생존 향상 표시)을 기본으로 켜 비교 부담을 줄인다.
- 성능: 드랍마다 베이스 277개와 옵션 102줄을 거른다. 두 배가 되면 부위, 방어 형태, 대분류별 풀을 캐시한다(방치 정산이 많이 부른다).
- 저장: 새 필드는 기본값, 이전 저장 마이그레이션, 중복 적용 방지를 함께 넣는다.

## 6. 먼저 할 5가지(검토자 추천)
