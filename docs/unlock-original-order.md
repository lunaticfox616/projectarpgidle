# 선택식 개편 전 해금 순서

2026-09-06 조사. 새 정책이 아닌 기존 동작 정리다. 게임 코드·저장은 변경하지 않았다.
선택 카탈로그의 `minLoop`와 `after`는 원래 조건의 근거로 사용하지 않는다.
개편 전 비교 기준은 Git `4355fe3`의 지도 진행표와 도메인·메뉴 함수이며, 현재에도 남아 있는 개별 조건과 대조했다.
루프 표는 새 콘텐츠가 추가되거나 기존 콘텐츠가 확장되는 시점만 적었다.

## 특정 루프 하나로 정렬할 수 없는 콘텐츠

| 콘텐츠 | 원래 기준 |
| --- | --- |
| 기본 장비 재련·보조 젬·젬 연구·플라스크 관리 | 각각 장비·젬·재료를 사용하는 기본 기능. 선택 포인트나 독립적인 루프 2/3 선행 해금은 없었음 |
| 스킬 트리·장비 메뉴 | 원래 스킬 트리는 레벨 2, 장비 메뉴는 첫 장비/재화. 최근 합의인 루프 1 기본 4종 제공과 역사적 메뉴 노출 조건은 구분 |
| 직업 전직 | 1차 시련은 액트 3 진행, 2차는 액트 8 진행. 시련 완료 후 직업 선택; 후속 시련은 열쇠·레벨 등 추가 조건 |
| 재능 | 재능 개화 시련과 개화 기록. 나무꾼 잔상, 전직, 카오스/코어 열쇠 각 1개 등이 입장 조건 |
| 전문가 | 균사학자: 루프 2 + 화염 홀씨. 젬 각인사: 루프 2 + 군주의 핵 또는 루프 4 + 창공의 힘. 천문학자·양봉가는 해당 콘텐츠/재료와 연결 |
| 거래소 | 액트 5 클리어 |
| 고유 도감 | 첫 고유 장비 획득/장착/등록 |
| 저널 | 프롤로그 이외의 기록 획득 또는 도감 개방 |
| 전적·장비 전당 | 독립적인 루프 해금 조건 없는 메뉴 |
| 대전 | 개편 전 지도 정의에는 `initiallyUnlocked: true`. 현재의 루프 3 배치는 이후 변경이므로 원래 목록에는 적용하지 않음 |
| 혼돈 주입기 | 나무꾼 시뮬레이터 조우·도전·저널 기록 등 |
| 영구 혼돈계 | 나무꾼에게 생명력 10% 이상 피해를 준 전투를 마무리. 입장 시 해당 루프 혼돈 20층 클리어 요구 |
| 지하계 | 혼돈계 해금 + 케르베로스 처치 + 혼돈 심화 30층 도달 + 고대 미궁 100층 도달. 입장에는 해당 루프 혼돈 20층 클리어도 요구 |
| 우주계 | 나무꾼 저널 + 지하계 진행 `highestFloor >= 30` |
| 아르카나 | 우주계 보스 등에서 봉인된 카드를 처음 획득 |
| 루프 패시브 확장 | 기본 루프 패시브 노드를 전부 1레벨 이상 확보. 오래된 진행표의 ‘루프 5 확장’ 문구와 실제 판정이 다름 |

## 해석 시 주의할 기존 차이

- 기존 표의 ‘루프 4 창공 강화’는 각인/가공 계열을 뜻한다. 창공의 탑은 루프 15 계열이다.
- 지하계 18, 우주계·아르카나 20, 연구 3, 강화 전체 4라는 최근 선택 카탈로그의 수치를 원래 해금 조건으로 읽으면 안 된다.
- 기존 진행 기록이 있는 저장은 접근을 유지하는 예외가 있어 새 캐릭터의 최초 해금 조건과 다를 수 있다.
- 위 표는 콘텐츠 순서 정리를 위한 자료다. 모든 개별 레시피·보스의 입장 비용까지 전수 나열한 문서는 아니다.
