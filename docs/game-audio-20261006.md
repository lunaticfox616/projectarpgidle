# 게임 효과음 전면 교체 — 2026-10-06

현재 구현은 `codex/game-feel-juice-20261005`의 `assets/audio/game-sfx-v2/`다.
최종 사용자 결정: **일반 희귀템 드롭은 무음**이다. 황금률·고유·강조 드롭의 중요 알림은 유지한다.
사용자가 이전 결과 전체를 폐기하라고 요청해 기존 배포 음원·비교 음원·원본 WAV 147개
(약 32.9 MB)를 삭제했다. 폐기한 소리를 재사용하거나 피치만 바꾼 변주를 만들지 않았다.
삭제 범위와 파일 해시는 `artifacts/audio-production/v2-sources/discarded-files.json`에 남겼다.

## 제작 방식과 확인 한계

설치된 Agent Audio MCP의 `generate_audio`로 Stable Audio 3 Medium 원본을 새로 생성했다.
이 생성기의 로컬 TFLite README는 너무 짧은 클립이 충분한 latent 토큰을 갖지 못한다며
약 20초 이상을 권장한다. 이 설명은 특히 루프의 일관성을 다루므로, 이전 효과음 품질
저하의 확정 원인으로 단정하지 않는다. 이전 1~3초 직접 생성에서 20초 원본 생성 후
개별 타격 추출로 제작 방식을 바꿨다.

16개 소재 원본과 별도 재시도 3개, 이후 레벨업·번개·귀중품·희귀 차임 교정 원본 8개를 만들었고,
현재 사용하는 게임 샘플은 그중 19개 원본에서 추출했다. 재시도 이유는 독립된 이벤트 대신
긴 지속음이 나온 경우다. 초기·재시도·교정 프롬프트는 `scripts/game-audio-v2-prompts.json`에 있다.
MCP 생성 결과와 원본 WAV도 같은 artifacts 폴더에 보존한다.

`scripts/prepare-game-audio-v2.py`가 에너지 상승으로 개별 타격을 찾아 시작을 맞추고,
용도별 최대 길이로 자른 뒤 일반 효과음은 시작 1.5ms와 끝 최대 45ms에 페이드를 적용한다.
레벨업은 자연 감쇠가 포함된 마지막 3.2초 구간에 시작 15ms·끝 180ms 페이드를 적용한다.
귀중품 알림은 새 금속 타격 원본의 첫 타격부터 2.4초를 사용하며, 긴 잔향의 마지막
1.1초를 감쇠시킨다. 번개는 가장 강한 후속 구간에 맞추지 않고 첫 방전부터 보존한다.
음량을 맞추고 peak 0.65 이하로 제한한다. 현재 사용하는 51개 음원에는 EQ·피치 변환이 없다.
이는 새 원본을 게임용으로 편집한 파일이며, 가공 없는 원본이라고 부르지 않는다.
`provenance.json`은 원본 해시, 추출 구간, 가공 내용, 결과 해시를 기록한다.

직접 청취 능력 없이 음질이나 예술적 완성도를 검증했다고 주장하지 않는다.
생성 성공, 파형·파일 검사, 재생 성공과 플레이어의 청취 평가는 서로 다른 검증이다.

## 게임에 사용하는 소리

총 51개 WAV, 4,293,156 bytes, 44.1kHz 스테레오 PCM16.
공격은 약 0.23~0.75초, 귀중품 2.4초, 레벨업 3.2초다.

| 구분 | 소리 |
| --- | --- |
| 물리 | 칼 타격·찌르기·회전, 화살, 묵직한 강타·방패 |
| 속성 | 화염 참격·폭발·숨결, 냉기 관통·폭발, 번개 방전·광선·폭발 |
| 기타 공격 | 마법 탄, 공허 절단·파열, 독 투척, 플라스크 |
| 사건 | 플레이어 피격, 처치, 항아리·목재 파괴, 상자, 전리품, 레벨업, 보스 보상, 귀환 |

근접·투사체·마법은 각 3변주, 세부 공격은 2변주다.
베기는 근접과, 치명타는 근접의 큰 음량과, 정예 처치는 일반 처치의 큰 음량과
같은 파일을 공유한다. 이 공유는 실제 자산 수에 중복해서 세지 않는다.

`js/ui-audio.js`가 사용자 입력 후 필요한 51개만 한 번 가져와 디코딩한다.
게임에서 AI 모델을 실행하지 않는다. 전체 8음성, 일반 전투 4음성, 공격별
110~180ms 제한을 유지하며 준비 중·숨긴 탭·오프라인 정산 중의 소리를 큐에 쌓지 않는다.
기존 효과음 설정을 끄면 현재 소리도 멈춘다.
별도의 표현용 shuffle bag으로 인접한 동일 변주를 피하고 게임 난수는 소비하지 않는다.

`js/canvas-combat-feedback.js`는 실제 스킬 정의 및 FX 속성으로 소리를 고른다.
실제 단계의 속성이 기본 스킬 속성보다 우선한다. 지속 피해 틱은 조용하고,
해당 스킬 시전만 소리를 낸다. 전투·드롭·저장 규칙은 변경하지 않았다.
기존 메뉴 확인·취소용 합성음은 이번 생성 음원 교체 범위가 아니다.

## 레벨업·번개 교정 및 귀중품 드롭 알림

기존 레벨업은 원본이 계속 울리는 구간에서 1.15초 길이로 잘려 있었다. 새로운 원본의
자연 감쇠 구간으로 교체했다. 마지막 350ms의 RMS/전체 RMS 비율은 이전 1.188에서
0.044로 줄었고, 0.1 미만을 요구하는 회귀 검사는 이전 음원에서 실패·교정본에서 통과했다.
이는 끝음 감쇠 검사이며 음악적 종지나 청취 품질을 증명하지 않는다.

번개·연쇄/광선은 전기 방전 원본, 낙뢰·룬 폭발은 균열음과 낮은 천둥을 요청한 별도
원본에서 총 6개 샘플을 교체했다. 기존에는 시작 방전이 잘릴 수 있었던 추출 정렬도 수정했다.

귀중품 드롭은 드롭 중요도를 소리로 구분하도록 낮은 청동 타격과 맑은 잔향을
요청한 새 원본으로 제작했다. `battle-ground-loot-ui.js`의 기존 판정을 유지한다.
황금률·고유 장비·강조된 장비(목표 옵션, 목표 고유, 특출 베이스, 타락 등)는
바닥 착지 때 `lootMajor`를 재생한다. 일반 희귀 장비와 보통 매물은 소리 없이
표현한다. 내부 가격 감정을 새로 노출하거나 매 프레임 계산하지 않는다.
중요 드롭 간격은 1.6초, 우선순위 2로 일반 타격에 잘리지 않으며, 한 더미의
대표 소리만 재생한다. 기존 설정의 음소거와 오프라인 무음 정책을 그대로 따른다.
실제 착지 검증 중 상자 재화와 검토 버튼이 `count` 대신 `amount`를 넘겨 표시가
생략되는 문제도 수정했다. 지급량은 그대로이며, 새 회귀 검사로 실제 상자 지급량과
표현용 수량의 일치를 확인한다. 이 검사는 수정 전 `undefined !== 1`로 실패했다.

이번 교정으로 변경된 파일은 레벨업 1개·번개 6개·귀중품 1개다. 다른 44개 WAV는
교정 전과 SHA-256이 같다.

아래는 최종 무음 결정 이전의 제작 이력이다.
후속 요청으로 일반 희귀 전리품(`lootRare`)만 0.55초에서 0.44초로 20% 단축했다.
같은 원본의 시작 타격을 쓰고 끝 45ms 페이드를 유지한다. 귀중품 알림과 다른 51개
음원은 직전 버전과 해시가 같다. 게임·미리듣기의 캐시 키도 갱신했다.
단축 후 오디오 스모크·전체 273/273(49.4초)·빌드·diff 검사를 통과했다.
4242 미리듣기 서버의 WAV 응답 해시도 수정 자산과 일치한다. 직접 청취 평가는 미실시다.

이어진 ‘띠링~’ 요청으로 `lootRare`를 `rare-soft-ping.wav`에서 새로 추출했다.
짧은 두 음의 부드러운 전자 종 차임을 요청해 생성했고, 선택한 두 번째 구간의 시작을
보존해 0.44초로 편집했다. 첫 시도 `rare-tiling.wav`는 강한 7~11kHz 성분이 있어
사용하지 않고, 중간 음역의 둥근 종소리 방향으로 다시 생성했다. 기존 음원의 피치나
EQ를 바꾼 변형은 아니다. 끝 100ms 감쇠를 적용하고 다른 51개 음원 해시는 유지했다.
이 설명은 생성 방향·편집·파형 검사이며 직접 청취한 음질 평가는 아니다.
차임 교체 후 전체 273/273(46.0초), 오디오 스모크, 빌드, diff 검사 통과.
미리듣기 서버가 제공한 WAV의 해시가 새 차임 자산과 일치한다.

전화벨처럼 들린다는 후속 피드백으로 전자 차임을 교체했다. 새 `rare-crystal-low.wav`
유리 타격 원본의 음높이를 한 옥타브 낮춰 0.44초로 편집했다. 80~300ms 구간에서
가장 강한 주파수 성분은 이전 약 1759Hz에서 약 1082Hz로 낮아졌다. 이는 음역 비교이며
맑음·전화벨 유사성에 대한 청취 판정은 아니다. 함께 생성한 `rare-vibra-low.wav`는
250Hz 중심의 긴 어택이라 사용하지 않았다. 직전 전자 차임은 재활용하지 않았다.
짧은 단발 재생, 끝 100ms 페이드, 기존 음량·드롭 판정은 유지하며 다른 51개 WAV 해시는 같다.
낮은 유리 차임 적용 후 오디오 스모크·전체 273/273(42.2초)·빌드·diff 검사 통과.
4242 서버 응답과 배포 WAV의 해시 일치도 확인했다. 직접 청취 평가는 미실시다.

최종적으로 일반 희귀템 소리를 사용하지 않기로 했다. `playLootDropSound(false)`는
아무 소리도 만들지 않으며 `lootRare`를 재생 목록·로딩·미리듣기에서 제외했다.
기존 차임은 `artifacts/audio-production/v2-sources/retired-lootRare-20261006.wav`에
보존했다. 일반 희귀 드롭의 무음과 중요 드롭의 정상 재생·중복 제한을 회귀 검사로 확인한다.
무음 적용 후 전체 273/273(43.3초), 오디오 스모크, 구조 검사, 빌드, diff 검사 통과.
