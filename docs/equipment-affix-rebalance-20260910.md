# 장비 옵션 개편 — 2026-09-10

## 적용 계약

- 개발본 `pr-repo`에 반영. 전투 발사 상한은 유지한다.
- 장비의 `projectileExtraShots`는 `projectileExtraChance`(퍼센트)로 전환한다. 기존 +11은 약 550%에 해당하며, 5발 확정 + 50% 확률로 1발이다. 패시브·큐브의 확정 발사 효과는 유지한다.
- 정규 장비 추가 옵션 102종은 실제 티어별 최소·최대값을 가진다. 저항 감소를 전투 배율로 숨기지 않는다. 기존 티어 추첨 확률은 유지한다.
- 화염·냉기·번개 저항 T20은 46–48%. 모든 원소 저항은 30–32%, 원래 낮던 카오스 저항은 28–30%.
- 부위별 일반·물리 기본 피해를 올리고 원소·카오스 기본 피해는 더 높인다. 고티어 증가폭이 더 크다. 이 변경에서는 베이스 장비를 유지했으며, 무기의 기본 피해·주문 내장 피해는 후속 [2026-09-11 조정](weapon-base-damage-20260911.md)에서 별도로 상향했다.
- 일반 피해 증가 < 공격/주문·태그 한정 피해 증가 < 개별 원소 피해 증가로 범용성의 대가를 둔다.
- 일반 생명력 흡수는 공격 타격 전용이다. 주문 타격에는 별도 `spellLeech`가 필요하며 지속 피해는 흡수하지 않는다. 기존 흡수 소프트캡·회복 상한은 유지한다.
- 공격 피해 증가 옵션을 신설하고 주문 피해 증가와 분리한다. 결투의 규율의 주문 피해 증가 공유는 기존 키스톤 규칙을 유지한다.
- 복합 옵션은 주 효과와 부 효과 모두 품질·균열·장비 배율을 적용한다. 새 일괄 추첨도 복합 옵션의 모든 스탯을 중복 검사한다.
- 항상 +1인 옵션은 고정값으로 표시한다. 소환 무기 젬 레벨의 1–5 단계 및 방패 최대 저항의 작은 정수 범위는 티어가 일부 겹치는 예외다.

## 2026-09-12 티어 구간 연속성 보정

- 각 티어의 최댓값과 T1 범위를 유지하고 T2부터 최솟값을 이전 최댓값 다음으로 연결했다. 일반 옵션 76종과 복합 옵션의 부 효과를 보정했다.
- 정수 옵션은 1, 소수 옵션은 기존 추첨 정밀도인 0.01 단위로 이어진다. 옵션별 `valueStep`을 명시해 양 끝이 정수인 소수 옵션 티어도 같은 간격으로 추첨한다.
- 이중 방어구에서 파생되는 부 효과도 비율 적용 후 반올림 때문에 공백·중복이 생기지 않게 연결한다.
- T0 고정 옵션 및 소환 젬 레벨·방패 모든 최대 저항의 기존 정수 단계 예외는 유지한다. 고유·생장·화석 전용 옵션표는 이번 정규 옵션 보정 대상이 아니다.
- 높은 티어가 뜰 확률은 그대로다. 최솟값이 낮아진 티어는 새 추첨의 평균값이 소폭 낮아지며, 기존 장비 수치는 낮추지 않는다.
- 연속성 검사는 실제 추첨의 최소·최대·첫 증가값을 전 티어에서 확인한다. 수정 전 기본 피해 T3의 누락된 12에서 실패했고, 수정 후 복합·이중 방어 옵션까지 통과했다. 기존 버전 1의 일반·복합·증폭 옵션 보존, 벌꿀 고정 보존, 중복 로드, 갱신 범위 재련도 검증한다.
- 이번 보정 검증: 전체 스모크 186개 및 PC·모바일 장비 브라우저 검사 2개 통과. 기존 기대값 중 새 범위와 달라진 명중·무기 원소 피해의 최솟값만 갱신했다.
- 최종 `npm run check:architecture`도 통과했다. 새 전역과 스크립트 로드 순서 변경은 없다.

## 저장 호환

`normalizeItem`에서 개편 전 장비는 기존 티어와 범위 내 위치를 바탕으로 변환한다. 이미 1차 개편된 장비(`affixBalanceVersion:1`)는 현재 수치와 제작으로 증폭된 수치를 보존하고, 추첨 범위만 갱신해 버전 2로 기록한다. 복합 옵션도 같은 기준이며 재호출 시 중복 변환하지 않는다. 아이템 ID, 잠금, 장착 여부를 보존한다.

고유·생장 장비의 전용 범위는 정규 장비 티어표로 덮어쓰지 않는다. 장비 투사체 옵션의 단위 변경은 고유·베이스·지하계 마법부여에도 적용한다. 기존 베이스 재추첨 범위 역시 같은 단위로 변환한다. 이미 존재하는 중복 옵션을 삭제하지 않는다.

수치 표 소유자는 기존 MOD_DB이며 새 스크립트나 로드 순서 변경은 없다. 소비하는 JS의 캐시 키를 갱신했다.

## 검증

- `node scripts/smoke-equipment-affix-rebalance.js`: 실제 롤·재추첨, 티어 범위, 저장 변환/중복 방지, 복합 증폭, 투사체 확률, 실제 타격 상한·비교 DPS, 피해 태그, 공격·주문 흡수 및 영혼의 성역 회복 대상.
- `npm test`: 전체 183개 통과.
- `npx playwright test -g 'equipment affix chance'`: PC·모바일 2개 통과. 장비 상세의 확률/고정 옵션, 공격·주문 흡수 수치 및 툴팁 확인.
- `npm run check:architecture`: 통과. 마지막 보정은 장갑·반지의 티어별 상수값만 변경하며 JS 구조는 동일하다.

실제 관통 사격에서 추가 확률 1100%와 2200%는 둘 다 피해 5130, 비교 DPS 1116.01로 동일했다(통제된 테스트 캐릭터). 확률 550%의 성공한 나머지 판정에서는 추가 6발이 나갔다. 이는 특정 세팅의 동작 검증이며 전체 빌드 밸런스나 재미 검증은 아니다.
