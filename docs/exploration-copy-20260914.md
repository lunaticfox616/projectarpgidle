# 탐험 표기 정리

- `도전과 원정`을 `탐험`, 나무 상세의 `액트 사냥`을 `나무`, 지도 메뉴의 `벌집 원정`을 `벌집`으로 변경했다.
- 권역 내부 카드의 우측 동작 표기는 `이동`으로 통일했다. 실제 입장·재화 소비 동작은 변경하지 않았다.
- 후속 리뷰 반영으로 보상은 이름만 표시하고 기존 커스텀 툴팁에 설명을 연결했다. 클릭·터치·키보드로 설명을 열어도 카드 이동을 실행하지 않는다. 보스 조건 충족 요약은 제거하고 벌집 열쇠는 보유량만 표시한다.
- 벌집·군락지의 분류 문구를 제거했다. 새 전직 시련이 가능하면 시련 카드와 상위 탐험 카드에 기존 테두리 강조를 적용한다. 이동 제한 또는 완료 시 강조가 해제된다.
- 권장 전투력은 기존 계산 결과의 DPS·EHP가 각각 권장값 이상이고 지하계 지속 회복 부족이 없을 때 달성이다. 지도와 우주계가 `getMapPowerReadiness().meetsRecommendation`을 공유한다. 카드에는 달성(초록)/미달성(빨강), 보상 감소(빨강)만 표시하며 상세 비교는 기존 툴팁에 유지한다.
- 지하계·창공의 최고 층수는 클리어 층수로 표시한다. 기존 `highestFloor`는 다음 도전 가능 층이므로 지하계는 1을 빼고, 창공은 기존 `getClearedSkyTowerFloor`를 사용한다.
- 현재 루프 클리어 최고층은 `loopProgressCurrent.bestUnderworldFloor`와 `bestSkyFloor`로 기록한다. 낮은 층 반복은 최고 기록을 낮추지 않으며 루프 초기화 시 0이 된다. 기록이 없는 이전 저장은 `null`로 구분해 최고 기록만 표시하고 영구 진행도를 복사하지 않는다.
- 탐험 내부의 중복 소제목을 제거하고 모든 카드의 제목·이동 동작을 첫 줄에 맞췄다.

검증: 스모크 194개 통과. 탐험·준비 화면·권역 브라우저 검사에서 변경 전 표기 기대값과 중복 도감 선택자를 수정한 뒤 관련 실패 항목을 PC/모바일에서 재검증했다. 지도·우주계 전투력의 색상, 툴팁, 새 시련의 상위 카드 강조를 확인했다. 구조 검사는 최종 코드 기준으로 별도 실행한다.
