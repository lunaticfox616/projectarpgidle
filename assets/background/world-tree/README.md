# World Tree ACT battle maps

- Source package: `WorldTree_ACT01-10_WebGame_Maps_v1`
- Runtime format: compressed WebP, 816×624 pixels
- Combat field: 9×8 cells, 48×48 pixels, source origin `(192, 144)`
- Required source credit recorded by the supplied package: `(C)Zepharex`

The outer environments are preserved from the supplied maps. The central 9×8 battle floors were generated per ACT with OpenAI ImageGen, composited only inside the combat field, and compressed at WebP quality 82 for runtime use.

These files are complete map images derived from the user's licensed RPG Maker asset package. Do not redistribute them as a standalone asset pack. Recheck the upstream DLC terms before a public release.
