    노드를 선택하세요

    노드를 클릭하면 구조와 효과를 고치고, 여럿을 고르면 한꺼번에 바꿉니다.

    • Shift+드래그 범위 선택 · Shift/Ctrl+클릭 여럿 고르기 · Ctrl+A 모두
    • 방향키 고른 노드 옮기기(Shift 격자만큼) · 고른 것이 없거나 Ctrl+방향키 화면 이동
    • Ctrl+C/X/V 복사·잘라내기·마우스 자리에 붙여넣기 · Ctrl+D 복제
    • Delete/Backspace 지우기 · Esc 선택 해제, 모드 끝내기 · Q/E 시점 돌리기
    • 노드를 끌 때 Alt 격자 무시 · 빈 곳의 연결선을 누르면 그 연결을 고릅니다
